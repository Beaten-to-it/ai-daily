## 녹음 파일을 읽기 쉬운 회의록으로 바꾸기

**무엇을**  
인터뷰나 회의 녹음을 화자별 텍스트와 핵심 구간 중심으로 정리한다. 새로 공개된 음성 인식 모델은 화자 구분, 단어 단위 타임스탬프, 불필요한 추임새 제거와 자동 서식을 지원한다.

**어떻게**  
녹음 파일을 전사한 뒤 화자 구분과 타임스탬프가 포함된 결과를 만든다. 이어 결정 사항, 담당자, 기한처럼 필요한 항목만 별도로 추려 달라고 요청한다. 전문용어나 고유명사가 많다면 사용자 지정 어휘를 미리 제공한다. 자세한 기능은 [Intelligent transcription with Gemini 3.5 Transcribe]({{< relref "/articles/2026-08-27-737331cbffc8a092b5af.md" >}})에서 확인할 수 있다.

**주의할 점**  
자동으로 정돈된 문장은 실제 발언과 달라질 수 있다. 중요한 숫자, 이름, 결정 사항은 타임스탬프를 따라 원음과 대조한다.

## AI 에이전트에 API 키를 직접 보여주지 않기

**무엇을**  
코딩 에이전트가 외부 서비스를 호출해야 할 때 API 키를 프롬프트나 대화창에 붙여 넣지 않는다.

**어떻게**  
`key-amnesia` 같은 도구를 이용해 키를 암호화된 볼트에 보관하고, `ka run`으로 실행한 자식 프로세스에만 환경변수로 주입한다. 비밀번호와 실행 승인은 에이전트가 접근하기 어려운 별도 콘솔에서 직접 입력한다. 실행 결과에 키 원문이 섞였을 때 가리는 기능도 활용한다.

**주의할 점**  
편의를 위해 승인이나 비밀번호 확인을 장시간 캐시하면 보호 범위가 달라질 수 있다. 처음에는 사용할 때마다 직접 확인하는 기본 모드로 시작한다.

## 표 분석 결과는 모양을 바꿔 한 번 더 확인하기

**무엇을**  
AI가 스프레드시트나 CSV를 분석했다면 같은 근거를 다른 표 형태로 제시해 결론이 유지되는지 확인한다.

**어떻게**  
원본 표로 분석을 요청한 뒤 열 순서나 표 구성을 바꾼 사본에도 같은 질문을 던진다. 두 답의 수치와 결론을 비교하고, 근거가 부족하거나 충돌할 때는 추측하지 말고 부족한 정보와 추가 질문을 제시하도록 요청한다.

**주의할 점**  
표현만 달라졌는데 결과가 크게 바뀐다면 어느 한쪽을 바로 채택하지 않는다. 계산식과 원본 행을 직접 확인하거나 분석 조건을 더 명확히 지정한다.
