## 무엇이 있었나

마이크로소프트의 소형 코딩 모델 ‘MAI-Code-1.1-Flash’가 GitHub Copilot에 순차적으로 도입된다. 이전 모델보다 코딩 품질과 지시 이행, 도구 사용, 성능이 개선됐으며, 이미지를 이해할 수 있는 네이티브 비전 기능도 추가됐다.

GitHub에 따르면 이 모델의 정가 기준 비용은 MAI-Code-1-Flash보다 73% 낮다. 연간 GitHub Copilot 구독자에게는 프리미엄 요청 배수 0.25배가 적용되며, 사용량 기반 과금에서는 모델 제공자의 정가를 기준으로 청구된다.

Copilot Free와 Student 이용자는 자동 모델 선택을 통해 이용할 수 있다. Pro, Pro+, Max, Business, Enterprise 이용자는 자동 선택뿐 아니라 모델 선택기에서 직접 지정할 수 있다. 지원 환경에는 Copilot CLI와 클라우드 에이전트, GitHub Copilot 앱, GitHub·Visual Studio Code·Visual Studio의 Copilot Chat, GitHub Mobile, JetBrains IDE, Eclipse, Xcode가 포함된다.

Business와 Enterprise 요금제에서는 관리자가 Copilot 설정의 MAI-Code-1.1-Flash 정책을 활성화해야 한다. 이 정책은 기본적으로 꺼져 있다.

## 왜 중요한가

비용과 응답 성능의 균형이 중요한 가벼운 개발 작업에서 선택지가 늘었다. 특히 이미지 이해 기능이 추가돼 화면 캡처나 시각 자료를 활용하는 코딩 흐름에도 적용할 수 있다.

국내 기업과 조직에서 Business 또는 Enterprise 요금제를 운영한다면 모델이 자동으로 허용되지 않는다는 점을 확인할 필요가 있다. 실제 사용 전에 관리자가 정책을 켜야 하며, 조직의 과금 방식과 요청 배수도 함께 검토해야 한다.

## 확인 범위

GitHub Changelog가 발표한 모델 기능, 가격 비교, 요청 배수, 제공 요금제와 지원 환경, 관리자 정책 설정 내용을 확인했다. 다만 순차 배포의 지역별·계정별 완료 시점과 실제 작업별 성능, 최종 사용 요금은 이 발표만으로 확정할 수 없다.
