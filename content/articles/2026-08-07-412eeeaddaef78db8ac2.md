## 무엇이 있었나

GitHub가 오픈웨이트 AI 모델 ‘Kimi K3’를 GitHub Copilot에 도입한다고 발표했다. 적용 대상은 Copilot Pro, Pro+, Max, Business, Enterprise 요금제이며, 지원 환경에는 Visual Studio Code와 Visual Studio, Copilot CLI, GitHub 웹·모바일 앱, JetBrains IDE, Xcode, Eclipse 등이 포함된다.

다만 GitHub는 같은 날 편집자 주를 추가해 GitHub Actions 관련 사고를 완화하는 동안 Kimi K3 배포를 일시 중단했다고 밝혔다. 따라서 발표 시점에는 모든 사용자가 모델을 바로 선택할 수 있는 상태가 아니며, 배포 재개 시점도 제시되지 않았다.

Kimi K3는 GitHub가 Fireworks AI를 통해 호스팅한다. 사용량 기반 과금 가격은 입력 토큰 100만 개당 3달러, 출력 토큰 100만 개당 15달러, 캐시된 입력 토큰 100만 개당 0.30달러로 안내됐다.

## 왜 중요한가

이번 도입은 GitHub Copilot 이용자가 기존 상용 모델뿐 아니라 오픈웨이트 모델도 개발 작업에 선택할 수 있게 된다는 의미가 있다. 여러 개발 도구와 Copilot 환경에 걸쳐 제공될 예정이어서, 국내 개인 개발자와 기업도 작업 특성과 비용을 고려해 모델을 선택할 여지가 넓어진다.

기업에서는 별도의 관리 절차가 필요하다. Copilot Business와 Enterprise에서는 Kimi K3가 기본적으로 비활성화되며, 조직 관리자가 정책을 켜야 구성원이 사용할 수 있다. GitHub는 활성화에 앞서 각 조직의 보안·규제 준수·데이터 거버넌스 요건에 맞는지 검토할 것을 권고했다.

## 확인 범위

GitHub Changelog가 2026년 8월 6일 공개하고 같은 날 편집자 주로 갱신한 내용만 확인했다. Kimi K3의 단계적 배포 대상과 지원 환경, 예정 가격, 기업용 기본 비활성화 정책은 확인됐지만, GitHub Actions 사고의 구체적인 내용과 배포 재개 일정은 공개된 본문에서 확인되지 않는다. 실제 이용 가능 여부는 사용자 계정과 조직 정책, 향후 배포 상태에 따라 달라질 수 있다.
