## 무엇이 있었나

NVIDIA-labs가 AI 에이전트의 상태와 기능, 프롬프트, 입출력 규칙을 하나의 Python 클래스에 정의하는 프레임워크 ‘NOOA’를 선보였다. 클래스 필드는 상태, 메서드는 기능, 독스트링은 프롬프트, 타입 어노테이션은 입출력 계약으로 활용된다.

일반 Python 메서드는 작성된 코드대로 실행되고, 본문을 생략한 생성 메서드는 LLM이 처리한다. 개발자는 결정론적 코드와 모델의 판단이 필요한 작업을 한 클래스 안에서 조합할 수 있다. Python 메서드와 타입 정보가 도구 인터페이스 역할을 해 별도의 도구 스키마나 콜백을 연결하는 작업도 줄이는 방식이다.

NOOA는 LiteLLM을 통해 Anthropic·OpenAI·Ollama·vLLM 등이 지원하는 모델을 선택할 수 있으며, LLM 호출과 코드·메서드 실행을 추적하는 브라우저 기반 뷰어도 제공한다. Apache-2.0 라이선스의 연구용 소프트웨어로 소개됐다.

## 왜 중요한가

AI 에이전트를 일반 Python 객체처럼 테스트하고 리팩터링하며 버전 관리할 수 있다는 점이 핵심이다. 기존 Python 개발 방식과 에이전트 구성을 가깝게 결합하면 국내 개발팀도 별도의 프롬프트·도구 연결 계층을 관리하는 부담을 줄일 가능성이 있다.

다만 모델이 생성한 Python 코드는 파일 삭제나 정보 유출 같은 위험한 동작을 수행할 수 있다. 실제 서비스에 적용하려면 컨테이너나 가상머신 등 운영체제 수준의 격리 환경을 함께 마련해야 한다.

## 확인 범위

이 기사는 GeekNews에 실린 짧은 소개 내용만을 근거로 작성했다. NOOA의 실제 성능과 안정성, 지원 기능의 세부 조건, 운영 환경에서의 보안 수준은 확인하지 못했다. 연구용 소프트웨어인 만큼 도입 전 공식 저장소와 문서, 라이선스 및 샌드박스 구성을 별도로 검토할 필요가 있다.
