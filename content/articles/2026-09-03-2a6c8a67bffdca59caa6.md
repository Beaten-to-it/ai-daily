## 무엇이 있었나

메타가 실시간 음성 인식 모델 ‘뮤즈 보이스 트랜스크라이브’를 공개했다. 메타 슈퍼인텔리전스 랩스가 개발한 첫 실시간 오디오 인식 모델로, 음성을 문자로 변환하는 동시에 화자를 구분하고 발화가 끝나는 시점도 감지한다.

이 모델은 80밀리초 단위로 들어오는 음성을 분석해 곧바로 단어를 출력할지, 문맥을 더 확보한 뒤 처리할지 결정하는 ‘적응형 지연’ 기술을 적용했다. 70개가 넘는 언어를 학습했으며, 출시 시점에는 한국어를 비롯한 25개 언어를 검증된 지원 언어로 제공한다. 여러 언어를 한 문장 안에서 섞어 쓰는 상황과 20명 이상의 화자가 참여하는 장시간 음성도 처리할 수 있다고 메타는 설명했다.

기사에 따르면 아티피셜 애널리시스의 스트리밍 음성·텍스트 변환 평가에서 단어 오류율 3.1%를 기록했고, 공개 화자 분리 벤치마크에서는 평균 오류율 17.5%를 나타냈다. 메타는 해당 모델을 메타 AI와 ‘뮤즈 코드’의 음성 입력에 적용했으며, 메타 모델 API와 맥용 메타 AI를 통해서도 제공한다. 모델 가중치는 공개하지 않는다.

## 왜 중요한가

음성 인식과 화자 분리, 발화 종료 감지를 하나의 모델에서 처리하면 회의 기록이나 음성 비서, 음성 기반 코딩처럼 즉각적인 반응이 필요한 서비스의 구성을 단순화할 수 있다. 특히 한국어가 초기 검증 언어에 포함돼 국내 이용자와 개발자도 실시간 음성 인터페이스의 직접적인 적용 대상이 된다.

다만 메타가 모델 가중치 대신 자사 서비스와 API 중심으로 제공하기로 한 만큼, 외부 개발자의 활용 범위는 향후 공개될 접근 조건과 비용, 실제 환경에서의 성능에 영향을 받을 것으로 보인다.

## 확인 범위

모델의 기능, 지원 언어, 제공 경로와 벤치마크 수치는 AI타임스 기사에 제시된 메타 측 발표 및 기사 설명을 기준으로 정리했다. 오류율은 특정 평가 조건에서 나온 결과이므로 모든 언어와 소음 환경, 화자 구성에서 동일한 성능을 보장하는 수치로 해석할 수 없다. API의 구체적인 가격과 이용 제한, 한국어 실사용 정확도는 제공된 자료에서 확인되지 않았다.
