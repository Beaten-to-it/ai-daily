## 무엇이 있었나

GitHub가 xAI의 추론 모델 Grok 4.6을 GitHub Copilot에 순차적으로 배포하기 시작했다. 이 모델은 에이전트형 코딩과 복잡한 다단계 작업을 겨냥한다. GitHub는 자체 시험에서 Grok 4.6이 Visual Studio Code와 Copilot CLI의 터미널 기반 코딩 작업, 특히 지속적인 추론과 도구 사용이 필요한 장시간 작업에서 강점을 보였다고 밝혔다.

지원 대상은 Copilot Pro, Pro+, Max, Business, Enterprise 요금제다. 사용자는 Visual Studio Code와 Visual Studio, Copilot CLI, GitHub Copilot 클라우드 에이전트 및 앱, JetBrains IDE, Xcode, Eclipse의 모델 선택 화면에서 Grok 4.6을 고를 수 있다. 단계적 배포이므로 계정에 따라 표시 시점이 다를 수 있다.

사용량 기반 과금에서는 모델 제공사의 정가가 적용된다. Copilot Business와 Enterprise 관리자는 Copilot 설정에서 Grok 4.6 정책을 직접 활성화해야 하며, 기본값은 비활성화다.

## 왜 중요한가

한국의 개발자와 기업도 기존 Copilot 환경에서 복잡한 코딩 작업에 특화된 모델을 추가로 선택할 수 있게 됐다. 여러 도구를 오가며 긴 작업을 수행하는 코딩 에이전트 활용이 늘어나는 가운데, 팀은 작업 성격에 따라 모델을 비교하고 선택할 여지가 커졌다.

기업 사용자는 도입 전에 관리자 정책과 사용량 기반 비용을 함께 확인할 필요가 있다. 특히 Business·Enterprise 환경에서는 모델이 자동으로 활성화되지 않으므로 조직 차원의 검토와 설정이 선행돼야 한다.

## 확인 범위

GitHub Changelog가 발표한 지원 요금제, 이용 환경, 과금 방식, 관리자 정책과 순차 배포 계획을 확인했다. 성능 평가는 GitHub의 내부 시험 결과에 근거한 설명이며, 구체적인 평가 수치나 독립 벤치마크 결과는 해당 공지에 제시되지 않았다. 실제 제공 여부와 비용은 계정, 요금제, 배포 시점에 따라 달라질 수 있다.
