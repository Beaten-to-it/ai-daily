## 무엇이 있었나

GeekNews가 소개한 조사 내용에 따르면 ChatGPT Work는 클라우드에서 독립 실행 환경을 제공하는 Work Cloud와 사용자 컴퓨터의 파일·프로그램을 다루는 Work Local로 구분된다. 이 가운데 Work Cloud는 인터넷에 연결된 코드 실행, Chrome 기반 브라우저 자동화, 세션 간 공유되는 영구 파일 공간, 웹사이트 제작·배포, 하위 에이전트 운용 같은 기능을 제공한다.

일반 Chat이 대화와 짧은 결과물 생성에 초점을 둔다면, Work는 파일·분석·사이트·반복 작업처럼 실행 가능한 산출물이 필요한 업무를 겨냥한다. 조사자는 Work 환경에서 모델과 추론 수준을 선택하고 여러 하위 에이전트에 작업을 병렬로 맡길 수 있다고 설명했다. 직접 살펴본 환경에서는 개인 MCP 도구 6개를 포함해 등록 도구 223개와 스킬 44개가 확인됐다고 밝혔다.

또한 반복 일정을 자연어로 설정하는 자동화 기능과 Cloudflare 기반의 사이트 배포 기능도 소개됐다. 현재 이용 대상은 월 20달러 이상 유료 구독자로 정리됐다.

## 왜 중요한가

ChatGPT Work의 차별점은 답변 생성 자체보다 조사부터 코드 실행, 브라우저 조작, 파일 관리, 결과물 배포까지 하나의 환경에서 이어갈 수 있다는 데 있다. 국내 기업과 개인 사용자에게는 자료 수집이나 정기 보고, 데이터 분석, 웹 기반 결과물 제작을 자동화할 선택지가 늘어난다는 의미가 있다.

반면 이런 통합은 보안 위험도 키운다. 비공개 데이터 접근, 신뢰할 수 없는 웹 콘텐츠 노출, 외부 통신 기능이 한 시스템에 결합되면 프롬프트 주입을 통한 정보 유출 가능성을 신중하게 관리해야 한다. 중요한 계정이나 내부 자료를 연결할 때는 접근 권한과 외부 전송 범위를 제한하고, 자동 실행 결과를 사람이 검토하는 절차가 필요하다.

## 확인 범위

이 기사는 제공된 GeekNews 게시물에 정리된 조사 결과를 바탕으로 작성했다. Work Cloud와 Work Local의 기능 구분, 구독 조건, 도구·스킬 수치는 해당 게시물에서 확인되는 내용이다. 다만 모델별 제공 범위, 사용량 산정 방식, 기본 인터넷 접근 정책과 프롬프트 주입 방어 체계 일부는 조사자의 관찰 또는 추정으로 제시됐으며, OpenAI의 공식 기술 명세를 통해 독립적으로 재확인한 내용은 아니다. 서비스가 빠르게 변경되고 있다는 설명도 있어 실제 제공 기능과 조건은 시점이나 계정에 따라 달라질 수 있다.
