## 무엇이 있었나

연구진이 사람이 미리 만든 대규모 문제 모음 없이도 대규모언어모델(LLM)의 추론 능력을 훈련하는 자기대국 방식 ‘LURE’를 제안했다. 검증 가능한 보상을 활용하는 기존 강화학습은 대체로 사람이 선별한 과제에 의존하고, 기존 제로 데이터 방식도 생성된 문제의 학습 가능성을 사후 판정하는 데 머문다는 문제의식에서 출발했다.

LURE는 문제를 만드는 모델을 ‘회피자’, 문제를 해결하는 모델을 ‘추격자’로 설정한다. 회피자는 추격자가 여러 차례 시도했을 때 절반가량 성공할 정도의 난도에 문제를 배치하도록 학습한다. 추격자는 최종 정답 여부뿐 아니라 검증 과정에서 나타나는 단계적인 진전도 보상으로 받는다. 연구진은 이 구조가 문제 난도를 고정된 기준으로 거르는 대신, 학습자의 실력 변화에 맞춰 조절하도록 설계됐다고 설명했다.

논문 초록에 따르면 LURE는 검증 가능한 추론 환경 3종과 기반 모델 계열 3종에서 비교 기법보다 높은 성능을 보였다. 여러 과제를 함께 학습한 통합 모델은 세 과제군에 속한 미학습 벤치마크 9종의 종합적인 분포 외(OOD) 제로샷 정확도에서도 학습된 비교 모델들을 앞섰다.

## 왜 중요한가

핵심은 학습 데이터를 없애는 데 그치지 않고, 모델이 현재 풀기에는 너무 쉽지도 어렵지도 않은 문제를 스스로 찾아내도록 했다는 점이다. 이런 방식이 다양한 환경에서 재현된다면 사람이 문제를 계속 제작하고 난도를 조정하는 비용을 줄이면서 추론 모델의 학습 과정을 확장할 가능성이 있다.

한국의 AI 연구·개발 현장에서도 검증기를 만들 수 있는 수학, 논리, 코드 실행형 과제 등에 적용 가능성을 검토할 만하다. 특히 자체 학습 데이터가 부족하거나 사람의 문제 제작 비용이 큰 조직에는 데이터 생성과 난도 조절을 하나의 학습 과정으로 묶었다는 점이 의미가 있다. 다만 실제 서비스에 적용하려면 계산 비용과 학습 안정성, 특정 검증 환경 밖으로 성능이 얼마나 일반화되는지를 별도로 확인해야 한다.
