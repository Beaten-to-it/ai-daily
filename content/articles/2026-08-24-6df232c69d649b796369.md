## 무엇이 있었나

업스테이지가 자체 언어모델 ‘솔라 프로 4’를 기반으로 한 AI 코드 리뷰 도구 ‘코드 솔라’를 공개했다. 이용자가 깃허브 등 코드 저장소를 등록하고 검토를 요청하면 코드 솔라가 버그와 보안·성능 문제를 찾아 해당 코드 줄에 수정안을 제시하는 방식이다.

김성훈 업스테이지 대표는 코드 솔라가 발견한 버그를 앤트로픽의 ‘클로드 오퍼스’가 수정하는 사용 사례도 소개했다. 다만 업스테이지는 현재 코드 솔라를 클로드 코드나 코덱스 같은 범용 코딩 에이전트로 확장할 구체적인 계획은 없다고 밝혔다.

기반 모델인 솔라 프로 4는 기사에 제시된 8월 20일 기준 오픈라우터의 글로벌 모델 일일 토큰 사용량 순위에서 10위를 기록했다. 업스테이지는 AMD와의 협력을 통해 추론 처리량을 최근 2개월간 25% 높였으며, 모델 수요에 대응하기 위해 AMD 칩 1만장을 도입할 계획이라고 전했다.

## 왜 중요한가

코드 솔라는 국내 AI 기업이 범용 언어모델을 실제 소프트웨어 개발 과정의 품질 관리 도구로 연결한 사례다. 코드 생성뿐 아니라 검토와 오류 탐지에 자체 모델을 적용했다는 점에서 국내 모델의 기업용 활용 범위가 넓어질 가능성을 보여준다.

또한 업스테이지가 모델 개발과 함께 대규모 추론 인프라 확충에 나섰다는 점도 주목된다. 코드 리뷰 서비스의 실효성은 모델 성능뿐 아니라 처리 속도, 운영 안정성, 보안 체계에 좌우되는 만큼 향후 실제 도입 사례와 성능 검증이 중요하다.

## 확인 범위

코드 솔라의 기능, 현재 확장 계획, 오픈라우터 사용량 순위와 AMD 협력 관련 수치는 제공된 AI타임스 기사에서 확인했다. 서비스의 공개 범위와 이용 조건, 지원 언어·저장소, 정확도, 가격, 코드 보안 및 데이터 처리 정책은 기사에 구체적으로 제시되지 않았다. 실제 코드 리뷰 품질과 다른 도구 대비 성능도 독립적으로 검증된 내용은 아니다.
