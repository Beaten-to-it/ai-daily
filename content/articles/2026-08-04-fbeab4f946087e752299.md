## 무엇이 있었나

포뮬러1(F1)이 AWS와 함께 마케팅 데이터 플랫폼 ‘Customer 360’의 운영을 자동화하는 ‘데이터 액셀러레이터’를 구축했다. 2026년 초 개발된 이 시스템은 Amazon Bedrock AgentCore 기반 AI 에이전트를 활용해 신규 데이터 소스의 설정과 파이프라인 코드, 데이터 변환, 거버넌스 정책 등을 생성한다.

기존에는 데이터 소스 하나를 연동하는 데 6~8주가 걸렸지만, AWS가 공개한 사례에 따르면 코드 생성 시간은 약 40분으로 줄었다. 실제 배포와 엔지니어 검토에는 추가로 수시간이 필요하다. F1은 에이전트가 온보딩 작업의 95%를 처리하며, 18개월 분량이던 12개 데이터 소스 연동 적체도 수주 안에 해소했다고 밝혔다.

자동화 범위에는 개인정보보호 규정(GDPR)에 따른 데이터 분류와 태깅도 포함된다. 에이전트가 생성한 변경 사항은 GitHub 풀 리퀘스트와 Jira 티켓으로 남으며, 엔지니어가 검토하고 승인해야 다음 단계로 진행된다.

시스템은 운영 중인 데이터의 스키마 변경도 감지한다. 공급자가 열 이름이나 데이터 구조를 바꾸면 영향을 받는 파이프라인을 파악하고 수정 코드를 제안한다. 이 밖에 Amazon SageMaker Unified Studio를 통한 데이터 접근 통합, 데이터 계보와 장애 원인을 보여주는 관측 기능도 도입됐다. F1은 기존 고객 식별 알고리즘도 최적화해 처리 시간을 50% 줄였다고 설명했다.

## 왜 중요한가

이번 사례는 기업용 AI 에이전트가 단순 질의응답을 넘어 데이터 엔지니어링의 반복 업무를 맡는 방식을 보여준다. 특히 코드와 정책을 바로 운영 환경에 반영하지 않고, 기존 풀 리퀘스트 검토 절차 안에서 사람이 최종 결정을 내리도록 설계한 점이 눈에 띈다.

여러 외부 사업자로부터 데이터가 들어오는 국내 미디어·유통·금융 기업에도 참고할 만하다. 데이터 형식 변경과 개인정보 분류, 접근 권한 설정을 함께 다루면 연동 속도를 높이면서도 변경 이력을 추적할 수 있기 때문이다. 다만 실제 도입 효과는 기존 데이터 표준화 수준, 승인 절차, 규제 요건과 시스템 복잡도에 따라 달라질 수 있다.

## 확인 범위

내용은 AWS가 공개한 F1 고객 사례와 기술 설명을 바탕으로 확인했다. 온보딩 시간 6~8주에서 코드 생성 약 40분으로의 단축, 작업의 95% 자동 처리, 고객 식별 처리 시간 50% 감소 등의 수치는 AWS와 F1이 제시한 결과다. 독립적인 성능 평가나 비용 자료, 자동 생성 코드의 오류율과 장기 운영 지표는 공개된 자료에서 확인되지 않았다.

또한 약 40분은 전체 운영 배포 시간이 아니라 코드 생성에 걸린 시간이다. 엔지니어 검토와 배포에는 별도로 수시간이 소요된다고 명시돼 있다.
