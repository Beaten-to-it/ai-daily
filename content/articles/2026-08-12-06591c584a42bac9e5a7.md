## 무엇이 있었나

GitHub가 JetBrains용 GitHub Copilot 플러그인에 대화 세션을 넘나드는 메모리 기능과 Ollama 연동을 추가했다. 메모리를 활성화하면 에이전트 채팅이 프로젝트 정보나 사용자 선호를 기억해 다음 대화에서 활용할 수 있으며, 설정 포털에서 기능을 켜거나 끌 수 있다.

Ollama는 사용자가 모델 공급자를 직접 연결하는 BYOK 방식으로 지원된다. JetBrains 환경에서 공급자 설정과 모델 선택이 가능해져 개발 환경에 맞는 모델을 활용할 선택지가 늘었다.

기업 관리자는 플러그인 사용 여부, MCP 서버 접근, 권한 우회 동작, OpenTelemetry 설정을 서버 측에서 제어할 수 있게 됐다. 이 밖에도 Codex 세션의 에이전트 디버그 로그 표시, 지침과 스킬을 이용한 Codex 맞춤 설정, IDE 통합 터미널을 통한 Copilot CLI 자동 설치가 추가됐다. 계정 전환과 삭제, 파일·폴더 참조, 터미널 출력, MCP 실행 및 승인 과정 등도 개선됐다.

## 왜 중요한가

JetBrains IDE를 사용하는 국내 개발팀은 반복해서 프로젝트 맥락을 설명하는 부담을 줄이고, Ollama를 통해 자체 개발 환경에 맞는 모델 운용 방식을 선택할 수 있다. 특히 조직 단위의 플러그인·MCP 접근 제어가 강화돼 AI 개발 도구를 도입하면서 관리 정책과 관측성 요건을 함께 적용하려는 기업에 의미가 있다.

다만 대화 간 메모리는 편의성과 함께 어떤 정보가 저장되고 다시 활용되는지 살펴야 하는 기능이다. 기업 사용자는 조직의 보안 정책과 GitHub가 제공하는 관리 설정을 검토한 뒤 적용하는 편이 적절하다.

## 확인 범위

GitHub가 2026년 8월 11일 공개한 변경 기록에서 기능 추가와 개선 사항을 확인했다. 구체적인 지원 모델 목록, 메모리의 저장 방식과 보존 기간, Ollama 연결에 필요한 세부 조건, 기업별 배포 시점은 제공된 변경 기록만으로 확인되지 않는다.
