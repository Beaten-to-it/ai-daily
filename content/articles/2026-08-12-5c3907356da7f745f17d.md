## 무엇이 있었나

통신 브랜드 솔루션 기업 퍼스트 오리온이 아마존의 브라우저 에이전트 기술인 ‘Amazon Nova Act’를 웹 애플리케이션 품질보증(QA) 자동화에 도입했다. 기존 Selenium·Playwright 기반 테스트가 화면 요소를 지정하는 선택자에 의존해 UI 변경 때마다 깨지는 문제를 줄이고, QA 분석가가 자연어로 테스트 절차를 작성해 직접 실행할 수 있도록 한 것이 핵심이다.

퍼스트 오리온은 React 기반 작성 화면과 Amazon S3의 테스트 저장소, Amazon ECS·AWS Fargate에서 작동하는 Python 테스트 실행기를 구축했다. 브라우저 실행과 세션 녹화, 병렬 처리는 Amazon Bedrock AgentCore Browser가 담당하며, 결과는 Allure 대시보드와 Microsoft Teams를 통해 공유한다.

AWS가 공개한 퍼스트 오리온의 집계에 따르면, 지원되는 테스트 시나리오에서는 테스트 정의부터 자동 실행까지 걸리는 시간이 수일에서 수분으로 줄었다. 특정 유형의 QA 주기는 최대 20~25% 단축됐고, 엔지니어링 시간은 25~30% 절감된 것으로 추산됐다. 일부 사례에서는 테스트 범위도 15% 이상 늘었다.

## 왜 중요한가

이번 사례는 생성형 AI 기반 에이전트가 테스트 코드를 보조하는 수준을 넘어, 실제 화면 상태를 해석하고 여러 단계의 브라우저 작업을 수행하는 방식으로 QA 업무에 적용될 수 있음을 보여준다. 자연어 테스트 작성이 자리 잡으면 개발 완료 후 자동화 엔지니어가 선택자를 일일이 작성하는 병목을 줄이고, 회귀 테스트를 더 이른 개발 단계에서 반복 실행할 수 있다.

웹 서비스와 배포 주기가 빠르게 늘어나는 한국 기업에도 의미가 있다. 특히 한정된 QA 인력으로 여러 제품과 브라우저 환경을 점검해야 하는 조직이라면 테스트 작성 속도와 유지보수 부담을 낮출 가능성이 있다. 다만 자연어 입력만으로 안정적인 자동화가 완성되는 것은 아니다. 퍼스트 오리온도 명확한 프롬프트, 업무 규칙과 사전 조건의 명시, 모델 동작의 일관성을 높이기 위한 매개변수 조정이 필요했다고 밝혔다.

## 확인 범위

구성 요소와 성과 수치는 AWS와 퍼스트 오리온이 공동 작성한 사례 게시물에서 확인했다. 수치는 모든 테스트에 일괄 적용된 결과가 아니라 특정 테스트 유형이나 일부 사례를 대상으로 한 자체 측정·추정치다. 퍼스트 오리온은 아직 도입 범위와 관련 기능을 확대하는 단계이며, 독립적인 제3자 검증 결과나 장기간 운영 통계는 해당 게시물에 제시되지 않았다.
