## 무엇이 있었나

텐센트와 싱가포르국립대학교, 홍콩이공대학교 공동 연구진이 키보드 입력에 맞춰 캐릭터와 카메라의 움직임을 영상으로 생성하는 액션 제어형 월드 모델 ‘H3-월드’를 공개했다.

H3-월드는 미니맥스의 330억 매개변수 영상 생성 모델 H3를 기반으로 한다. 캐릭터 이동에는 W·A·S·D 키를, 카메라 조작에는 I·J·K·L 키 등을 사용한다. 입력된 키는 짧은 영어 명령으로 변환돼 영상 생성 과정에 반영된다.

연구진은 별도의 대규모 제어 모델을 붙이는 대신 방향성 주의 마스크와 LoRA를 활용했다. 약 8000개의 게임플레이 영상을 사용했으며, 기반 모델 전체의 0.199%인 6560만개 매개변수만 추가 학습했다고 밝혔다. 기본 설정에서는 시작 이미지와 장면 설명, 키보드 입력을 바탕으로 832×480 해상도의 약 5.2초 영상을 생성한다.

모델은 rank-32 LoRA 형태로 허깅페이스에 공개됐으며 라이선스는 아파치 2.0이다. 다만 실제 구동에는 LoRA 가중치뿐 아니라 약 135GB 규모의 H3 기반 모델과 전용 코드, 수정된 영상 생성 파이프라인이 필요하다.

## 왜 중요한가

H3-월드는 영상 생성 AI가 정해진 프롬프트에 따라 결과물을 만드는 도구에서 사용자의 연속적인 조작에 반응하는 시뮬레이션 시스템으로 확장되는 흐름을 보여준다. 게임 제작과 가상환경 구축, 로봇 학습용 시뮬레이션 등에서 상호작용 가능한 장면을 만드는 기반 기술로 활용될 가능성이 있다.

특히 기존 영상 모델이 습득한 언어·동작 표현을 재활용하고 일부 매개변수만 추가 학습했다는 점은 주목할 만하다. 국내 개발사와 연구기관에도 거대한 제어 모델을 새로 구축하지 않고 기존 생성 모델을 특정 용도에 맞게 확장하는 접근법을 제시한다. 다만 기반 모델의 크기가 커 실제 도입에는 상당한 저장공간과 연산 자원이 필요하다.

## 확인 범위

공개 방식과 모델 구조, 학습 규모, 출력 사양, 라이선스 및 구동 요건은 AI타임스가 전한 연구진 발표 내용을 기준으로 정리했다. 새로운 환경과 학습하지 않은 동작 조합에서도 제어할 수 있다는 설명 역시 연구진의 주장으로, 실제 성능과 지연시간, 필요한 하드웨어, 다른 모델 대비 우위는 이 기사만으로 독립적으로 검증되지 않았다.
