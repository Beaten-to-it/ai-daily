## 무엇이 있었나

연구진이 코드 생성 모델을 함수 단위로 평가하고 학습하는 프레임워크 ‘STEP-KTODER’를 공개했다. 여러 함수로 구성된 프로그램에서 각 함수를 하나의 학습 단계로 정의하고, 자동 생성한 단위 테스트를 실행해 함수별 정답 여부를 판정하는 방식이다. 여기에 전체 프로그램의 실행 결과도 함께 반영한다.

연구진은 HumanEval(+), MBPP(+), BigCodeBench, LiveCodeBench에서 STEP-KTODER를 평가했으며, 전체 프로그램의 최종 결과만 사용하는 KTO와 DPO보다 성능이 향상됐다고 보고했다. 언어모델을 평가자로 사용했을 때는 함수 실패를 실제보다 자주 예측해 올바른 단계의 학습 신호까지 훼손하는 경향이 나타났다고 설명했다.

논문은 EMNLP 2026 Findings에 채택됐으며, 구현 코드도 공개됐다.

## 왜 중요한가

코드 생성 AI는 최종 출력이 실패했더라도 그 안의 모든 함수가 틀린 것은 아니다. 함수별 실행 결과를 학습 신호로 활용하면 정상적인 부분과 오류가 있는 부분을 구분해 모델을 더 세밀하게 개선할 수 있다.

특히 국내 기업과 개발 조직이 사내 코드나 특정 업무에 맞춘 모델을 조정할 때, 사람 또는 다른 언어모델의 주관적 판정보다 자동화된 테스트 결과를 활용하는 접근이 학습 데이터의 신뢰도를 높일 가능성이 있다. 다만 이를 실제 개발 환경에 적용하려면 함수별 동작을 정확히 검증할 수 있는 테스트를 얼마나 안정적으로 만들 수 있는지가 중요하다.

## 확인 범위

이번 내용은 arXiv에 공개된 논문의 서지 정보와 초록을 기준으로 확인했다. 제안 방식, 평가에 사용된 벤치마크, 비교 대상보다 성능이 향상됐다는 연구진의 결론은 확인되지만, 벤치마크별 구체적인 개선 폭과 통계적 유의성은 제공된 자료만으로 판단하지 않았다. 실제 소프트웨어 프로젝트에서의 비용, 테스트 생성 오류, 복잡한 코드베이스에 대한 일반화 성능도 추가 검증이 필요하다.
