## 무엇이 있었나

AWS는 정식 출시된 Amazon Bedrock AgentCore harness를 n8n의 시각적 편집기에서 이용할 수 있는 오픈소스 커뮤니티 노드 `@aws/n8n-nodes-agentcore`를 소개했다. 이 노드를 사용하면 별도의 에이전트 인프라나 오케스트레이션 코드를 직접 작성하지 않고도 대화 기억, 사용자별 메모리 분리, 도구 호출, 세션 격리 등을 갖춘 AI 에이전트를 n8n 워크플로에 구성할 수 있다.

노드는 Amazon Bedrock뿐 아니라 OpenAI, Google Gemini, LiteLLM 호환 공급자를 지원하며, 같은 대화 세션 중에도 모델 공급자를 변경할 수 있다. 코드 실행용 샌드박스, 클라우드 브라우저, AgentCore Gateway, 원격 MCP 서버 등의 도구도 연결할 수 있다.

운영 환경을 위한 기능도 포함됐다. 사용자와 대화 단위로 메모리를 분리할 수 있고, AWS가 관리하는 VPC 환경에서 에이전트를 실행하거나 특정 버전을 스테이징·프로덕션 엔드포인트에 고정할 수 있다. 노드는 MIT 라이선스로 공개됐으며 AWS의 오픈소스 에이전트 프레임워크인 Strands Agents를 기반으로 한다.

## 왜 중요한가

n8n을 사용하는 국내 기업과 개발자는 기존 자동화 흐름 안에서 상태를 유지하고 실제 도구를 다루는 에이전트를 구성할 수 있게 됐다. 단순한 모델 호출을 넘어 장기 작업, 사용자별 문맥 관리, 사내망 자원 접근 같은 운영 요구를 하나의 시각적 워크플로에서 다룰 수 있다는 점이 핵심이다.

특히 특정 모델 공급자에 고정되지 않고 업무에 따라 모델을 선택할 수 있어 비용과 성능, 내부 정책을 고려한 구성이 가능하다. 다만 AgentCore harness와 관리형 메모리, VPC 엔드포인트는 과금 대상이며, AWS 자격증명과 실행 역할에는 최소 권한 원칙을 적용해야 한다.

## 확인 범위

이 기사는 AWS ML 블로그가 공개한 기능 설명과 사용 절차를 기준으로 작성했다. 커뮤니티 노드의 지원 기능, MIT 라이선스, 다중 모델 공급자 연동, 메모리·도구·VPC 구성은 해당 자료에서 확인했다. 실제 성능과 비용, 지역별 제공 여부, 각 외부 모델 및 n8n 환경과의 호환성은 개별 구성과 최신 서비스 문서를 기준으로 별도 확인이 필요하다.
