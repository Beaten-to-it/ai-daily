## 무엇이 있었나

Anthropic이 파이썬 SDK `anthropic-sdk-python` 0.121.0 버전을 공개했다. 이번 릴리스에는 세션 예산, 어드바이저 도구, 추론 위치 고정, GitHub에서 스킬을 자동으로 불러오는 기능에 대한 API 지원이 추가됐다.

대화 도중 도구 구성을 변경할 수 있는 베타 기능도 반영됐다. 유지보수 항목으로는 지원이 종료된 Claude Opus 4.1 모델 제거, 문서와 설명 문자열 수정, 모든 의존성에 대한 메이저 버전 범위 지정이 포함됐다.

## 왜 중요한가

세션 예산 지원은 Claude 기반 애플리케이션이 세션 단위의 자원 사용을 관리하는 데 활용될 수 있다. 추론 위치 고정 기능은 처리 위치가 중요한 서비스의 배포·운영 설계를 세밀하게 조정할 여지를 준다. GitHub 기반 스킬 자동 로딩과 대화 중 도구 변경 기능은 에이전트가 필요한 기능을 불러오고 조정하는 워크플로를 구현할 때 유용할 수 있다.

다만 지원 종료 모델이 SDK에서 제거됐으므로 Claude Opus 4.1을 명시적으로 참조하는 기존 파이썬 애플리케이션은 업그레이드 전에 모델 설정과 호환성을 점검할 필요가 있다.

## 확인 범위

GitHub에 게시된 0.121.0 릴리스의 변경 목록과 공개 시각을 확인했다. 각 기능의 구체적인 API 형태, 이용 조건, 지원 지역, 요금 및 안정화 일정은 제공된 릴리스 정보만으로 확인되지 않는다. 대화 중 도구 변경 기능은 릴리스에서 베타로 명시돼 있어 향후 인터페이스나 동작이 바뀔 가능성이 있다.
