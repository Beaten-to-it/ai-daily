## 무엇이 있었나

기업 데이터에 대한 자연어 질의를 처리하는 LLM 아키텍처를 비교한 ‘SemPlan Benchmark’ 논문이 arXiv에 공개됐다. 연구진은 영어와 브라질 포르투갈어로 구성된 합성 데이터 1,800건을 만들고, 이 가운데 1,200건을 고정 평가 세트로 사용했다.

비교 대상은 SQL 직접 생성, 제한된 도구형 에이전트, 구조화된 의미 요청을 만든 뒤 결정론적으로 계획·실행하는 방식, 그리고 명확화 대화와 상태 관리를 추가한 의미 계획 방식 등 네 가지다. 동일한 모델 설정으로 생성한 주요 평가 기록 4,800건을 분석한 결과, 정답률은 각각 22.25%, 22.58%, 25.67%, 24.25%였다.

구조화된 의미 요청과 결정론적 실행을 결합한 방식이 가장 높은 정답률을 기록했고, 사전에 정한 쌍별 분석에서도 다른 세 방식보다 유의하게 높은 성과를 보였다. 다만 SQL 직접 생성 방식은 정책 준수율이 가장 높고 안전하지 않거나 유효하지 않은 결과의 비율이 가장 낮았다. 명확화·상태 관리 방식은 평균 API 비용과 잘못된 응답 거부 비율이 가장 낮았다.

## 왜 중요한가

기업 환경의 자연어 데이터 질의는 단순히 답을 맞히는 문제에 그치지 않는다. 접근 정책을 지키면서 실행 가능한 질의를 만들고, 비용과 비결정성까지 관리해야 한다. 이번 결과는 중간 표현과 결정론적 계획을 도입하면 정확도를 일부 높일 수 있지만, 안전성·비용·응답 거부 같은 다른 지표까지 일괄적으로 개선되지는 않는다는 점을 보여준다.

특히 최고 정답률도 25.67%에 머물렀다. 한국 기업이 LLM 기반 데이터 조회 기능을 도입할 때 특정 아키텍처를 만능 해법으로 보기보다, 권한 통제와 검증 절차를 별도로 두고 업무 목적에 따라 정확도·안전성·비용의 우선순위를 정해야 한다는 시사점이 있다.

## 확인 범위

이 기사는 arXiv에 공개된 논문의 초록과 서지 정보를 바탕으로 작성했다. 150개 사례로 구성된 안정성 평가에서는 정답 여부의 반복 일치도가 92.00~98.67%로 나타났지만, 이는 정답률 자체가 아니라 반복 실행 때 결과가 얼마나 일관됐는지를 나타내는 지표다.

벤치마크는 합성 데이터와 영어·브라질 포르투갈어를 대상으로 하므로 실제 기업 데이터나 한국어 환경에서도 같은 결과가 나온다고 단정할 수 없다. 논문은 TMLR에 제출됐다고 명시돼 있으나, 게재 승인이나 동료평가 완료 여부는 제공된 정보에서 확인되지 않는다.
