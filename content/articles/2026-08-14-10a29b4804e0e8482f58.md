## 무엇이 있었나

AWS가 Amazon Bedrock AgentCore를 활용해 인수·합병(M&A) 실사를 지원하는 멀티에이전트 시스템의 참조 아키텍처와 샘플 구현을 공개했다. 감독 에이전트가 대상 기업 선별, 재무 분석, 전략적 적합성 평가, 규정 준수 검증을 담당하는 네 전문 에이전트에 작업을 배분하는 구조다.

시스템은 Aurora PostgreSQL의 정형 데이터, Amazon Bedrock Knowledge Bases의 문서 검색, AgentCore Gateway를 통한 외부 도구 연동, 과거 거래 정보를 보존하는 메모리를 결합한다. 사실 주장에 출처가 있는지 검사하는 평가기와 Guardrails, CloudWatch 로그, AWS X-Ray 추적 기능도 포함해 결과의 근거와 실행 과정을 확인할 수 있도록 설계됐다.

AWS는 통합형 서비스인 Amazon Quick을 이용하는 경로와 AgentCore로 맞춤 시스템을 구축하는 경로를 함께 제시했다. 공개 샘플은 실제 기업 정보가 아닌 합성 데이터를 사용하며, 지원 리전에서 배포해 각 에이전트의 응답과 인용 검증 절차를 시험할 수 있다.

## 왜 중요한가

M&A 실사는 재무 자료와 규제 문서, 시장 정보, 내부 기록을 함께 검토해야 해 많은 반복 작업이 발생한다. 이번 사례는 AI 에이전트를 단순 문서 요약 도구가 아니라 데이터 조회부터 분석, 업무 분배, 근거 검증까지 연결하는 작업 체계로 구성하는 방법을 보여준다.

국내 금융·제조·물류 기업에도 참고할 만한 지점은 감사 가능성이다. 민감한 거래 정보를 다루는 환경에서는 빠른 분석만큼 접근 권한 통제와 출처 추적, 결과 검증이 중요하다. AWS가 제시한 구조는 IAM 권한 범위 제한, Cedar 정책 기반 기본 거부 방식, 사설 네트워크, 저장 데이터 암호화 등을 함께 적용한다. 다만 실제 도입 시에는 국내 개인정보·금융 규제와 기업별 승인 절차에 맞춘 별도 설계와 검증이 필요하다.

## 확인 범위

AWS가 2026년 8월 13일 공개한 기술 설명과 참조 구현 내용을 기준으로 확인했다. 수주가 걸리던 작업을 수시간으로 줄였다는 설명은 AWS의 자체 테스트 결과이며, 독립적인 성능 검증이나 실제 기업 환경의 운영 성과로 확인된 수치는 아니다. 배포 비용과 시간 역시 AWS가 제시한 샘플 환경 기준으로, 리전·모델 사용량·구성에 따라 달라질 수 있다.

또한 공개 구현은 합성 데이터를 사용한 기술 예제다. 실제 M&A 의사결정에 필요한 분석 정확도, 법적 책임, 보안 적합성 또는 투자 판단의 타당성을 보증하는 상용 실사 결과로 해석해서는 안 된다.
