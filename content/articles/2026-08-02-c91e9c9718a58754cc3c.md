## 무엇이 있었나

2026년 7월 28일자 모델 컨텍스트 프로토콜(MCP) 사양에 상태 비저장 방식이 도입됐다. 기존 방식은 세션을 초기화해 식별자를 받은 뒤 도구를 호출해야 했지만, 새 방식에서는 프로토콜 버전과 호출 정보를 담은 한 번의 HTTP 요청으로 도구를 실행할 수 있다.

서버가 세션 상태를 유지하거나 동일한 세션을 특정 백엔드로 연결할 필요가 줄어들어 클라이언트와 서버 구현, 웹 환경에서의 확장이 단순해진다는 것이 글의 핵심 평가다.

개발자 사이먼 윌리슨은 새 사양을 활용한 프로젝트도 공개했다. MCP 서버를 탐색하고 도구를 호출하는 파이썬 명령줄 도구 `mcp-explorer`, 데이터 탐색 도구 Datasette에 MCP 엔드포인트를 추가하는 `datasette-mcp`, 자신의 LLM 명령줄 도구에서 MCP를 이용하게 하는 초기 단계의 `llm-mcp-client`다. `datasette-mcp`는 데이터베이스 목록 확인, 스키마 조회, 읽기 전용 SQL 실행 기능을 제공한다.

## 왜 중요한가

상태 비저장 구조는 MCP 서비스를 여러 서버에 분산하거나 필요에 따라 확장할 때 세션 관리 부담을 낮춘다. 국내 기업과 개발자도 사내 데이터베이스나 제한된 업무 기능을 AI 에이전트에 연결하는 도구를 보다 단순한 구조로 설계할 수 있다는 의미가 있다.

보안 측면에서도 주목할 만하다. 임의의 셸 명령과 인터넷 접근 권한을 에이전트에 통째로 제공하는 방식보다, 사전에 정의한 MCP 도구만 노출하면 허용된 기능과 위험 범위를 파악하고 통제하기 쉽다는 것이 윌리슨의 견해다. 다만 MCP 자체가 프롬프트 주입이나 정보 유출 위험을 없애는 것은 아니므로, 도구 권한과 입력 데이터에 대한 별도 보안 설계는 여전히 필요하다.

## 확인 범위

새 사양의 요청 구조와 세 프로젝트의 기능은 공개된 글에서 확인했다. MCP의 구현 편의성과 보안상 이점은 저자의 개발 경험과 평가를 요약한 것이며, 독립적인 성능 측정이나 보안 검증 결과는 해당 글에 제시되지 않았다. `llm-mcp-client`는 알파 단계로 소개돼 향후 기능과 통합 방향이 바뀔 수 있다.
