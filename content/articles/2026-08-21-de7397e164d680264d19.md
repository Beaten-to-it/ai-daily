## 무엇이 있었나

Anthropic이 2026년 8월 19일 Python SDK 0.125.0을 공개했다. 릴리스 안내에 따르면 이번 버전에는 관리형 에이전트의 웹 검색 설정과 자체 호스팅 샌드박스 메모리 관련 기능이 추가됐다.

이번 릴리스는 이전 버전인 0.124.0 이후의 기능 업데이트로 분류됐으며, 관련 변경 커밋과 전체 변경 이력도 함께 공개됐다.

## 왜 중요한가

Anthropic API를 Python 환경에서 사용하는 개발자는 에이전트의 웹 검색 동작과 자체 호스팅 샌드박스의 메모리 기능을 SDK 차원에서 다룰 수 있게 됐다. 검색이나 실행 환경을 결합한 에이전트 시스템을 개발하는 국내 팀에도 관련 구성 작업을 단순화할 가능성이 있다.

다만 실제 적용 전에는 전체 변경 이력과 SDK 문서를 확인해 새 설정의 구체적인 사용법, 지원 범위, 기존 코드와의 호환성을 검토할 필요가 있다.

## 확인 범위

GitHub 릴리스 페이지에서 버전 번호, 공개 시각, 기능 추가 항목과 변경 커밋을 확인했다. 제공된 릴리스 요약에는 각 기능의 API 형식이나 동작 조건, 마이그레이션 방법, 호환성 영향에 관한 상세 설명이 없어 해당 내용은 확인된 사실로 다루지 않았다.
