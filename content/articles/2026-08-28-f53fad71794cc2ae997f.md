## 무엇이 있었나

오픈AI가 ‘챗GPT 워크’에 비밀번호로 보호된 웹사이트의 로그인 절차를 처리할 수 있는 기능을 추가했다. 인증이 필요한 시점에는 사용자가 별도 화면에서 아이디와 비밀번호, 보안 인증코드 등을 직접 입력하며, 해당 정보는 챗GPT 기반 모델에 전달되거나 학습에 사용되지 않는다고 설명했다.

로그인이 끝나면 챗GPT 워크가 유지된 세션을 이용해 예약, 환급 확인, 상품 주문과 반품, 여행 일정 취소, 청구서 입력, 인허가 신청서 작성 등의 후속 업무를 수행할 수 있다. 결제 제출이나 예약 확정처럼 영향이 크거나 되돌리기 어려운 단계에서는 사용자 확인을 받도록 설계됐다.

특정 시간뿐 아니라 지메일 메시지 수신, 슬랙 게시물 등록, 깃허브 풀 리퀘스트 활동 같은 이벤트를 조건으로 작업을 실행하는 기능도 확대됐다. 기사에 따르면 로그인 기능은 웹과 모바일의 플러스·프로·비즈니스 가입자에게 제공된다.

## 왜 중요한가

이번 변화는 생성형 AI의 역할이 정보 검색과 문서 작성에서 실제 웹서비스 조작으로 넓어지고 있음을 보여준다. 로그인 때문에 사람이 개입해야 했던 행정·회계·예약 등의 작업을 하나의 흐름으로 자동화할 수 있어, 국내 개인 사용자와 기업의 반복 업무 처리 방식에도 영향을 줄 가능성이 있다.

다만 AI가 계정에 접속해 행동하는 만큼 권한 범위와 세션 데이터 관리가 중요해진다. 사용자는 연결된 사이트의 브라우징 데이터를 개별적으로 삭제하거나 전체 초기화할 수 있으며, 중요한 최종 단계에서는 직접 승인하도록 통제권을 유지할 수 있다.

## 확인 범위

챗GPT 워크의 기능 구성, 인증 정보 처리 방식, 지원 사례와 제공 대상은 AI타임스가 전한 오픈AI 발표 내용을 기준으로 확인했다. 실제 서비스 환경에서의 보안 수준, 사이트별 호환성, 국내 계정에서의 제공 여부와 세부 이용 조건은 독립적으로 검증하지 않았다.
