## 무엇이 있었나

DeepSeek가 코딩 에이전트 실행 환경인 ‘DeepSeek Harness’를 오픈소스로 공개했다. 핵심은 모델 어댑터와 도구뿐 아니라 세션 로그, 에이전트 실행 루프, 파일시스템, 터미널, 샌드박스, 권한 승인, 하위 에이전트와 백그라운드 작업까지 플러그인으로 구성하는 구조다.

사용자는 고정된 코어를 직접 수정하는 대신 프로필과 번들을 조합해 필요한 기능을 추가하거나 기존 구현을 교체할 수 있다. DeepSeek 외에도 Anthropic·OpenAI 계열 모델과 Bedrock, Vertex AI, Azure, Codex, OpenAI 호환 엔드포인트 등을 연결할 수 있도록 설계됐다.

웹 UI와 헤드리스 실행 방식, Python SDK를 제공하며 세션은 추가 전용 이벤트 로그로 기록된다. 이 기록을 토대로 실행 과정 확인과 세션 재개·분기·재생 등이 가능하다. 프로젝트는 MIT 라이선스로 공개됐으며 현재 개발자 미리보기 단계다.

## 왜 중요한가

코딩 에이전트 경쟁의 초점이 모델 자체에서 모델을 실제 개발 업무에 연결하는 실행 환경으로 넓어지고 있음을 보여준다. 기업이나 개발팀은 자체 모델 게이트웨이, 보안 정책, 승인 절차와 개발 도구를 플러그인 단위로 결합할 수 있어 조직별 환경에 맞춘 에이전트를 구성하기가 쉬워질 수 있다.

실행 내역을 이벤트 단위로 남기는 방식도 주목할 부분이다. 에이전트가 어떤 입력을 받고 어떤 도구를 사용했는지 추적할 수 있어 디버깅과 감사, 작업 재현에 활용할 여지가 있다. 다만 플러그인 중심 구조는 확장성을 높이는 대신 구성 복잡도와 호환성 관리 부담을 키울 수 있다. 특히 초기 개발 단계인 만큼 실제 업무 도입 전에는 API 변경 가능성과 플러그인 안정성을 따져봐야 한다.
