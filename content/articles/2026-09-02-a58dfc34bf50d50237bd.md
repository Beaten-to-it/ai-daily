## 무엇이 있었나

모바일 GUI 에이전트를 실제 안드로이드 환경 대신 세계 모델로 훈련하는 강화학습 프레임워크 ‘WM-R1’이 arXiv에 공개됐다. 연구진은 학습 과정의 모든 롤아웃에서 세계 모델이 상태 전이를 생성하도록 설계해, 실제 환경과의 상호작용을 없앴다고 설명했다.

WM-R1은 에이전트가 최종 행동을 선택하기 전에 후보 행동의 결과를 세계 모델로 추론하도록 구성됐다. 과제 성공 여부뿐 아니라 경로의 효율성과 세계 모델 활용도까지 반영하는 규칙 기반 보상 체계도 적용했다. 연구진은 난도가 높은 과제 2,000개로 학습 데이터를 구성했으며, 안드로이드 모바일 벤치마크 실험에서 GRPO만 사용한 기준 모델과 추론 단계 시뮬레이션 방식보다 높은 성능을 기록했다고 보고했다. 코드도 공개됐다.

## 왜 중요한가

GUI 에이전트의 강화학습은 실제 기기를 반복해서 조작해야 해 비용이 크고 학습이 불안정해질 수 있다. 세계 모델이 실제 환경을 대신할 수 있다면 다수의 학습 경로를 병렬로 생성하고 개별 단계 단위로 세밀하게 훈련하는 길이 열린다.

한국의 모바일 서비스·앱 자동화 분야에서도 실제 단말 운영 부담을 줄이면서 에이전트를 학습시킬 가능성을 보여준다는 점에서 의미가 있다. 다만 세계 모델이 실제 앱의 화면 변화와 예외 상황을 얼마나 정확히 재현하는지가 현장 적용의 핵심 조건이 될 전망이다.

## 확인 범위

논문의 공개 메타데이터와 초록을 바탕으로 연구 목적, 학습 방식, 데이터 규모와 저자들이 보고한 성능 비교를 확인했다. 구체적인 벤치마크별 수치와 실험 조건, 세계 모델의 오류가 학습 결과에 미치는 영향, 실제 서비스 환경에서의 일반화 성능은 이 자료만으로 판단하지 않았다. 성능 우위는 연구진의 실험 결과이며 독립적인 재현 여부까지 확인된 것은 아니다.
