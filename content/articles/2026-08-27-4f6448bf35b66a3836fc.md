## 무엇이 있었나

여러 AI 코딩 에이전트가 하나의 프로젝트를 실시간으로 나눠 작업하도록 지원하는 협업 프로토콜 ‘에이전트룸(AgentRoom)’이 공개됐다. 에이전트룸은 CRDT로 병합되는 공유 파일 시스템 위에 파일 단위 작업 선점, 진행 상태 공유, 메시지 전파 기능을 MCP 도구로 제공한다.

연구진은 5개 고성능 코딩 CLI 모델을 대상으로 백엔드 개발 과제 4개를 수행하고, Python DevBench와 Rust·axum 환경에서 언어별 검증을 진행했다. 논문 초록에 따르면 CLI 동작이 안정적인 모델에서는 에이전트 2개를 투입한 구성이 단일 에이전트보다 과제 포기 사례와 실행별 결과 편차가 적었다. 같은 연산량으로 비교한 일부 평가에서도 단순 병렬 실행 후 병합하는 방식보다 나은 결과가 관찰됐다.

## 왜 중요한가

이번 연구는 AI 에이전트의 수를 늘리는 것만으로 개발 성과가 좋아지는 것은 아니며, 서로의 작업 범위와 진행 상황을 공유하는 조정 체계가 핵심이라는 점을 실험적으로 제시한다. 특히 여러 파일과 언어가 얽힌 실제 개발 환경에서는 중복 수정과 충돌을 줄이고, 한 에이전트가 중단한 작업을 다른 에이전트가 이어받을 수 있는 구조가 중요하다.

국내 개발 조직에도 시사점이 있다. 멀티에이전트 코딩 도구를 도입할 때 모델 성능이나 병렬 처리량뿐 아니라 파일 소유권, 상태 공유, 충돌 병합 방식까지 함께 설계해야 한다는 뜻이다. MCP와 CRDT를 결합한 접근은 향후 에이전트 기반 개발 환경을 평가하는 하나의 구현 사례가 될 수 있다.

## 확인 범위

이 기사는 arXiv에 공개된 논문 메타데이터와 초록에서 확인되는 연구 설계 및 결과를 바탕으로 작성했다. 실험은 5개 모델과 4개 백엔드 과제에 한정됐으며, 초록에는 모델별 수치나 전체 통계표가 제시되지 않았다. 따라서 모든 코딩 모델과 대규모 상용 프로젝트에서도 같은 효과가 나타난다고 일반화할 수는 없다. 논문은 v1 사전 공개본으로, 동료평가를 거친 최종 출판물은 아니다.
