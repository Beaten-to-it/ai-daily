## 무엇이 있었나

GeekNews는 Castform이 강화학습으로 후처리한 4B 규모 오픈 가중치 모델이 특정 기업 문서 검색 작업에서 GPT-5.6 Sol과 비슷하거나 더 높은 정확도를 기록하면서, 요청당 비용은 약 100분의 1로 낮췄다는 사례를 소개했다.

Castform은 기업이 보유한 문서와 제품 기록, 지원 자료 등에서 질문과 정답을 합성하고, 검색 도구 사용과 답변 정확성을 평가하는 보상 함수를 결합해 모델을 학습한다. 데이터 저장부터 학습 중 검색, 실제 추론까지는 Neon의 Postgres 기반 Lakebase Search 환경을 활용한다. 병렬 학습 과정에서 발생하는 검색 부하는 동적 확장으로 처리하고, 데이터를 변경하는 에이전트는 데이터베이스 브랜칭으로 실행 환경을 격리한다는 설명이다.

## 왜 중요한가

이번 사례는 모든 검색 요청을 고가의 범용 모델에 맡기는 대신, 반복적이고 범위가 분명한 업무에는 소형 특화 모델을 배치하는 방식이 비용과 지연 시간을 줄일 수 있음을 보여준다. 내부 규정 검색이나 고객 지원처럼 질의량이 많은 국내 기업에는 특히 의미가 있다.

다만 초기 학습 비용과 데이터 준비 작업이 필요하며, 문서 성격이 크게 바뀌었을 때 기존 검색 전략이 얼마나 잘 전이되는지도 살펴봐야 한다. 개인정보나 영업비밀을 다루는 조직이라면 외부 GPU·클라우드 사용에 따른 데이터 접근 위험과 실행 환경의 격리 수준도 함께 검토해야 한다.

## 확인 범위

Castform의 학습 구성, Neon 활용 방식과 비용·성능 수치는 GeekNews가 전달한 사례 설명에서 확인했다. 그러나 공통 공개 벤치마크에 기반한 독립 평가 결과나 전체 실행 조건, 모델별 속도는 제공된 자료만으로 충분히 검증되지 않는다. 따라서 ‘100배 저렴하다’거나 프런티어 모델을 능가한다는 표현은 모든 검색 업무에 일반화된 결론이 아니라 특정 데이터셋과 설정에서 나온 사업자 측 주장으로 봐야 한다.
