## 무엇이 있었나

알리바바 Qwen 연구진이 비전 기능을 갖춘 270억 매개변수 언어 모델 ‘Qwen 3.8 27B’를 아파치 2.0 라이선스로 공개했다. 사이먼 윌리슨은 약 17GB 크기의 Q4_K_M 양자화 모델을 128GB 메모리의 M5 Max 맥북 프로와 엔비디아 DGX Spark에서 시험했다.

이 모델은 추론 강도가 기본적으로 `xhigh`로 설정돼 있다. 윌리슨의 테스트에서는 간단한 SVG 생성 요청에도 추론 토큰을 지나치게 많이 사용해 응답 시간이 크게 늘거나, 요청하지 않은 요소까지 추가하는 문제가 나타났다. 자전거를 타는 펠리컨 SVG 생성에는 추론 토큰 2만2,276개가 쓰였고 21분이 걸렸다. 추론을 끈 같은 작업은 137초 만에 끝났다. 그는 처음 사용할 때 추론 강도를 `low`로 낮추거나 아예 끌 것을 권했다.

반면 복잡한 작업에서는 추론의 효용도 확인됐다. 모델은 사진 속 펠리컨 위치를 좌표 상자로 비교적 정확하게 표시했고, 해당 좌표를 이미지 위에 시각화하는 HTML 도구도 한 번의 요청으로 제작했다. 추론을 끈 상태에서 만든 도구는 좌표 위치가 어긋났다. 또한 로컬 환경에서 파일을 탐색하는 코딩 에이전트로 작동했으며, JSONL 대화 기록을 마크다운으로 바꾸는 파이썬 프로그램을 작성하고 테스트했다.

속도는 한계로 지적됐다. LM Studio에서는 초당 약 15~30토큰을 기록했다. 다만 llama.cpp의 다중 토큰 예측 기능을 이용한 저자의 비교에서는 기본 LM Studio 구성보다 처리 성능이 약 72% 향상됐다.

## 왜 중요한가

Qwen 3.8 27B는 장문 문맥 처리와 도구 호출, 이미지 이해, 코드 생성을 지원하는 범용 모델을 고성능 개인용 컴퓨터에서 로컬로 구동할 수 있음을 보여준다. 데이터가 외부 API로 전송되지 않는 환경을 구성하려는 국내 개발자와 조직에는 비용과 개인정보 보호 측면에서 주목할 만한 선택지가 될 수 있다.

다만 추론 강도를 높이면 항상 더 나은 결과가 나오는 것은 아니다. 간단한 업무에서는 지연과 연산 비용만 커질 수 있고, 코딩이나 도구 제작처럼 여러 단계를 점검해야 하는 작업에서는 일정 수준의 추론이 정확도를 높일 수 있다. 따라서 작업 성격에 맞춰 추론 수준과 실행 환경을 조정하는 운영 전략이 중요하다.

## 확인 범위

모델의 크기와 라이선스, 기능, 실행 속도 및 작업 결과는 윌리슨이 공개한 실험 기록을 바탕으로 정리했다. 성능 수치는 특정 양자화 파일과 하드웨어, 소프트웨어 구성에서 나온 결과이므로 다른 환경에 그대로 적용되지 않을 수 있다. Qwen이 공개한 벤치마크 향상치는 자체 측정 결과이며, 기사 작성 시점에는 독립 평가로 확인되지 않았다고 원문도 명시했다.
