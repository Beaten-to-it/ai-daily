## 무엇이 있었나

Anthropic이 파이썬 SDK 1.2.0을 공개했다. 이번 버전에서는 베타 파일·스킬 네임스페이스가 정식 API 형태를 사용하도록 변경됐으며, 날짜가 명시된 베타 헤더 고정값도 제거됐다.

AWS Bedrock 연동 시 바이너리 파일 업로드가 가능하도록 요청 원본 바이트를 서명하는 수정이 적용됐다. 에이전트 도구 모음과 메모리 도구가 줄바꿈을 변환하지 않고 파일 바이트를 그대로 보존하게 된 점도 주요 변화다.

이 밖에 새로운 이벤트 유형을 수용할 수 있도록 세션 이벤트 누적 처리의 호환성을 높였고, 크기 제한을 넘는 파일도 범위를 지정해 읽을 수 있게 했다. 웹훅 `unwrap()` 호출에는 헤더 전달이 필수로 바뀌었으며, 조직의 사용량 제한 목록 API에 관한 페이지네이션 문서도 보완됐다.

## 왜 중요한가

한국의 개발팀이 Anthropic API를 파일 처리나 에이전트 워크플로에 활용한다면, 바이너리 데이터와 파일 원본 보존의 안정성이 개선됐다는 점에 주목할 만하다. 특히 AWS Bedrock을 통해 Claude를 사용하는 환경에서는 바이너리 업로드 서명 문제가 수정돼 관련 장애 가능성을 줄일 수 있다.

다만 웹훅 처리 방식처럼 호출 조건이 달라진 부분도 있다. SDK를 올리기 전 기존 코드가 `unwrap()`에 헤더를 전달하는지 확인하고, 파일 처리 및 세션 이벤트 관련 회귀 테스트를 실행하는 편이 안전하다.

## 확인 범위

이 기사는 GitHub에 게시된 Anthropic 파이썬 SDK 1.2.0 릴리스 노트에서 명시적으로 확인되는 변경 사항을 바탕으로 작성했다. 각 변경의 세부 구현과 실제 운영 환경에서의 성능·안정성 개선 폭은 릴리스 노트만으로 확인되지 않는다.
