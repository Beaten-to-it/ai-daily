## 무엇이 있었나

AWS 프로페셔널 서비스가 Amazon Bedrock AgentCore와 Strands Agents SDK를 활용해 대규모 클라우드 이전을 지원하는 다중 에이전트 프레임워크를 공개했다. 이 프레임워크는 애플리케이션 현황 조사, 인프라 코드 생성, 이전 현황·거버넌스 관리, 이전 후 운영을 각각 담당하는 네 종류의 에이전트로 구성된다.

AWS가 소개한 사례에서는 300여 개 애플리케이션을 대상으로 애플리케이션당 3~4주 걸리던 인프라 코드 개발을 자동 생성 방식으로 수분까지 단축했다. 이 수치는 AWS의 내부 프로젝트 추적 자료에 근거한다.

각 에이전트는 AgentCore Gateway를 거쳐 필요한 도구와 연결되며, Identity와 IAM 역할을 통해 권한을 제한한다. 도구 호출에는 정책 검사가 적용되고, 실행 내역은 관측·감사 체계에 기록된다. 프로덕션 시스템에 영향을 주는 작업은 사람이 명시적으로 승인한 뒤 실행하도록 설계됐다.

## 왜 중요한가

국내 기업의 대규모 데이터센터 이전이나 레거시 현대화에서도 현황 조사와 반복적인 인프라 코드 작성, 규정 준수 확인은 일정과 인력을 많이 소모하는 작업이다. AWS 사례는 AI 에이전트를 단순 질의응답이 아니라 문서 분석부터 코드 생성, 정책 검사, 운영 모니터링까지 이어지는 업무 흐름에 적용한 사례라는 점에서 의미가 있다.

특히 조직이 승인한 인프라 패턴과 보안 기준을 재사용하면 이전 작업의 속도뿐 아니라 환경별 구성 일관성도 높일 수 있다. 다만 자동화 범위가 확대될수록 최소 권한, 실행 전 정책 검사, 감사 기록, 사람의 승인 절차를 함께 설계해야 한다는 점도 보여준다.

## 확인 범위

프레임워크의 구성, 적용 절차와 성과 수치는 AWS가 공개한 기술 글에서 확인했다. 개발 시간 단축과 300여 개 애플리케이션 적용 결과는 특정 프로젝트의 내부 추적 자료에 기반한 AWS 측 설명이며, 독립적인 제3자 검증 결과는 제시되지 않았다. 실제 효과는 애플리케이션 복잡도, 기존 인프라 표준화 수준, 보안 요구와 연동 도구에 따라 달라질 수 있다.
