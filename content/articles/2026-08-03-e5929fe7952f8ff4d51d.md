## 무엇이 있었나

터미널 기반 코드 리뷰 도구 ‘wiff’가 소개됐다. 이 도구는 Git 작업 트리와 인덱스, 커밋 이력의 변경 사항을 로컬 리뷰 세션으로 저장하고, 구문 강조가 적용된 화면에서 차이를 살펴보거나 주석을 남길 수 있게 한다.

사람은 터미널 사용자 인터페이스(TUI)를 이용하고, AI 에이전트는 명령줄 인터페이스와 스킬을 통해 같은 세션을 읽고 수정할 수 있다. 로컬 변경 사항 검토, GitHub 풀 리퀘스트 검토, 기존 코드 탐색 등 세 가지 방식이 제공된다. GitHub 풀 리퀘스트를 로컬 세션으로 가져온 뒤 리뷰 결과를 다시 게시하는 흐름도 지원한다.

리뷰 데이터는 사용자 컴퓨터에 저장되며, 작업 트리나 Git 이력의 변경 사항을 가져오는 기본 과정은 네트워크 연결 없이 진행할 수 있다. 세션 ID를 이용해 이전 리뷰를 이어가는 기능도 포함됐다.

## 왜 중요한가

개발 과정에 AI 에이전트를 도입할 때 사람과 에이전트가 서로 다른 화면이나 임시 메시지에 의견을 남기면 검토 맥락이 쉽게 흩어진다. wiff는 양쪽이 동일한 리뷰 세션과 주석을 공유하도록 설계해 이런 단절을 줄이는 데 초점을 맞췄다.

소스 코드를 외부 서비스로 보내기 어려운 국내 기업이나 보안 요구가 높은 개발 환경에서는 로컬 우선 방식도 의미가 있다. 동시에 GitHub 연동을 제공하므로, 내부 검토는 로컬에서 수행하고 필요한 결과만 기존 협업 흐름에 반영하는 방식으로 활용할 수 있다.

## 확인 범위

GeekNews에 게시된 도구 소개와 기능 요약을 기준으로 작성했다. 로컬 세션 저장, 사람과 에이전트의 공동 접근, 세 가지 리뷰 방식, GitHub 연동 및 오프라인 사용 가능성이 소개 내용에서 확인됐다. 다만 실제 환경에서의 성능과 보안 수준, 대규모 변경 사항 처리 능력, 편집기 및 `jj` 지원 여부는 이 자료만으로 확인되지 않았다. 댓글에 언급된 다른 도구와 사용 경험은 이용자 의견이므로 제품의 공식 기능으로 간주하지 않았다.
