## 무엇이 있었나

GitHub가 2026년 8월 배포된 VS Code 1.132~1.135의 GitHub Copilot 업데이트를 공개했다. 이번 업데이트는 에이전트 세션 관리와 대화 탐색, 변경 사항 검토, 통합 브라우저, 받아쓰기 기능을 중심으로 구성됐다.

Agents 창에서는 여러 채팅을 나란히 배치하고, 기본 대화가 실행되는 동안 같은 문맥을 공유하는 보조 대화를 `/btw` 명령으로 열 수 있다. 프롬프트 타임라인을 통한 대화·파일 변경 탐색, 외부 애플리케이션에서 만든 최근 Copilot 또는 Claude 세션 이어가기, 여러 VS Code 창에서 같은 세션 연결하기도 지원한다. Agent Plugins 1.0 표준을 따르는 휴대형 플러그인 설치 기능도 추가됐다.

Claude 세션에서는 Anthropic 구독과 Copilot 구독에서 제공되는 모델 사이를 전환할 수 있다. Claude API 키를 설정한 경우 GitHub 로그인 없이 Agents 창을 여는 실험적 설정도 제공된다. Copilot Agent Host에서는 다른 모델에 누락된 세부 사항이나 예외 상황을 검토하도록 요청하는 실험적 `/rubber-duck` 명령을 시험할 수 있다.

채팅에는 전체 대화 검색, 현재 프롬프트를 화면에 고정하는 스티키 스크롤, 모델별 입력·캐시 입력·출력 토큰 사용량 확인 기능이 들어갔다. 실험적 하이브리드 마크다운 편집기는 렌더링된 문서의 차이를 확인하면서 내용을 편집할 수 있게 한다.

통합 브라우저에서는 웹페이지의 여러 HTML 요소를 선택해 에이전트에 수정 의견을 전달할 수 있다. 로컬 HTML 파일은 디스크 변경 시 자동으로 다시 불러오며, 설정을 통해 통합 브라우저를 HTML 파일의 기본 편집기로 지정할 수 있다.

내장 받아쓰기는 온디바이스 모델을 이용한 다국어 입력과 언어 자동 감지를 지원한다. 사용자 또는 작업 공간 단위의 지침으로 프로젝트 용어와 서식을 반영할 수 있으며, 터미널에서는 셸 문법을 고려해 음성 입력을 정리한다.

## 왜 중요한가

이번 업데이트는 AI 코딩 도구의 활용 단위를 한 번의 질문과 답변에서 장시간 이어지는 작업 세션으로 넓힌다. 여러 에이전트 대화를 비교하고 다른 애플리케이션이나 VS Code 창에서 작업을 이어갈 수 있어, 긴 개발 작업의 문맥을 관리하기가 수월해질 수 있다.

전체 대화 검색과 프롬프트별 변경 탐색, 마크다운 차이 검토 기능은 에이전트가 만든 결과를 사람이 확인하는 과정에도 도움을 준다. 특히 한국어를 포함한 다국어 받아쓰기와 프로젝트별 정리 지침은 키보드 입력 외의 작업 방식을 활용하려는 국내 개발자에게 의미가 있다. 통합 브라우저의 요소별 피드백과 HTML 자동 새로고침은 웹 UI를 반복해서 수정하는 작업의 이동 비용을 줄일 수 있다.

## 확인 범위

GitHub가 공개한 2026년 8월 VS Code용 Copilot 변경 기록에서 기능과 적용 버전을 확인했다. 기사에 언급된 일부 기능은 실험 단계이거나 별도 설정을 활성화해야 하며, Claude 관련 기능은 API 키나 Anthropic·Copilot 구독 구성에 따라 이용 조건이 달라질 수 있다. 각 기능의 세부 지원 언어, 요금제별 제공 범위, 정식 기능 전환 일정은 해당 변경 기록만으로 확인되지 않는다.
