## 무엇이 있었나

Spotify가 사내에서 사용한 기술을 바탕으로 AI 코딩 환경 ‘Xirp’를 선보였다. macOS용 베타 앱인 Xirp는 Claude Code, Codex, Gemini 같은 기존 코딩 에이전트를 여러 프로젝트와 세션에 걸쳐 실행하고 관리한다. 각 에이전트의 CLI와 인증, 모델, 권한 설정은 그대로 유지한다.

Xirp는 작업별 Git worktree를 만들어 같은 저장소에서도 여러 에이전트가 서로의 작업 공간을 침범하지 않도록 지원한다. 앱을 종료한 뒤에도 터미널 세션을 이어갈 수 있으며, Git 변경 사항과 규칙 파일, 스킬, 세션 상태를 한 화면에서 관리할 수 있다.

Spotify의 개발자 포털 Portal과 연결하면 서비스 소유권, 의존성, 문서, 기술적 결정, 이전 작업 기록 등 조직 내부 정보를 에이전트가 활용할 수 있다. 모든 자료를 초기 프롬프트에 넣는 대신, 필요한 시점에 MCP를 통해 관련 정보를 조회하는 방식이다. Portal 연동은 선택 사항이며 Xirp만 별도로 사용할 수도 있다.

현재 베타는 Apple Silicon과 Intel 기반 Mac을 지원한다. 서버 배포와 SSH 기반 원격 세션은 아직 제공하지 않는다.

## 왜 중요한가

AI 코딩 도구의 성능은 코드 생성 능력뿐 아니라 조직의 맥락을 얼마나 정확히 찾고 활용하느냐에 좌우될 수 있다. 기술적으로 동작하는 코드라도 서비스 소유 관계나 과거의 설계 결정, 운영상의 제약을 알지 못하면 실제 환경에는 맞지 않을 수 있기 때문이다.

Xirp는 메신저, 위키, 오래된 문서와 구성원의 기억에 흩어진 지식을 필요할 때 검색해 에이전트에 전달하는 접근을 택했다. 작업 과정에서 새로 생긴 지식과 세션 기록을 이후 작업에 다시 활용하는 구조도 제시한다. 여러 AI 에이전트를 병렬로 사용하는 국내 개발 조직에는 작업 공간 격리와 조직 지식 재사용을 함께 다루는 사례라는 점에서 참고할 만하다.

## 확인 범위

이 기사는 제공된 GeekNews 게시물에서 확인되는 기능과 지원 범위를 바탕으로 작성했다. Xirp의 실제 성능, 보안 체계, 가격 정책, 정식 출시 일정과 기업 환경에서의 효과는 해당 자료만으로 확인되지 않는다. Portal에 연결되는 조직 정보의 구체적인 접근 통제와 데이터 처리 방식 역시 추가 확인이 필요하다.
