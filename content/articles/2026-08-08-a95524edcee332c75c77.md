## 무엇이 있었나

알리바바가 최대 30초 분량의 영상을 한 번에 만드는 AI 모델 ‘완(Wan) 3.0’을 퍼블릭 베타로 공개했다. 텍스트·이미지·음성·영상뿐 아니라 워드, 엑셀, 파워포인트, PDF, 애플 업무 문서와 웹페이지 등도 참고 자료로 활용할 수 있다. 기업이 기존 제품 소개서나 교육 자료, 판매 데이터를 입력해 설명·홍보 영상 제작에 활용하는 방식이다.

완 3.0은 알리바바 클라우드 API 기반 유료 서비스로 제공된다. 기사에 따르면 요금은 생성 영상 1초당 480p 0.05달러, 720p 0.10달러, 1080p 0.20달러다. 30초 영상 기준으로는 각각 1.5달러, 3달러, 6달러가 든다. 퍼블릭 베타에는 동시 작업과 요청 횟수 등에 제한이 적용된다.

## 왜 중요한가

업무 문서를 곧바로 영상 제작의 입력 자료로 사용할 수 있다는 점은 국내 기업의 마케팅, 영업, 교육 콘텐츠 제작 과정에도 영향을 줄 수 있다. 별도의 영상용 프롬프트나 시각 자료를 처음부터 준비하는 부담을 줄이고, 사내에 이미 축적된 자료를 콘텐츠로 전환할 가능성을 보여준다.

또한 오픈소스 모델 중심이었던 완 시리즈가 클라우드 API 과금 방식으로 이동했다는 점도 주목할 만하다. 기업 입장에서는 자체 인프라 없이 모델을 도입하기 쉬워지는 대신, 사용량에 따른 비용과 외부 클라우드로 전송되는 문서의 보안·개인정보 처리 조건을 함께 검토해야 한다.

## 확인 범위

공개 시점, 지원 입력 형식, 최대 생성 길이, API 요금과 베타 이용 제한은 AI타임스 보도를 기준으로 확인했다. 영상의 인물·제품 일관성, 음성 동기화, 렌더링 품질 등에 관한 내용은 알리바바 측 설명에 기반한다. 문서 이해 정확도와 수치 처리 성능, 긴 영상의 일관성을 입증할 정량 평가 결과는 기사 기준으로 공개되지 않아 실제 성능을 독립적으로 판단하기는 어렵다.
