## 무엇이 있었나

GitHub가 기업 관리형 설정에서 원하는 GitHub Copilot 모델을 새 대화의 기본값으로 지정하는 기능을 정식 제공한다. 기업 전체에 하나의 기본 모델을 적용하거나, 소속 팀에 따라 서로 다른 모델을 배정할 수 있다.

팀별 선택을 허용하려면 관리자가 모델 설정을 재정의할 수 있도록 지정하고 `team-mappings.json`의 팀 구성 파일을 수정해야 한다. 별도 팀 설정이 없는 사용자는 기업 기본값을 상속한다.

이 기능은 Copilot Business와 Copilot Enterprise에서 이용할 수 있으며, GitHub Copilot 앱과 Copilot CLI, Visual Studio Code에 적용된다.

## 왜 중요한가

기업은 개발 조직마다 업무 성격과 선호 모델이 다른 상황에서도 기본 사용 환경을 중앙에서 관리할 수 있다. 예를 들어 팀별 개발 과정에 맞는 모델을 미리 지정하면서, 별도 구성이 필요하지 않은 구성원에게는 공통 정책을 유지할 수 있다.

국내 기업의 AI 개발 도구 운영 측면에서는 조직 표준화와 팀별 자율성을 함께 다룰 수 있는 관리 수단이 늘었다는 의미가 있다. 다만 이번 발표만으로는 모델별 비용, 데이터 처리 정책, 접근 권한까지 자동으로 최적화된다고 볼 수 없으므로 기존 기업 정책과 함께 검토해야 한다.
