## 무엇이 있었나

GitHub가 JetBrains용 GitHub Copilot 플러그인에 기업 관리 설정을 도입했다. 기업 관리자는 조직의 Copilot 이용자를 대상으로 플러그인과 마켓플레이스, MCP 서버 접속, OpenTelemetry 구성, 에이전트 권한 모드를 일관되게 통제할 수 있다.

플러그인은 활성화 여부를 지정하고 승인된 추가 마켓플레이스를 제공하거나, 설치 가능한 출처를 제한할 수 있다. MCP 서버는 허용·차단 목록으로 관리한다. OpenTelemetry에서는 수집기 주소와 프로토콜, 서비스 이름, 리소스 속성, 콘텐츠 수집 정책 등을 중앙에서 설정할 수 있으며, 관리자가 지정한 값이 개발자의 개별 설정보다 우선한다.

관리자는 `permissions.disableBypassPermissionsMode` 설정을 통해 JetBrains의 Copilot 에이전트가 Bypass Approvals 또는 Autopilot을 사용하지 못하도록 제한할 수도 있다.

## 왜 중요한가

JetBrains IDE를 표준 개발 환경으로 쓰는 한국 기업에는 Copilot 운영 정책을 개발자 개인 설정에 맡기지 않고 조직 차원에서 적용할 수 있다는 의미가 있다. 특히 외부 MCP 서버 연결과 플러그인 공급처를 제한하면 승인되지 않은 도구나 서버가 개발 환경에 연결되는 것을 통제하는 데 도움이 된다.

텔레메트리 전송 대상과 수집 정책도 중앙에서 맞출 수 있어 보안·감사 기준을 적용하기 쉬워진다. 에이전트의 승인 우회 관련 모드를 차단하는 기능은 자동화 수준을 조직의 위험 관리 원칙에 맞추는 수단이 될 수 있다.

## 확인 범위

GitHub Changelog가 2026년 8월 18일 공개한 발표에서 기능 제공 사실과 지원 설정 항목을 확인했다. 실제 적용에 필요한 플러그인 버전, 세부 설정 절차, 요금제별 지원 범위와 각 설정의 기본값은 제공된 자료만으로 확인하지 않았다. 도입 전에는 GitHub의 기업 관리 설정 참조 문서와 조직의 현재 Copilot 구성을 함께 확인할 필요가 있다.
