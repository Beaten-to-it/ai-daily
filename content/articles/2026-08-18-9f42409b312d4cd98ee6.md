## 무엇이 있었나

연구진이 실행 결과를 학습 신호로 활용해 비주류 프로그래밍 언어 간 코드 번역을 개선하는 강화학습 방법을 공개했다. 먼저 검증 가능한 파이썬 프로그램을 여러 언어로 확장하고, 실제 실행에 성공한 코드로 다국어 학습 데이터를 구성했다. 이후 언어 모델이 만든 번역 후보를 실행 결과에 따라 평가해 보상 모델을 학습하고, 이를 기반으로 25개 언어 사이의 600개 방향별 번역 조합을 GRPO 방식으로 최적화했다.

연구진은 평가를 위해 HumanEval-X의 언어 범위를 확장한 실행 기반 벤치마크 ‘HumanEval-X++’도 제안했다. Qwen-3.5 4B와 9B 모델을 대상으로 실험한 결과, 학습하지 않은 기준 모델보다 여러 벤치마크에서 일관된 성능 향상이 나타났다고 보고했다. 특히 4B 모델은 HumanEval-X++ 전체 언어 평균에서 13%, 중간 수준 언어군에서 21% 개선됐다고 밝혔다.

## 왜 중요한가

기존 신경망 기반 코드 번역은 C++, 자바, 파이썬처럼 학습 자료가 풍부한 언어에 집중돼 있었다. 이번 연구는 병렬 데이터가 부족한 언어에서도 코드가 그럴듯해 보이는지만 평가하지 않고, 실제 실행 동작이 유지되는지를 학습과 검증의 기준으로 삼았다는 데 의미가 있다.

국내 개발 환경에서도 오래된 시스템의 언어 전환, 다국어 소프트웨어 유지보수, 상대적으로 자료가 적은 언어를 포함한 코드 현대화에 응용 가능성이 있다. 다만 논문이 제시한 성능 향상이 실제 산업용 대규모 코드와 복잡한 의존성 환경에서도 이어지는지는 별도 검증이 필요하다.
