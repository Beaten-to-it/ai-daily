## 무엇이 있었나

LTX가 오픈 웨이트 기반 영상 생성 모델 ‘LTX-2.5’를 공개했다. 새 모델에는 빠른 생성 과정에서 발생하는 시각적 왜곡을 줄이기 위한 확산 비디오 디코더와 여러 장면의 인물·배경·음성을 일관되게 유지하는 네이티브 멀티샷 기능이 도입됐다.

LTX가 제시한 자체 벤치마크에서는 엔비디아 GB200 두 대로 오디오가 포함된 720p 영상 10초 분량을 6.8초 만에 생성했다. API 환경에서 1080p 10초 영상을 만드는 데에는 23.7초가 걸렸다고 밝혔다.

최소 16GB VRAM을 갖춘 엔비디아 RTX GPU에서도 실행할 수 있도록 최적화됐으며, 맥과 소비자용 PC를 통한 로컬 활용도 지원한다. 모델은 허깅페이스와 ComfyUI에서 이용할 수 있고 별도 클라우드 API도 제공된다.

다만 이용 조건상 모든 조직이 제한 없이 사용할 수 있는 것은 아니다. 연간 반복 매출 1,000만달러 이하 조직에는 무료지만 이를 넘는 기업에는 별도 라이선스가 필요하며, 특정 용도에 관한 제한도 있다.

## 왜 중요한가

영상 생성 AI를 자체 장비에서 구동할 수 있으면 기업과 창작자는 원본 데이터나 지식재산을 외부 서비스로 전송하지 않고 작업할 수 있다. 광고와 소셜미디어처럼 여러 변형 영상을 반복 제작하는 분야에서는 보유 GPU를 활용해 클라우드 사용료를 줄일 가능성도 있다.

멀티샷 일관성과 로컬 실행 성능이 실제 환경에서도 확인된다면 국내 영상 제작사와 광고·콘텐츠 팀의 사전 시각화 및 대량 제작 과정에 활용될 여지가 있다. 반면 상업적 도입 전에는 라이선스 조건과 사용 제한을 검토해야 한다.

## 확인 범위

LTX-2.5의 공개 기능, 지원 환경, 라이선스 조건과 성능 수치는 AI타임스 보도를 기준으로 확인했다. 생성 속도와 품질 비교 결과는 LTX가 자체 측정하거나 의뢰한 자료이므로 독립 벤치마크와 동일하게 볼 수 없다. 기사 작성 시점에는 아티피셜 애널리시스 영상 벤치마크에도 이 모델이 포함되지 않아 경쟁 모델 대비 실제 성능은 추가 검증이 필요하다.
