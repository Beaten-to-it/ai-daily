## 무엇이 있었나

딥시크가 베이징 시간 기준 8월 23일 0시부터 토요일과 일요일의 모든 API 사용량에 비성수기 요금을 적용하기로 했다. 이에 따라 주말에는 이용 시간과 관계없이 피크 시간대 할증이 붙지 않는다. 변경 전 발생한 사용료에는 기존 정책이 적용된다.

딥시크는 앞서 API 호출 증가에 따른 서버 부담을 관리하기 위해 평일 특정 시간대의 요금을 비성수기 대비 두 배로 책정하는 차등 요금제를 도입했다. 이번 조정은 그 체계를 유지하면서 주말에만 할증을 없앤 것이다.

## 왜 중요한가

실시간 처리가 필요하지 않은 배치 작업이나 대규모 데이터 처리, 모델 평가와 테스트를 주말로 옮길 수 있는 개발자와 기업은 API 비용을 줄일 여지가 생겼다. 한국 이용자는 베이징 시간과 한국 시간의 시차를 고려해 작업 일정을 구성해야 한다.

이번 개편은 단순한 가격 인하를 넘어 수요가 몰리는 시간대를 피해 작업을 분산하도록 유도하는 운영 정책이라는 점에서도 의미가 있다. 기업 입장에서는 모델 성능뿐 아니라 작업 시점에 따른 비용까지 API 운영 전략에 반영할 필요가 커졌다.

## 확인 범위

딥시크의 주말 요금 변경 시점과 적용 방식, 기존 시간대별 차등 요금제의 내용은 AI타임스 보도를 근거로 정리했다. 실제 청구액은 사용하는 모델과 토큰 종류, 이용 시점에 따라 달라질 수 있다. 기사에 언급된 다른 AI 기업의 가격 정책과 딥시크의 공식 요금표는 별도 출처로 교차 확인하지 않았다.
