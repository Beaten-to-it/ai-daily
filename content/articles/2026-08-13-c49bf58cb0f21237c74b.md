## 무엇이 있었나

AI 코드 편집기 커서가 실행 중인 웹 화면에서 요소를 선택하거나 여러 항목을 함께 지정하고, 화면 위에 표시를 그리거나 음성으로 설명해 에이전트에 코드 수정을 요청하는 디자인 모드를 소개했다.

요소를 선택하면 XPath와 컴포넌트 정보, 속성, 계산된 스타일, React Fiber 트리의 props 등이 화면 캡처와 함께 문맥으로 전달된다. 이를 통해 에이전트는 대상 코드뿐 아니라 주변 배치와 당시 화면 상태까지 참고할 수 있다.

여러 수정 요청을 앞선 작업이 끝나기 전에 보낼 수도 있다. 에이전트의 작업이 완료되면 실행 중인 앱에 변경 사항이 핫 리로드 방식으로 반영된다. 커서는 빠른 UI 수정 작업에 자사 모델인 Composer 2.5가 적합하다고 설명했다.

## 왜 중요한가

UI 수정은 텍스트만으로 위치와 관계를 설명하기 까다롭다. 디자인 모드는 사용자가 실제 화면을 직접 가리키며 의도를 전달하게 해 디자이너, 기획자, 프론트엔드 개발자와 AI 에이전트 사이의 해석 차이를 줄일 수 있다.

특히 여러 컴포넌트의 모양을 맞추거나 특정 영역의 밀도를 조정하는 등 공간적 맥락이 중요한 작업에서 유용하다. 한국의 제품 개발 조직에도 디자인 검토와 코드 수정 사이의 왕복 시간을 줄이고, 실행 화면을 중심으로 협업하는 방식이 확산될 가능성을 보여준다.

## 확인 범위

기능의 동작 방식과 기술적 문맥 구성은 커서 공식 블로그에 기재된 내용을 기준으로 확인했다. 다만 성능과 작업 속도에 관한 평가는 회사 측 설명이며, 독립적인 비교 결과는 제시되지 않았다.
