## 무엇이 있었나

OpenAI가 GPT-5.6 제품군을 활용해 AI 에이전트의 비용과 처리 효율을 개선하는 방법을 공개했다. 핵심은 모든 작업에 최상위 모델을 일괄 적용하는 대신, 난도와 처리량에 따라 Sol·Luna·Terra를 선택하고 추론 강도를 조절하는 방식이다.

OpenAI가 제시한 자체 평가에서 GPT-5.6 Luna는 검색형 벤치마크 BrowseComp에서 이전 상위 모델과 비슷한 성능을 더 낮은 비용으로 기록했다. ARC-AGI-3 평가에서는 추론 내용 유지와 대화 압축을 적용한 GPT-5.6 Sol의 점수가 기본 구성의 13.3%에서 38.3%로 상승했으며, 출력 토큰은 약 6분의 1 수준으로 줄었다.

Responses API에는 장기 작업을 위한 추론 상태 유지와 네이티브 압축, 여러 작업을 병렬로 처리하는 멀티 에이전트 기능, 도구 호출 결과를 자바스크립트로 가공하는 프로그래매틱 도구 호출 기능이 도입됐다. 프롬프트 캐시의 최소 유지 시간도 30분으로 늘어났다.

## 왜 중요한가

이번 발표는 AI 에이전트의 경쟁 기준이 단순한 모델 성능에서 실제 운영 비용과 지연시간, 장기 작업의 안정성으로 이동하고 있음을 보여준다. 반복적인 검색·추출·분류에는 소형 모델을 쓰고, 판단이 필요한 단계에만 더 강한 모델과 높은 추론 강도를 배치하면 서비스 비용을 낮출 여지가 있다.

한국의 스타트업과 개발 조직에도 모델 선택과 시스템 설계가 모델 자체만큼 중요해졌다는 의미가 있다. 특히 문서 처리, 금융·법률 조사, 코드 탐색처럼 도구 호출이 많고 입력 문맥이 긴 업무에서는 캐싱과 압축, 코드 기반 데이터 가공을 함께 적용하는 것이 비용 효율을 좌우할 수 있다.

## 확인 범위

GPT-5.6 제품군과 Responses API 기능, 벤치마크 수치 및 기업 적용 사례는 OpenAI가 공개한 기술 안내문을 기준으로 확인했다. 성능과 비용 수치는 특정 평가 구성 또는 참여 기업의 사례이므로 모든 환경에서 동일하게 재현된다고 볼 수 없다. 독립 기관의 비교 검증 결과나 세부 가격 조건, 개별 서비스의 전체 운영비는 이 자료만으로 확인되지 않는다.
