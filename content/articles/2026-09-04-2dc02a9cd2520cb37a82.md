## 무엇이 있었나

LangChain 프로젝트가 2026년 9월 3일 `langchain==1.4.0`을 공개했다. 이번 버전에는 `langchain.mcp` 네임스페이스와 `MCPAdapter`가 추가됐으며, 실행 가능한 MCP 예제 문서도 함께 보강됐다.

에이전트가 도구를 배정하는 과정에서 모델 목적지가 포함되도록 라우팅 로직을 수정했다. Anthropic 및 LangChain 미들웨어의 추적 입력을 생략하는 성능 개선과 테스트 의존성인 `vcrpy`의 최소 버전을 8.2.0 이상으로 올리는 변경도 포함됐다.

## 왜 중요한가

이번 릴리스는 LangChain 애플리케이션에서 MCP 관련 기능을 다루기 위한 공식 진입점을 제공한다는 점에서 주목할 만하다. 한국의 AI 서비스 개발팀도 MCP 기반 도구 연동을 검토할 때 새 네임스페이스와 어댑터를 활용할 수 있다.

모델 목적지를 반영하도록 에이전트 도구 라우팅을 고친 부분은 여러 모델이나 도구를 조합하는 시스템의 동작 정확성과 관련된 변경이다. 다만 실제 개선 효과와 기존 코드에 미치는 영향은 각 프로젝트의 구성에 따라 별도 검증이 필요하다.

## 확인 범위

GitHub에 게시된 LangChain 1.4.0 릴리스 항목과 그 변경 목록을 기준으로 확인했다. 릴리스 태그, 공개 시각, 서명 검증 표시, 포함된 변경 항목은 확인됐지만 각 변경의 내부 구현, 성능 향상 폭, 호환성 영향까지는 제공된 릴리스 정보만으로 판단하지 않았다.
