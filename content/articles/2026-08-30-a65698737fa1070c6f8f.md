## 무엇이 있었나

OpenAI가 파이썬 SDK `openai-python` 3.6.0 버전을 공개했다. 이번 버전에는 Responses API와 Chat Completions API의 사용량 정보에 `compute_units` 항목을 추가하는 기능 변경이 포함됐다.

인증 부문에서는 X.509 워크로드 아이덴티티 연동을 강화하는 버그 수정이 이뤄졌다. 이 밖에도 타입 검사 도구와 개발 의존성, GitHub Actions 구성 요소, 파이썬 패키지 배포 도구 등의 버전이 갱신됐다.

## 왜 중요한가

`compute_units`가 사용량 데이터에 포함되면서 해당 API를 운영하는 개발자는 SDK가 제공하는 응답을 통해 컴퓨팅 자원 관련 지표를 다룰 수 있게 됐다. 다만 이 값의 정의와 산정 방식, 과금과의 관계는 이번 릴리스 안내만으로 확인되지 않는다.

X.509 워크로드 아이덴티티 연동 강화는 인증서를 기반으로 서비스 간 인증을 구성한 환경과 관련된 변경이다. 해당 방식을 사용하는 한국 기업과 개발팀은 SDK를 갱신하기 전에 기존 인증 흐름에 미치는 영향을 점검할 필요가 있다.

## 확인 범위

GitHub에 게시된 3.6.0 릴리스 안내에서 기능 추가 1건, 인증 관련 수정 1건과 의존성·빌드 도구 갱신 내역을 확인했다. 릴리스 페이지에는 변경 항목과 관련 풀 리퀘스트가 제시돼 있지만, `compute_units`의 세부 의미나 X.509 수정의 구체적인 영향 범위까지는 설명돼 있지 않다.
