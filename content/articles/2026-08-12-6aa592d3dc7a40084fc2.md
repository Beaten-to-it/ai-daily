## 무엇이 있었나

일본 건설 기술 스타트업 ONESTRUCTION이 AWS 생성형 AI 혁신센터의 기술 자문을 받아 건설 BIM 업무에 특화된 파운데이션 모델 ‘Ishigaki-IDS’를 개발했다. 이 모델은 자연어나 CSV로 작성한 지시를 BIM 정보 요구사항 표준인 IDS 형식으로 변환해, 비전문가도 속성 정보를 검토하고 관리할 수 있도록 설계됐다.

개발진은 Qwen3의 8B·14B·32B 모델을 기반으로 연속 사전학습, 지도 미세조정, 검증 가능한 보상을 활용한 강화학습을 차례로 적용했다. 공개 데이터가 부족한 문제는 도메인 전문가가 참여한 합성 데이터로 보완했으며, 강화학습 단계에서는 buildingSMART의 IDS-Audit-Tool을 이용해 XML 형식과 IDS 구조, 의미적 일관성을 검사했다.

학습에는 엔비디아 H200 GPU를 탑재한 Amazon EC2 P5en 인스턴스 2대와 AWS ParallelCluster, Amazon FSx for Lustre가 사용됐다. 자체 평가도구 IDS-Bench에서 XML 및 IDS 구조 준수율은 100%에 가까웠고, IDS 내용 일관성은 80%를 넘었다고 회사 측은 밝혔다. 약 12만 토큰 규모의 입출력도 처리할 수 있다고 설명했다.

## 왜 중요한가

이번 사례는 공개 데이터가 적고 출력 형식을 엄격하게 검증해야 하는 산업 분야에서 범용 모델을 특화하는 방법을 보여준다. 특히 전문가가 만든 합성 데이터와 자동 검증 도구를 결합하면 대규모 정답 데이터가 부족해도 모델의 구조적 오류를 줄이며 반복 학습할 수 있다는 점이 핵심이다.

한국에서도 BIM 도입 확대와 건설 인력 부족 대응이 중요한 과제로 꼽히는 만큼, 설계·시공·유지관리 정보를 표준 형식으로 다루는 업무에 특화 AI를 적용하는 방식은 참고할 만하다. 금융·의료·법률처럼 전문 용어와 정형 출력 규칙이 함께 요구되는 분야에도 유사한 개발 전략을 검토할 수 있다.

## 확인 범위

모델 구성, 학습 절차, AWS 인프라와 평가 수치는 ONESTRUCTION과 AWS가 공동 작성한 기술 사례에서 확인했다. 다만 IDS-Bench는 ONESTRUCTION 내부 전문가들이 만든 자체 벤치마크이며, 비교 대상인 범용 모델의 구체적인 명칭과 세부 평가 조건은 공개된 본문에서 확인되지 않는다. 성능 수치와 현장 활용성은 독립적인 외부 평가 결과가 아니라 개발사 측 보고로 해석해야 한다.
