## 무엇이 있었나

GitHub가 Slack용 GitHub 통합에 Copilot CLI와 Copilot 앱의 에이전트 기능을 추가하고 공개 미리보기로 제공한다. 사용자는 다이렉트 메시지나 채널, 스레드에서 `@GitHub`를 호출해 코드와 GitHub 활동에 관해 질문하거나 버그를 분류하고 이슈를 생성·수정할 수 있다.

Copilot은 허용된 GitHub 정보와 Slack 대화 내용을 바탕으로 장애를 조사하고, 보안이 적용된 클라우드 샌드박스에서 코드를 수정·검증한 뒤 풀 리퀘스트를 열 수 있다. 작업은 비동기로 이어지며 Slack에서 진행 방향을 조정한 뒤 터미널, Copilot 앱 또는 IDE에서 계속할 수 있다.

GitHub는 에이전트 작업 전용 채널인 ‘Slack Code’의 출시 파트너로도 참여했다. 팀원들은 전용 코드 채널에서 계획과 변경 내역, HTML 같은 결과물을 함께 살펴보고 에이전트 작업을 수정하거나 중단할 수 있다.

공개 미리보기는 GitHub Copilot Business와 Enterprise를 이용하는 조직에 제공된다. 관리자는 Copilot 클라우드 에이전트 정책을 활성화하고 Slack용 GitHub 앱을 설치하거나 업그레이드해야 한다. 에이전트가 만든 풀 리퀘스트에는 병합 전 추가 승인을 의무화할 수도 있다.

## 왜 중요한가

이번 통합은 개발 요청이 발생한 Slack 대화를 코드 작업의 출발점으로 직접 연결한다. 한국 기업과 개발 조직도 별도 도구로 맥락을 옮기는 과정을 줄이고, 이슈 처리부터 코드 수정과 리뷰 요청까지 팀이 공개된 대화 안에서 함께 추적할 수 있다.

특히 에이전트 세션이 팀에 공유되므로 특정 개발자와 AI 사이의 비공개 작업에 머물지 않는다. 기존 GitHub 권한과 통제 체계가 적용되고, 필요하면 에이전트 작성 풀 리퀘스트에 사람의 추가 승인을 요구할 수 있다는 점도 기업의 협업·컴플라이언스 운영에 의미가 있다.

## 확인 범위

GitHub가 2026년 8월 21일 공개한 변경 기록을 기준으로 기능, 대상 요금제, 초기 설정 조건과 권한 통제 방식을 확인했다. 현재 제공 단계는 정식 출시가 아닌 공개 미리보기다. 구체적인 지원 워크플로와 설정 조건은 조직 정책 및 후속 문서 변경에 따라 달라질 수 있다.
