## 무엇이 있었나

앤트로픽은 8월 20일 Claude 플랫폼의 컴퓨터 사용 도구와 Skills API, Files API를 정식 출시했다고 밝혔다. 웹페이지 구조를 읽고 특정 입력란이나 버튼을 조작하는 새로운 브라우저 사용 도구도 컴퓨터 사용 기능에 추가했다.

업데이트된 컴퓨터 사용 도구는 한 번의 모델 호출에서 여러 동작을 처리한다. Skills API는 업무 지침·스크립트·템플릿으로 구성된 기술 묶음을 업로드하고 버전별로 관리할 수 있게 한다. Files API는 에이전트가 읽거나 생성하는 문서를 저장하는 기능으로, 조직당 1TB 용량과 기존 대비 5배 높은 요청 한도, 파일 자동 만료 기능을 제공한다.

앤트로픽은 이 기능들을 결합하면 에이전트가 문서를 불러오고 조직의 업무 절차를 적용한 뒤, 별도 API가 없는 웹 시스템을 조작해 결과 파일까지 남기는 흐름을 구성할 수 있다고 설명했다. 컴퓨터 사용 기능은 앤트로픽과 사업자 간 계약인 BAA 아래에서 HIPAA 규제 대상 업무에도 사용할 수 있게 됐다.

Skills API와 Files API는 Microsoft Foundry에서도 제공된다. 업데이트된 컴퓨터 사용 및 브라우저 사용 도구는 Google Cloud Vertex AI에도 추후 도입될 예정이다.

## 왜 중요한가

이번 발표는 AI 에이전트의 역할이 답변 생성에서 실제 업무 수행으로 확대되고 있음을 보여준다. 특히 전용 API가 없거나 자동화가 어려운 보험·의료·금융 분야의 기존 시스템도 화면 조작 방식으로 연결할 수 있다는 점이 핵심이다.

국내 기업에는 사내 표준 절차를 스킬로 관리하고, 문서를 매번 다시 전송하지 않고 파일 ID로 재사용할 수 있다는 점이 실무적으로 의미가 있다. 업무 지침의 버전 관리와 결과물 저장을 하나의 플랫폼에서 처리할 수 있어 문서 중심 업무 자동화의 구축 부담을 줄일 가능성이 있다. 다만 화면 기반 자동화는 웹페이지 변경이나 예외 상황의 영향을 받을 수 있으므로, 실제 도입 때는 접근권한과 감사 기록, 실패 처리, 사람의 검토 절차를 함께 설계할 필요가 있다.

## 확인 범위

이 기사는 앤트로픽이 공개한 공식 제품 발표에서 정식 출시된 기능과 제공 범위를 확인해 정리했다. 구체적인 가격, 지역별 이용 가능 여부, 세부 보안 설정과 성능 한계는 제공된 발표문에 포함되지 않아 판단하지 않았다. 제품 효과와 규제 대상 업무 적용 범위는 앤트로픽의 설명을 기준으로 했으며, 개별 조직의 규제 준수나 실제 운영 성과를 독립적으로 검증한 것은 아니다.
