## 무엇이 있었나

Deepgram이 Amazon SageMaker AI에서 운영하는 음성·텍스트 변환 모델의 관측 기능을 강화했다. 새 기능은 크게 청구 및 사용량을 보여주는 ‘Deepgram Enhanced Metrics’와 엔진·GPU 상태를 추적하는 Prometheus 및 OpenTelemetry 지원으로 나뉜다.

Enhanced Metrics는 컨테이너 로그 경로를 이용해 AWS Marketplace 청구에 반영되는 사용 단위, 처리한 음성 길이, 합성한 문자 수 등을 Amazon CloudWatch로 보낸다. 별도의 에이전트나 사이드카, 추가 IAM 권한은 필요하지 않으며, 계정과 리전 단위로 모델·전송 방식·기능별 사용량을 확인할 수 있다. 다만 이 지표만으로 개별 엔드포인트나 인스턴스를 구분할 수는 없다.

더 세밀한 분석에는 SageMaker AI의 상세 관측 기능이 쓰인다. AWS 관리형 OpenTelemetry Collector가 Deepgram 컨테이너의 Prometheus 지표와 호스트·GPU 지표를 수집한다. 운영자는 엔드포인트와 인스턴스, GPU별 사용률을 살피고 활성 스트림 수와 엔진이 추정한 처리 용량을 비교할 수 있다. 새 엔드포인트에서는 상세 관측이 기본으로 활성화되며, 기존 엔드포인트는 구성을 갱신해야 한다.

## 왜 중요한가

자체 AWS 계정에서 음성 AI를 운영하는 기업은 데이터 통제력을 확보하는 대신, 실제 청구량과 모델 내부 부하를 파악하기 어렵다는 문제가 있었다. 이번 기능은 서비스 상태, 비용, 기능 사용량, GPU 포화도를 CloudWatch와 Prometheus 호환 도구에서 함께 분석할 수 있게 해 비용 예측과 증설 판단에 필요한 근거를 넓힌다.

한국 기업에도 데이터 소재지와 내부 통제가 중요한 금융·공공·고객센터 분야에서 의미가 있다. 다만 AWS 계정 안에서 모델을 운영한다는 사실만으로 규제 준수가 보장되는 것은 아니다. 기업별 보안 통제와 법적 의무를 별도로 검토해야 하며, 엔드포인트용 GPU 인스턴스와 CloudWatch 로그·지표 등 AWS 인프라 비용도 발생한다.

## 확인 범위

AWS가 2026년 8월 27일 공개한 기술 문서를 기준으로 기능 구성과 지표 수집 방식, 활성화 조건을 확인했다. 실제 비용 절감 폭이나 처리 성능 개선 수치는 제시되지 않았으며, 기능별 가용 범위와 비용은 배포 리전·엔드포인트 구성·사용량에 따라 달라질 수 있다.
