## 무엇이 있었나

GitHub가 Copilot 데스크톱 앱과 CLI, VS Code 1.132에 적용된 주간 업데이트를 공개했다. 이번 개편은 여러 작업을 동시에 다루고, 기존 흐름을 유지한 채 별도 질문이나 변경 작업을 진행하는 기능에 초점을 맞췄다.

Copilot 앱에서는 완료된 요청을 처리한 모델과 사용 가능한 경우 AI 크레딧·캐시 정보를 확인할 수 있다. 공유 세션으로 바로 이동하거나 `/side` 명령으로 기본 작업을 방해하지 않고 별도 질문을 탐색하는 기능도 추가됐다.

Copilot CLI에는 동시 세션을 관리하는 사이드바와 실험적 `/worktree` 명령이 도입됐다. 별도의 Git 작업 트리를 만들어 기존 작업 공간과 분리된 대화를 시작할 수 있다. Git 없이도 Copilot이 변경한 대화와 파일을 되돌리면서 이후 편집 내용은 보존하는 `/rewind`, 도구 호출 시간을 표시하는 기능도 포함됐다.

VS Code 1.132의 통합 브라우저에서는 웹페이지 요소를 여러 개 선택해 각각 의견을 달고 에이전트에 전달할 수 있다. 음성 받아쓰기는 기본적으로 기기 내 다국어 모델을 사용하며, 오디오는 장치에 남는다. `/btw`를 이용하면 진행 중인 에이전트 작업을 중단하지 않고 문맥을 공유하는 보조 대화를 열 수 있다. 마크다운 변경 사항은 편집 가능한 실험적 하이브리드 편집기에서도 검토할 수 있다.

## 왜 중요한가

이번 업데이트는 AI 코딩 도구를 단일 질의 창이 아니라 여러 작업을 병렬로 운영하는 개발 환경으로 확장하려는 흐름을 보여준다. 특히 세션 분리와 작업 트리 기능은 실험적인 수정이 현재 작업에 섞이는 위험을 줄이는 데 도움이 될 수 있다.

한국어를 포함한 다국어 음성 입력을 기기 내에서 처리하는 방식은 편의성과 함께 음성 데이터의 외부 전송 부담을 낮춘다는 의미가 있다. 웹 요소 단위 피드백과 문맥을 공유하는 보조 대화는 프런트엔드 검토나 긴 개발 작업에서 요구 사항을 더 구체적으로 전달하는 데 유용할 수 있다.

## 확인 범위

GitHub Changelog가 2026년 8월 7일 공개한 주간 릴리스 안내에서 Copilot 앱, Copilot CLI, VS Code 1.132의 기능을 확인했다. 일부 기능은 실험적으로 표시돼 있으며, 실제 제공 여부나 동작 범위는 사용 중인 제품 버전과 설정에 따라 달라질 수 있다. 성능 향상 폭이나 이용자 효과를 정량화할 수 있는 수치는 해당 안내에 제시되지 않았다.
