## 무엇이 있었나

DeepSeek가 추론형 오픈웨이트 모델 ‘DeepSeek V4 Flash 0731’을 공개했다. GeekNews가 소개한 Artificial Analysis 평가에 따르면, 이 모델은 Intelligence Index v4.1에서 최대 추론 설정 기준 50점을 기록했다.

모델은 전체 2,840억 개 파라미터 가운데 토큰마다 130억 개를 활성화하는 전문가 혼합(MoE) 구조다. 텍스트 입출력과 최대 100만 토큰의 문맥을 지원하지만 이미지 입력 기능은 없다. 가중치는 MIT 라이선스로 공개돼 자체 호스팅과 상업적 이용이 가능하다.

DeepSeek API의 100만 토큰당 가격은 입력 0.14달러, 출력 0.28달러, 캐시 적중 0.003달러로 소개됐다. 다만 평가에서 생성한 출력은 총 2억1,000만 토큰으로, 비교 대상 오픈웨이트 모델의 중앙값인 1억 토큰보다 많았다. 출력 속도는 기사 작성 시점에 공개되지 않았다.

## 왜 중요한가

저렴한 API 가격과 공개 가중치가 결합됐다는 점이 국내 개발자와 기업에 의미가 있다. 서비스 초기에는 API로 비용을 낮추고, 보안이나 운영 요건에 따라 자체 인프라로 이전하는 선택지를 검토할 수 있기 때문이다. 100만 토큰 문맥은 대규모 문서 검색과 분석을 수행하는 RAG 업무에도 활용 가능성을 제공한다.

다만 단가만으로 실제 비용 효율을 판단하기는 어렵다. 이 모델은 평가 과정에서 많은 출력 토큰을 사용했으므로, 긴 답변이 잦은 서비스에서는 낮은 토큰 가격의 이점이 일부 줄어들 수 있다. 응답 속도와 실제 업무별 정확도, 한국어 성능도 도입 전에 별도로 확인해야 한다.

## 확인 범위

모델 구조, 라이선스, 문맥 길이, API 단가와 벤치마크 결과는 제공된 GeekNews 기사에 기재된 내용을 기준으로 정리했다. Intelligence Index는 여러 평가를 결합한 종합 지표이므로 모든 실제 업무에서 같은 순위나 성능을 보장하지 않는다. 출력 속도는 확인되지 않았으며, 기사에 포함된 이용자 의견과 향후 모델 출시 전망은 검증된 사실에서 제외했다.
