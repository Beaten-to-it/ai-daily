## 무엇이 있었나

OpenAI가 8월 17일 파이썬 SDK `openai-python` 3.2.0을 공개했다. 이번 버전에는 Bedrock Runtime 엔드포인트 지원이 추가됐다. API 측면에서는 셸 호출 스트리밍 이벤트와 새로운 서비스·이미지 유형도 반영됐다.

릴리스 페이지에는 이 변경과 관련된 풀 리퀘스트 및 커밋이 함께 연결돼 있으며, 릴리스 커밋은 GitHub에서 서명이 검증된 상태로 표시된다.

## 왜 중요한가

파이썬 기반으로 OpenAI SDK를 사용하는 개발자는 새 버전에서 Bedrock Runtime 연동에 필요한 공식 지원 범위가 확대됐는지 검토할 수 있다. 셸 호출의 스트리밍 이벤트 추가는 실행 과정을 이벤트 단위로 처리하는 애플리케이션에 영향을 줄 수 있으며, 새 서비스·이미지 유형은 정적 타입 검사나 자체 데이터 모델을 사용하는 코드에서 확인이 필요하다.

국내 개발팀은 업그레이드에 앞서 기존 API 호출, 스트리밍 이벤트 처리 로직, 타입 의존 코드의 호환성을 테스트하는 것이 바람직하다.

## 확인 범위

GitHub의 공식 3.2.0 릴리스 페이지에 기재된 출시일과 기능 항목을 확인했다. 제공된 릴리스 요약에는 Bedrock Runtime 지원의 구체적인 설정 방법, 셸 호출 이벤트의 세부 스키마, 새 서비스·이미지 유형의 전체 목록은 포함돼 있지 않다. 따라서 지원 대상과 적용 방법에 관한 세부 사항은 연결된 변경 내역이나 SDK 문서를 추가로 확인해야 한다.
