## 무엇이 있었나

OpenAI가 7월 31일 공식 파이썬 SDK `openai-python` 2.52.0을 공개했다. 이번 버전에는 API의 콘텐츠 출처 확인 기능이 추가됐다.

클라이언트의 재시도 처리도 수정됐다. 서버가 `Retry-After`로 대기 시간을 지정하면 최대 2분까지 이를 따르도록 바뀌었다. API 키 기반 상호 TLS(mTLS) HTTP 클라이언트 구성법을 설명하는 문서도 추가됐다.

## 왜 중요한가

OpenAI API를 사용하는 국내 개발팀은 콘텐츠의 출처와 생성 이력을 확인하는 기능을 파이썬 애플리케이션에 연동할 수 있게 됐다. 다만 공개된 릴리스 설명만으로는 지원 대상과 적용 방법을 구체적으로 판단하기 어렵기 때문에 실제 도입 전 API 문서와 SDK 인터페이스를 함께 확인해야 한다.

재시도 정책 변경은 요청 제한이나 일시적인 서버 오류가 발생했을 때 서버가 제시한 대기 시간을 더 충실히 반영한다는 의미가 있다. mTLS 구성 예시는 상호 인증이 필요한 기업 환경에서 HTTP 클라이언트를 설정할 때 참고할 수 있다.

## 확인 범위

GitHub의 공식 2.52.0 릴리스 페이지에 명시된 기능 추가, 오류 수정, 문서 변경을 확인했다. 콘텐츠 출처 확인 기능의 세부 API, 지원 모델과 데이터 형식, 이전 버전과의 호환성은 해당 릴리스 요약에 제시되지 않아 확인 범위에 포함하지 않았다.
