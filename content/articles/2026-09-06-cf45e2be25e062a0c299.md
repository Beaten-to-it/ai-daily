## 무엇이 있었나
GitHub는 9월 4일 OpenAI의 GPT-6 Astra를 GitHub Copilot에 정식 제공한다고 발표했다. 대상은 Copilot Pro+, Max, Business, Enterprise 이용자이며, 배포는 순차적으로 진행된다.

지원 환경에는 Visual Studio Code와 Visual Studio, Copilot CLI·코딩 에이전트·앱, github.com, 모바일 앱, JetBrains IDE, Xcode, Eclipse가 포함된다. 이용자는 각 환경의 모델 선택 메뉴에서 GPT-6 Astra를 선택할 수 있다.

GitHub는 이 모델이 장시간 이어지는 자율 코딩과 에이전트 작업에 맞춰 설계됐다고 설명했다. 계획 수립과 검증을 병행하고 완료 선언 전에 결과를 확인하는 방식이 내부 테스트에서 두드러졌으며, 이전 OpenAI 모델보다 적은 단계로 장기 코딩 작업에서 더 나은 성능을 보였다는 평가다.

## 왜 중요한가
국내 개발팀도 기존 Copilot 작업 환경에서 새 모델을 활용할 선택지가 생겼다. 여러 단계에 걸친 코드 수정과 검증을 맡기는 팀이라면 실제 저장소에서 작업 완성도와 사용 비용을 함께 평가할 만하다.

과금은 사용량 기반으로 제공업체의 공시 가격을 적용한다. Business와 Enterprise 관리자는 Copilot 설정의 모델 정책으로 접근을 관리할 수 있다. 기본 모델 활성화 설정에서는 새 모델이 자동으로 켜지므로, 조직의 전역 기본 설정과 개별 모델 허용 여부를 확인할 필요가 있다.

## 확인 범위
이 기사는 제공된 GitHub 발표문을 근거로 작성했다. 지원 요금제와 환경, 순차 배포, 과금 원칙, 관리자 설정 방식은 발표문에서 확인된다. 개별 계정에서의 실제 이용 가능 여부와 구체적인 요금은 별도로 확인하지 않았다.

성능 설명은 GitHub의 내부 테스트 평가다. 제공된 자료에는 비교 모델별 수치나 상세 실험 조건이 없어, 성능 향상 폭과 실제 프로젝트에서의 효과를 판단하기에는 한계가 있다.
