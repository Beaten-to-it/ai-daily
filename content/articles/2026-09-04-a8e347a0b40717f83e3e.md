## 무엇이 있었나

연구진이 대규모 언어 모델의 ‘통계 문제 정의’ 능력을 평가하는 StatFormBench를 공개했다. 사용자의 비정형적인 목표와 여러 형태의 데이터가 주어졌을 때, 모델이 적절한 통계 과제를 파악하고 분석에 필요한 변수를 골라 역할을 정할 수 있는지 측정하는 벤치마크다.

StatFormBench는 통계 문제 분류와 변수 식별·역할 할당이라는 두 가지 하위 과제로 구성됐다. 연구진은 다섯 권의 여러 분야 통계 교재와 데이터 과학 사례 자료를 바탕으로 1,013개 문항을 구축했으며, 20개 상위 범주와 85개 세부 통계 문제 유형을 포함했다고 밝혔다.

공개형과 비공개형을 포함한 언어 모델 14개를 평가한 결과, 제로샷 조건에서 최고 성능은 세부 문제 분류 정확도 72.0, 변수 집합 중첩 점수 63.2로 나타났다. 두 과제에서 모두 일관되게 가장 뛰어난 모델은 없었고, 강화된 프롬프트 전략의 효과도 제한적이거나 일관되지 않았다는 것이 연구진의 설명이다.

## 왜 중요한가

데이터 분석에서는 계산이나 코드 작성에 앞서 무엇을 검증해야 하는지, 어떤 변수를 써야 하는지 정하는 단계가 중요하다. 문제를 잘못 정의하면 이후 분석이 정확해도 실제 질문과 동떨어진 결론에 이를 수 있다.

이번 연구는 언어 모델의 통계 역량을 이미 정리된 문제의 정답률만으로 평가하지 않고, 현실의 모호한 요구를 분석 가능한 문제로 바꾸는 초기 단계까지 확장했다는 데 의미가 있다. 한국의 기업·연구기관·공공 부문이 언어 모델을 데이터 분석 보조 도구로 도입할 때도 결과 생성 능력뿐 아니라 문제 유형과 변수 역할을 제대로 식별하는지 별도로 검증할 필요가 있음을 보여준다.
