## 무엇이 있었나

OpenAI가 파이썬 SDK `openai-python` 3.4.0을 공개했다. 이번 버전에는 스트리밍 응답 객체인 `ChatCompletionChunk`의 난독화 관련 필드와 프로젝트 데이터 레지던시 설정, 비용 수량 단위가 추가됐다.

버그 수정은 Realtime API와 Azure 연동, 전송 계층의 안정성과 보안 경계에 집중됐다. Realtime 통화 제안과 세션 설정의 인코딩을 보완했으며, 웹소켓 리디렉션의 출처 검사와 전송 대기열의 바이트 계산을 바로잡았다. Azure에서는 배포 이름 인코딩, 인증 방식 선택, 전송 방식이 달라질 때의 인증 경계 유지 문제가 수정됐다.

이 밖에도 TLS 호스트명 보존, SSE 이벤트의 점진적 디코딩, 진단 정보의 메타데이터 제한, 웹훅 서명 검증과 임베딩 응답 디코딩 로직 정리 등이 포함됐다. 이미지 생성 모델과 배경 처리에 관한 문서도 보완됐다.

## 왜 중요한가

OpenAI API를 파이썬 서비스에 연결한 국내 개발팀이라면 Realtime 통신과 Azure OpenAI 환경에서 발생할 수 있는 인코딩·인증·전송 문제의 개선 여부를 살펴볼 만하다. 특히 웹소켓 리디렉션 검사, TLS 호스트명 처리, Azure 인증 경계 보존은 서비스의 연결 신뢰성과 보안에 직접 닿는 변경이다.

다만 수정 항목이 많고 인증 및 네트워크 계층도 영향을 받는 만큼, 운영 환경에 바로 반영하기보다 기존 Azure 배포 이름, 인증 구성, 프록시·리디렉션, SSE 및 웹소켓 흐름을 중심으로 회귀 테스트를 거치는 편이 안전하다.

## 확인 범위

GitHub에 게시된 `openai-python` 3.4.0 공식 릴리스 노트에서 기능 추가, 버그 수정, 문서 및 리팩터링 항목을 확인했다. 각 변경의 구체적인 재현 조건과 실제 성능 영향, 기존 애플리케이션과의 호환성은 릴리스 요약만으로 판단할 수 없어 단정하지 않았다.
