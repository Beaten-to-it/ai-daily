## 무엇이 있었나

GitHub가 GitHub Copilot 앱의 ‘Customize’ 탭을 정식 제공한다고 발표했다. 이 탭은 MCP 서버와 플러그인, 스킬, 캔버스를 한곳에서 탐색할 수 있도록 구성됐다.

사용자는 추천 항목을 먼저 살펴보거나 유형별 전용 섹션에서 필요한 확장 기능을 찾을 수 있다. MCP 서버는 인기 항목과 카테고리를 기준으로 탐색할 수 있으며, 추천 캔버스를 통해 관련 맥락을 유지하면서 업무 파악에서 실행 단계로 넘어갈 수 있다. GitHub는 Azure DevOps의 이슈 분류, 백로그 우선순위 지정, 후속 작업 배정과 Copilot 위임 등을 활용 사례로 제시했다.

## 왜 중요한가

이번 변화는 팀이 사용하는 도구와 지식, 업무 흐름을 Copilot에 연결하는 진입점을 단순화했다는 데 의미가 있다. 특히 여러 확장 방식을 각각 찾아야 했던 사용자는 이제 하나의 화면에서 선택지를 비교하고 업무에 맞는 구성을 찾을 수 있다.

국내 개발팀에도 MCP 서버나 플러그인 등을 활용해 기존 협업 환경과 Copilot을 연결하는 과정의 탐색 부담을 줄여줄 수 있다. 다만 실제 도입 효과는 조직이 사용하는 서비스, 보안 정책, 관리 설정과 지원 범위에 따라 달라질 수 있다.

## 확인 범위

GitHub Changelog에 공개된 Customize 탭의 정식 제공 사실과 주요 탐색 기능, GitHub가 소개한 활용 사례를 확인했다. 요금제별 제공 범위, 조직 관리자의 통제 기능, 개별 사용자에 대한 배포 일정, 각 확장 항목의 별도 설치 조건은 제공된 내용에서 확인되지 않았다.
