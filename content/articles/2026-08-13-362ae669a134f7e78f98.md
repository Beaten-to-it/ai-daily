## 무엇이 있었나

xAI가 장시간 이어지는 에이전트 작업과 대화형·시각적 프로젝트 수행 능력을 강화한 AI 모델 ‘Grok 4.6’을 공개했다. 회사 설명에 따르면 새 모델은 Grok 4.5보다 긴 추가 학습을 거쳤으며, 모델이 생성한 추론·기술 데이터와 고품질 엔지니어링 데이터, 개선된 최적화 및 학습 방식을 활용했다.

사후학습 과정에서는 Grok 4.5로 지도 미세조정용 실행 궤적을 다시 만들고, 모델 기반 검사로 문제가 있는 기록을 걸러냈다. 강화학습 과제에는 일반 코딩과 지식 노동뿐 아니라 커널 최적화, 웹 개발, 컴퓨터 지원 설계 등이 포함됐다.

xAI가 공개한 평가에서 Grok 4.6은 여러 벤치마크를 종합한 Artificial Analysis Intelligence Index 61점을 기록했다. Grok 4.5보다 다수 평가에서 개선됐지만, DeepSWE와 Terminal-Bench 등 일부 항목에서는 비교 대상 모델보다 낮은 결과를 보였다.

모델은 Cursor, Grok Build, API 등에서 제공된다. 공개된 API 가격은 입력 100만 토큰당 2달러, 출력 100만 토큰당 6달러부터이며, 고속 변형은 두 배의 요금이 적용된다.

## 왜 중요한가

이번 발표는 모델의 파라미터 규모를 늘리는 것만이 아니라 데이터 선별, 실행 궤적 개선, 분야별 강화학습 같은 사후학습이 성능 경쟁의 핵심 수단으로 자리 잡고 있음을 보여준다.

한국의 개발자와 기업에는 장기 코딩 작업이나 제품 시제품 제작을 맡길 모델 선택지가 늘었다는 의미가 있다. 특히 반복적인 테스트와 검증을 포함하는 에이전트 성능이 실제 환경에서도 확인된다면, 애플리케이션 개발과 기술 조사 업무의 자동화 범위가 넓어질 수 있다. 다만 가격뿐 아니라 작업별 정확도, 도구 호환성, 보안 정책을 함께 비교할 필요가 있다.

## 확인 범위

모델 공개 사실과 학습 방식, 제공 경로, 가격, 평가 수치는 GeekNews가 정리한 xAI 발표 내용을 기준으로 확인했다. 벤치마크 결과는 xAI 및 각 개발사가 공개한 자료에 기반하므로 동일 조건의 독립 평가로 단정하기 어렵다. 장기 작업에서 자체 테스트와 검증 행동이 늘었다는 설명 역시 xAI의 관찰 결과이며, 실제 사용 환경에서의 성능은 별도 검증이 필요하다.

기반 모델의 정확한 파라미터 규모와 후속 모델 출시 일정, 발표 페이지에 표시된 조직 명칭의 의미는 제공된 자료만으로 확정하지 않았다.
