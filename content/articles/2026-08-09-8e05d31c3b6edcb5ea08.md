## 무엇이 있었나

여러 CLI 기반 코딩 에이전트를 병렬로 운용하는 오픈소스 에이전트 개발 환경(ADE) ‘Orca’가 소개됐다. Codex, Claude Code, OpenCode, Pi 등을 각기 분리된 Git 워크트리에서 실행하고, 진행 상황을 한 화면에서 추적하거나 여러 에이전트의 결과를 비교해 선택·병합할 수 있도록 설계된 도구다.

Orca는 데스크톱과 모바일 환경을 지원한다. 모바일 앱을 통한 원격 모니터링과 후속 지시, 터미널 화면 분할, Chromium 기반 UI 요소 선택, GitHub·Linear 연동, 원격 서버용 SSH 워크트리, AI가 만든 diff에 대한 주석과 재작업 요청 등의 기능이 소개됐다. MIT 라이선스로 공개됐으며 macOS, Windows, Linux와 iOS, Android, VPS 환경을 지원한다고 안내됐다.

## 왜 중요한가

코딩 에이전트를 여러 개 동시에 쓰면 작업 속도를 높이고 서로 다른 해법을 비교할 수 있지만, 작업 디렉터리 충돌과 세션 관리, 결과 검토·병합이 새로운 부담이 된다. Orca는 Git 워크트리를 이용한 격리와 통합된 모니터링·리뷰 기능으로 이런 운영 문제를 줄이는 데 초점을 맞춘다.

특히 특정 모델이나 API 사용권을 다시 판매하는 서비스가 아니라 사용자가 보유한 구독과 CLI 도구를 활용하는 방식이라는 점이 눈에 띈다. 국내 개발자에게도 Windows 지원, 원격 작업, 모바일 제어와 한글 IDE 관련 개선 여부 등이 실제 도입을 판단할 주요 요소가 될 수 있다.

## 확인 범위

이 기사는 GeekNews에 게시된 소개 내용과 해당 페이지에서 확인되는 기능 목록을 바탕으로 작성했다. 지원 플랫폼, 라이선스, 연동 기능은 게시물에서 확인했지만 각 기능의 안정성이나 성능, 보안성, 한국어 입력 호환성은 독립적으로 시험하지 않았다. 댓글에 언급된 모바일 입력 경험과 한글 IDE 문제는 개별 사용자의 경험이므로 제품 전반에 적용되는 검증된 평가로 보기는 어렵다.
