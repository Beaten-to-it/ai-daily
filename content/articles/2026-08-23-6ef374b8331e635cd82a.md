## 무엇이 있었나

GitHub가 마이크로소프트 팀즈에서 GitHub Copilot 클라우드 에이전트를 공동으로 운용하는 기능을 공개 미리보기로 제공한다. 팀즈의 채널과 대화 스레드, 다이렉트 메시지에서 `@GitHub`를 호출하면 참여자들이 같은 에이전트 세션을 보면서 질문하거나 맥락을 추가하고 작업 방향을 조정할 수 있다. 저장소 쓰기 권한이 있는 참여자는 Copilot에 코드 변경도 요청할 수 있다.

팀즈에서 시작한 작업은 보안이 적용된 클라우드 샌드박스에서 비동기로 진행된다. 사용자는 대화 스레드에서 진행 상황을 확인한 뒤 터미널, GitHub Copilot 앱 또는 IDE에서 에이전트가 만든 결과물을 이어서 다룰 수 있다.

공개 미리보기는 유료 GitHub Copilot 요금제에서 이용할 수 있다. 팀즈에서 시작한 클라우드 에이전트 세션은 AI 크레딧을 사용하며, 클라우드 샌드박스 이용료는 별도로 청구된다. 조직 환경에서는 관리자가 클라우드 에이전트와 샌드박스를 활성화해야 한다.

GitHub는 관리 통제 기능도 추가했다. 저장소 관리자는 마이크로소프트 팀즈의 Copilot 통합 계정이 만든 풀 리퀘스트에 별도의 승인을 요구할 수 있다. 기존에 승인 두 건이 필요한 저장소에서 이 설정을 켜면 Copilot이 만든 풀 리퀘스트에는 세 건의 승인이 필요하다.

## 왜 중요한가

이번 기능은 회의나 팀 대화에서 결정된 개발 작업을 별도의 전달 과정 없이 곧바로 조사와 구현 단계로 넘길 수 있게 한다. 특히 여러 사람이 에이전트의 진행 과정을 함께 보고 맥락과 지시를 보탤 수 있어, 개인 중심이던 AI 코딩 도구 사용을 팀 단위 협업으로 확장한다는 의미가 있다.

국내 기업과 개발 조직에는 업무 속도뿐 아니라 권한·비용·승인 정책을 함께 검토해야 한다는 점도 중요하다. 에이전트가 코드를 변경하려면 저장소 쓰기 권한이 필요하고, AI 크레딧과 샌드박스 비용이 각각 관리된다. 추가 승인 기능은 AI가 만든 변경 사항을 사람이 검토한 뒤 병합하도록 통제하는 수단이 될 수 있다.

## 확인 범위

GitHub Changelog가 공개한 기능 설명과 이용 조건, 비용 및 승인 정책을 확인했다. 공개 미리보기 단계이므로 향후 정식 출시 과정에서 지원 범위나 과금 방식, 세부 동작이 달라질 가능성이 있다. 실제 조직별 사용 가능 여부와 설정 방법은 관리자 정책 및 최신 GitHub 문서를 추가로 확인해야 한다.
