## 무엇이 있었나

Moonshot AI가 터미널에서 작동하는 오픈소스 코딩 에이전트 ‘Kimi Code CLI’를 공개했다. 이 도구는 코드를 읽고 수정하는 작업을 비롯해 셸 명령 실행, 파일 검색, 웹페이지 조회를 수행하며, 작업 결과에 따라 후속 단계를 선택한다.

Kimi 모델뿐 아니라 호환되는 다른 모델 제공자도 설정할 수 있다. macOS·리눅스·윈도우를 지원하고 Node.js 없이 실행되며, 윈도우에서는 Git Bash를 셸 환경으로 사용한다. 영상 입력, 대화형 MCP 서버 설정, 스킬과 데이터 소스 설치, 신뢰 수준 표시 기능도 제공한다.

별도 컨텍스트에서 병렬로 실행되는 내장 서브에이전트와 생명주기 훅을 지원하며, Agent Client Protocol을 통해 Zed와 JetBrains 계열 등 호환 IDE에서도 같은 에이전트 세션을 사용할 수 있다. 라이선스는 MIT다.

## 왜 중요한가

Kimi Code CLI는 코딩 에이전트의 활용 범위를 터미널에만 한정하지 않고 MCP 기반 외부 도구, 서브에이전트, IDE 연동까지 확장했다는 점에서 주목할 만하다. 특정 모델에 완전히 종속되지 않는 구성도 조직이나 개발자가 비용, 성능, 내부 정책에 맞춰 모델을 선택하는 데 유리할 수 있다.

특히 영상으로 UI 동작이나 데모를 전달하는 기능은 텍스트 중심이던 개발 지시 방식을 넓힐 가능성이 있다. 한편 도구 호출 차단용 훅과 설치 항목의 신뢰 수준 표시는 코딩 에이전트가 로컬 명령과 외부 시스템에 접근할 때 필요한 통제 장치를 제공한다.

## 확인 범위

이 기사는 GeekNews에 정리된 공개 내용에 근거했다. 지원 운영체제, 모델 제공자 호환, 영상 입력, MCP 설정, 서브에이전트, 생명주기 훅, ACP 연동 및 MIT 라이선스 여부를 확인 범위에 포함했다. 실제 성능과 안정성, 다른 모델 제공자와의 구체적인 호환 범위, 영상 기반 작업의 정확도, 보안 통제의 효과는 제시된 정보만으로 판단하지 않았다.
