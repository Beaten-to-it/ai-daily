## 무엇이 있었나

Anthropic이 Claude 웹·모바일 앱에 적용되는 핵심 시스템 프롬프트의 모델별 변경 이력을 공개했다. 시스템 프롬프트는 대화가 시작될 때 현재 날짜와 응답 지침 등을 모델에 전달하며, 코드 표시 방식과 같은 Claude의 행동에도 영향을 준다.

공개 대상은 Claude 3 계열부터 Claude Opus 5까지다. 같은 모델에 여러 버전이 존재하면 달라진 부분을 구분해 보여준다. 다만 Claude API에는 이 변경 사항이 적용되지 않으며, Claude 4.6 세대 이후에는 모델 ID가 하나의 고정 스냅샷을 가리켜 모델별 항목도 하나만 제공된다.

## 왜 중요한가

같은 기반 모델이라도 서비스가 제공하는 시스템 프롬프트에 따라 답변의 형식, 길이, 안전 판단과 도구 사용 방식이 달라질 수 있다. 따라서 Claude 앱에서 관찰한 동작을 API의 특성으로 그대로 일반화해서는 안 된다.

국내 개발자와 AI 서비스 운영자에게 이번 공개는 모델 자체의 성능과 서비스 계층의 지침이 결과에 각각 어떤 영향을 주는지 살펴볼 참고 자료다. 시스템 프롬프트 변경을 추적하면 동일 모델의 체감 동작이 시점에 따라 달라지는 이유를 분석하는 데도 도움이 된다.

## 확인 범위

GeekNews에 정리된 변경 이력의 적용 대상, 역할, 표시 방식과 API 미적용 사실을 확인했다. 입력에는 개별 시스템 프롬프트 전문이 포함되지 않아 구체적인 문구별 변화는 검증하지 않았다. 댓글에 제시된 성능 저하, 프롬프트 규모와 모델 행동의 관계 등에 관한 견해는 확인된 사실로 다루지 않았다.
