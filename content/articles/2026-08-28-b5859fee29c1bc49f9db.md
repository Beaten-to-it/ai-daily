## 무엇이 있었나

로컬 환경에서 대규모 언어 모델을 실행하는 오픈소스 도구 Ollama가 0.33.1 버전을 공개했다. 이번 릴리스에는 MLX 기반 Qwen3.8 Flash Next 지원과 MLX·llama.cpp 업데이트가 포함됐다.

MLX 실행기에는 구조화된 출력 기능이 추가됐다. 속도가 느린 저장장치에서 모델을 불러올 때 Metal GPU 시간 초과가 발생하지 않도록 하는 개선도 반영됐다. 외부 호환성 패치를 반복 적용해도 같은 결과를 유지하도록 CMake 관련 처리도 수정됐다.

## 왜 중요한가

이번 업데이트는 Apple 실리콘 기반 Mac에서 MLX를 활용해 모델을 구동하는 개발자에게 직접적인 의미가 있다. 구조화된 출력 지원은 모델 응답을 일정한 형식으로 받아 애플리케이션이나 자동화 도구에 연결하는 작업을 수월하게 할 수 있다.

느린 저장장치에서 모델을 로딩할 때 발생할 수 있는 GPU 시간 초과 문제를 완화한 점도 대용량 모델의 로컬 운용 안정성과 관련된다. 다만 실제 성능과 안정성 향상 폭은 사용 중인 하드웨어, 모델, 저장장치 구성에 따라 달라질 수 있다.

## 확인 범위

Ollama의 GitHub 0.33.1 릴리스 페이지에 기재된 변경 사항을 확인했다. 해당 페이지는 기능 추가와 수정 항목을 요약하지만, 성능 비교 수치나 지원 하드웨어의 세부 범위, 개별 변경 사항의 구현 내용까지 제공하지는 않는다. 따라서 구체적인 성능 향상이나 모든 환경에서의 문제 해결 여부는 확인되지 않았다.
