## 무엇이 있었나

Qwen이 차세대 Qwen4에 적용할 설계를 미리 선보이는 멀티모달 혼합전문가(MoE) 모델 ‘Qwen3.8-Flash-Next’를 공개했다. 모델 본체는 1,250억 개 매개변수와 별도의 510억 개 N-gram 임베딩으로 구성되지만, 토큰을 처리할 때 활성화되는 매개변수는 60억 개다.

새 모델은 과거 정보를 고정 크기 상태로 압축하는 Gated DeltaNet과 필요한 문맥 영역을 블록 단위로 찾는 Qwen Sparse Attention을 결합했다. Qwen이 공개한 측정 결과에 따르면 100만 토큰 조건에서 어텐션 커널의 사전 채우기와 디코딩 속도가 각각 최대 7.6배와 4.9배 향상됐다.

또한 네 개의 병렬 잔차 경로, 호스트 메모리로 옮길 수 있는 N-gram 임베딩, Muon 기반 최적화 방식을 도입했다. Qwen 측은 Qwen3.7-Plus 대비 훈련 비용을 약 9분의 1로 줄이면서 코딩과 사무 작업 성능을 개선했다고 밝혔다. 기본 문맥 길이는 26만2,144토큰이며 YaRN을 이용하면 최대 100만 토큰까지 확장할 수 있다.

가중치는 Hugging Face와 ModelScope에 공개됐다. 관리형 서비스인 QwenCloud에서는 `qwen3.8-flash`라는 이름으로 제공되며, 입력과 출력 100만 토큰당 가격은 각각 0.16달러와 0.47달러로 제시됐다.

## 왜 중요한가

이번 발표의 핵심은 모델 전체 규모를 키우면서도 실제 추론에 필요한 계산량과 메모리 부담을 낮추려는 시도다. 장문 문맥 처리 비용이 줄어들면 대규모 코드 저장소 분석, 긴 문서 기반 업무 자동화, 여러 도구를 연속으로 사용하는 AI 에이전트 같은 작업에 적용하기 쉬워진다.

오픈 가중치와 여러 API 호환 인터페이스를 함께 제공한다는 점도 국내 개발자에게 의미가 있다. 기존 OpenAI 또는 Anthropic 방식으로 구성된 개발 도구에서 연동 가능성을 검토할 수 있고, 공개 모델을 직접 평가해 비용과 성능의 균형을 비교할 수 있기 때문이다.

다만 공개 벤치마크에는 실행 도구, 문맥 길이, 평가 설정이 서로 다른 항목이 포함돼 있다. 따라서 개별 점수만으로 다른 상용·오픈 모델보다 전반적으로 우수하다고 단정하기보다는 실제 사용 환경에서 별도로 검증할 필요가 있다.

## 확인 범위

모델 구조와 매개변수 규모, 문맥 길이, 공개 위치, 서비스 가격 및 성능 수치는 제공된 GeekNews 기사에 기초해 확인했다. 속도·훈련 비용·벤치마크 결과는 Qwen 측 실험과 발표를 요약한 값으로, 독립적인 재현 결과로 확인된 것은 아니다. 향후 Qwen4에 실제로 어떤 설계가 채택될지와 출시 일정도 현재 확인된 범위에 포함되지 않는다.
