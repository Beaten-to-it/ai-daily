## 무엇이 있었나

메타가 모델 중개 플랫폼 오픈라우터에 ‘뮤즈 스파크 1.2’의 컨트리뷰터 요금제를 출시했다. 보도된 가격은 100만 토큰 기준 입력 0.10달러, 출력 0.20달러, 캐시 입력 0.002달러다. 기존 요금보다 최대 95% 낮으며, 기사에서는 당시 오픈라우터에 공개된 주요 모델 가운데 가장 저렴한 API 요금이라고 설명했다.

이 요금제는 사용자 데이터 활용과 학습 동의를 조건으로 비용을 낮춘 형태다. 메타는 에이전트 작업에 최적화된 모델의 가격 경쟁력을 앞세워 개발자와 기업 고객을 확보하려는 것으로 풀이된다.

## 왜 중요한가

API 비용이 낮아지면 국내 개발사와 스타트업도 반복 호출이 많은 자율형 에이전트, 다중 작업 루프, 서브에이전트 위임 같은 기능을 비교적 적은 비용으로 시험할 수 있다. 모델 선택 기준도 단순한 성능에서 비용 대비 성능과 데이터 이용 조건을 함께 따지는 방향으로 이동할 가능성이 있다.

다만 낮은 가격과 맞바꾼 데이터 활용 조건은 기업 이용자에게 중요한 검토 대상이다. 국내 조직은 서비스를 도입하기 전에 입력 데이터의 저장·학습 여부와 개인정보 및 영업비밀 처리 기준을 확인할 필요가 있다.

## 확인 범위

가격, 할인 폭, 출시 배경과 데이터 활용 조건은 AI타임스 기사에서 확인된 내용이다. ‘현존 최저가’와 모델 간 성능 비교는 기사 작성 시점의 오픈라우터 가격 및 외부 평가를 전제로 하므로 이후 변동될 수 있다. 실제 제공 지역, 세부 약관, 데이터 보관 방식과 독립적인 성능 검증 결과는 제시된 자료만으로 확인되지 않았다.
