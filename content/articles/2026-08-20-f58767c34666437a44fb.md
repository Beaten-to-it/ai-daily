## 무엇이 있었나

연구진이 AI 에이전트의 도구 호출을 정해진 메모리 한도 안에서 실행하도록 검사하는 런타임 ‘SkillEffect’를 제안했다. 언어 모델이 절차상 올바른 코드를 만들더라도 입력 전체를 한꺼번에 불러오면 단일 도구 호출에 허용된 메모리를 초과할 수 있다는 문제를 다룬다.

SkillEffect는 모델이 제안한 프로그램과 변경되지 않은 입력을 토대로 독립 검사기가 실행 방식을 다시 구성한 뒤 권한을 부여한다. 각 연산은 입력 인식, 사실 추출, 메모리 제한형 중간 표현 생성, 사용량 산정, 출력 조건 검사를 담당하는 별도 플러그인으로 등록된다. 공통 런타임은 실행 방식 선택과 제한형 가상머신 실행, 용량 할당, 결과 공개를 맡는다.

논문은 스트리밍 집계부터 제한된 힙을 이용한 상위 k개 선별까지 여섯 종류의 플러그인을 다뤘다. 연구진은 외부에서 고정한 메모리 상한 아래에서 제한형 접근이 최대 메모리 사용량을 줄이고 작업 완료율을 높였으며, 정상 구성은 받아들이고 평가에 사용한 적대적 제안은 모두 거부했다고 보고했다.

## 왜 중요한가

대용량 문서나 스프레드시트를 처리하는 AI 에이전트에서는 코드의 논리적 정확성만으로 안정적인 실행을 보장하기 어렵다. 입력을 어떤 방식으로 읽고 중간 상태를 얼마나 유지하는지도 장애 여부를 좌우하기 때문이다.

SkillEffect의 핵심은 모델이 만든 코드를 그대로 신뢰하지 않고, 사전에 감사된 연산별 규칙과 공통 실행 경계를 통해 메모리 사용과 결과 조건을 함께 검사한다는 데 있다. 제한된 서버나 사내 자동화 환경에서 에이전트 도구의 예측 가능성을 높이는 설계 사례가 될 수 있다. 다만 새로운 연산을 자동으로 지원하는 방식은 아니며, 연산마다 별도의 검토된 플러그인이 필요하다.
