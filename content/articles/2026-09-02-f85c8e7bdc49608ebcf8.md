## 무엇이 있었나

AWS는 앤트로픽의 ‘Claude Fable 5.1’을 아마존 베드록과 AWS 기반 Claude Platform에서 제공한다고 발표했다. AWS에 따르면 새 모델은 코딩과 과학 연구, 기업 업무를 비롯해 여러 도구와 애플리케이션을 오가는 장시간 작업에 초점을 맞췄다. 복잡한 추론과 지시 이행, 작업 진행 상황 전달 능력도 이전 모델보다 개선됐다는 설명이다.

이 모델은 추가적인 데이터 보존·안전 검토·접근 정책이 적용되는 ‘Covered Model’로 분류됐다. 일반적인 베드록 이용자는 모델 호출 전에 `aws_review` 모드를 설정해야 하며, 이 모드에서는 프롬프트와 출력이 AWS 경계 안에서 최장 30일 보관되고 AWS 담당자의 안전 검토 대상이 될 수 있다. 모델 제공사와의 데이터 공유는 요구되지 않는다고 AWS는 밝혔다.

AWS와 앤트로픽은 적격 기업 고객을 위한 ‘Enterprise Frontier Safeguards’도 소개했다. 해당 고객은 2026년 12월 31일까지 내부 용도에 한해 Claude Fable 5와 5.1을 데이터 무보존 방식으로 사용할 수 있다. AWS는 향후 고객 계정의 암호화 키와 접근 정책, 감사 로그 아래에 데이터를 두고 사람의 검토 없이 자동 안전 점검을 적용하는 기능도 제공할 계획이다.

Claude Fable 5.1은 미국 지역 및 글로벌 추론 프로필을 통해 베드록에서 이용할 수 있다. AWS GovCloud(US)와 북미 지역의 AWS 기반 Claude Platform도 지원 대상이다. 베드록 콘솔과 Anthropic Messages API, AWS의 Invoke·Converse API로 호출할 수 있다.

## 왜 중요한가

국내 기업이 고성능 AI 모델을 도입할 때는 모델 성능뿐 아니라 입력 데이터의 저장 위치와 보존 기간, 사람의 검토 여부가 중요한 판단 기준이 된다. Claude Fable 5.1은 일반 이용 시 최장 30일의 데이터 보존과 AWS 내부 검토가 적용될 수 있으므로, 개인정보나 기업 기밀을 다루는 조직은 기존 베드록 모델과 동일한 정책이라고 가정해서는 안 된다.

반면 적격 고객에게 제시된 데이터 무보존 방식과 고객 통제형 보호 장치는 금융·의료 등 규제가 엄격한 분야의 도입 가능성을 넓힐 수 있다. 다만 국내 조직은 실제 적용 전에 이용 자격과 지원 리전, 계약 조건을 확인하고 관련 법규 및 내부 보안 정책에 맞는지 별도로 검토할 필요가 있다.

## 확인 범위

모델 출시와 제공 경로, 데이터 보존 정책, Enterprise Frontier Safeguards의 조건은 2026년 9월 1일 공개된 AWS 공식 게시물을 기준으로 확인했다. 성능 향상에 관한 내용은 AWS가 전달한 앤트로픽의 자체 평가 결과이며, 독립적인 벤치마크나 실제 운영 환경에서의 성능은 이 자료만으로 확인되지 않는다. 향후 제공 예정인 보호 기능의 구체적인 출시 시점과 세부 조건도 확정된 범위가 제한적이다.
