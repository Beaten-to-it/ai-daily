## 무엇이 있었나

Anthropic이 8월 13일 Python SDK 0.122.0을 공개했다. 이번 버전에는 드림 생성 시 새 메모리 저장소를 만들거나 입력 저장소를 직접 갱신하도록 선택하는 `output_behavior` 옵션이 추가됐다.

비동기 클라이언트에서는 AWS SigV4 서명 작업을 이벤트 루프 밖에서 처리하도록 변경했다. Amazon Bedrock과 Vertex AI 연동에는 일부 베타 메시지 파싱 및 도구 실행 기능이 노출됐다.

스트리밍 처리도 다듬었다. 메시지를 누적할 때 모든 `message_delta` 필드를 반영하고, 서버 도구 사용 블록에서 `input_json` 이벤트를 내보내도록 했다. 잘못된 도구 입력 JSON 오류에는 문제를 파악할 수 있는 문맥이 추가됐다. 빈 API 키나 인증 토큰을 설정되지 않은 값으로 취급하고, 도구 경로의 심볼릭 링크 순환을 거부하는 수정도 포함됐다.

## 왜 중요한가

Python으로 Anthropic API를 연동하는 개발자에게는 스트리밍 응답의 일관성과 비동기 처리 안정성이 직접적인 운영 품질로 이어진다. 특히 AWS 서명 작업이 이벤트 루프를 막지 않도록 한 변경은 Bedrock 기반 비동기 서비스에서 응답 지연이나 동시 처리 저하를 줄이는 데 도움이 될 수 있다.

Bedrock과 Vertex AI에서 제공되는 기능 범위가 넓어진 점도 여러 클라우드 환경을 함께 운용하는 국내 기업에 의미가 있다. 다만 베타 API를 사용하는 기능은 정식 인터페이스보다 변경 가능성이 크므로 실제 적용 전 호환성 검증이 필요하다.

## 확인 범위

GitHub에 게시된 v0.122.0 릴리스 설명에서 기능 추가, 버그 수정, 리팩터링 및 문서 변경 내역을 확인했다. 각 수정의 실제 성능 향상 폭이나 모든 실행 환경에서의 동작은 해당 릴리스 설명만으로 확인할 수 없다. 업그레이드할 때는 기존 코드의 스트리밍 처리, Bedrock·Vertex 연동, 인증 설정을 중심으로 회귀 테스트하는 것이 바람직하다.
