## 무엇이 있었나

Anthropic이 조직 소유 인프라에서 Claude Code 클라우드 세션을 실행하는 ‘셀프호스팅 환경’의 빠른 시작 안내서를 공개했다. 이 기능은 Team과 Enterprise 요금제에서 공개 베타로 제공된다.

조직 관리자가 claude.ai에서 환경을 만들고 비밀 키를 발급한 뒤, 자체 서버에 러너를 실행하면 해당 환경으로 Claude Code 세션을 배정할 수 있다. 러너는 저장소를 내려받아 세션별 작업 공간을 만들고, 완료 후 종료되는 방식으로 동작한다. 운영 환경에서는 오케스트레이터를 이용해 러너를 다시 시작하도록 구성하는 것이 권장된다.

러너 호스트는 Linux 또는 macOS를 지원하며 Claude Code 2.1.224 이상과 Git 2.24 이상이 필요하다. Windows는 러너 호스트로 직접 지원되지 않아 Linux 컨테이너를 사용해야 한다. 외부 통신을 위한 HTTPS 연결, Git 저장소 접근 권한, 정확히 동기화된 시스템 시계도 요구된다.

## 왜 중요한가

기업이 코드와 내부 시스템을 자사 통제 환경에 두면서 Claude Code의 클라우드 세션을 활용할 수 있는 선택지가 생겼다는 의미가 있다. 특히 네트워크 경로, Git 인증 정보, 실행 환경과 세션 작업 공간을 조직의 보안 정책에 맞게 관리하려는 국내 기업에 유용할 수 있다.

다만 단일 호스트와 러너로 구성하는 빠른 시작 절차는 시험 실행을 위한 최소 구성이다. 실제 저장소나 내부 시스템에 연결하려면 외부 통신 통제, 비밀 정보 관리, 러너 재시작, 격리와 오케스트레이션 등을 별도로 설계해야 한다.

## 확인 범위

Claude Code 공식 문서에서 셀프호스팅 환경의 공개 베타 제공 대상, 지원 운영체제와 최소 버전, 환경 생성부터 러너 등록·세션 배정까지의 절차를 확인했다. 실제 환경에서의 성능, 비용, 보안 수준과 대규모 운영 안정성은 이 빠른 시작 문서만으로 확인되지 않았으며 별도의 실증 자료도 검토하지 않았다.
