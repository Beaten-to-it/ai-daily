## 무엇이 있었나

AI 코드 테스트 스타트업 블랙스미스가 피크XV파트너스 주도로 4천500만 달러 규모의 시리즈 B 투자를 유치했다. 이번 투자에서 평가된 기업가치는 5억5천만 달러로, 1년도 지나지 않아 이전 시리즈 A 당시의 6천만 달러에서 약 9배로 높아졌다. GV와 와이콤비네이터도 참여했으며, 누적 투자금은 5천850만 달러가 됐다.

2024년 설립된 블랙스미스는 소프트웨어가 실제 서비스에 반영되기 전 빌드와 테스트, 검증 작업을 처리하는 플랫폼을 운영한다. 처음에는 지속적 통합(CI) 작업용 클라우드 서비스로 출발했고, 이후 실패한 코드 검사를 자동으로 수정하는 AI 코딩 에이전트 ‘코드스미스’로 제품군을 넓혔다.

회사가 밝힌 고객 수는 5천 곳 이상으로, 1년 전 700여 곳에서 크게 늘었다. 공동창업자 겸 최고경영자 아디티아 자야프라카시에 따르면 직원 10명으로 연환산 매출 1천만 달러에 도달한 뒤 인력을 약 30명으로 확대했으며, 현재 매출은 수천만 달러 수준이다. 다만 구체적인 최신 연환산 반복매출은 공개하지 않았다.

## 왜 중요한가

Cursor와 Codex, Claude Code 같은 AI 코딩 도구가 코드 생산 속도를 높이면서 테스트와 검증이 새로운 병목으로 떠오르고 있다. 생성되는 코드가 많아질수록 오류와 품질 문제를 실제 배포 전에 찾아내는 과정도 함께 확장돼야 하기 때문이다. 블랙스미스의 빠른 성장과 기업가치 상승은 투자자들이 코드 생성뿐 아니라 검증 인프라도 AI 개발 생태계의 핵심 시장으로 보고 있음을 보여준다.

한국의 개발 조직에도 같은 과제가 적용된다. AI 코딩 도구 도입 효과를 코드 작성량만으로 평가하기보다 테스트 시간, 실패율, 수정 과정, 배포 안정성까지 함께 측정해야 한다. 검증 자동화 역량이 부족하면 개발 속도가 빨라져도 리뷰와 배포 단계의 부담이 오히려 커질 수 있다.

시장 경쟁은 치열하다. 블랙스미스는 GitHub Actions와 주요 클라우드 사업자의 테스트 서비스뿐 아니라 Codex·Claude Code 등에 포함된 검증 기능, Cursor의 자동화 기능, 여러 신생 업체와 경쟁해야 한다. 회사는 테스트 속도와 비용 경쟁력을 내세우며 코드 작성부터 검증과 병합까지 지원 범위를 확대할 계획이다.

## 확인 범위

투자 규모, 기업가치, 누적 투자금, 고객 수와 사업 현황은 TechCrunch가 회사 최고경영자 인터뷰를 토대로 보도한 내용에서 확인했다. 구체적인 최신 연환산 반복매출은 공개되지 않았으며, 고객 수와 매출 관련 수치는 회사 측 설명에 기반한다. 시장점유율이나 경쟁 서비스 대비 성능·가격 우위는 독립적으로 검증된 자료가 제시되지 않아 확정적으로 판단하기 어렵다.
