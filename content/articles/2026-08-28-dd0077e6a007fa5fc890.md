## 무엇이 있었나

GitHub가 기업 관리 설정에서 개별 플러그인 마켓플레이스의 자동 업데이트를 지원한다. 관리자는 `extraKnownMarketplaces` 항목에 `autoUpdate: true`를 설정할 수 있다. 지원되는 클라이언트는 해당 마켓플레이스를 자동으로 확인하고, 그곳에서 설치한 플러그인을 업데이트한다.

자동 업데이트를 사용하더라도 마켓플레이스는 현재 적용되는 `strictKnownMarketplaces` 허용 목록에 포함돼 있어야 한다. 이 기능은 Copilot Business와 Copilot Enterprise에서 정식 제공되며 GitHub Copilot 앱, Copilot CLI, Visual Studio Code가 지원 대상이다.

## 왜 중요한가

사내 전용 플러그인이나 조직별 개발 환경을 운영하는 기업은 업데이트 작업을 일일이 수행해야 하는 부담을 줄일 수 있다. 중앙 관리 설정을 통해 배포된 플러그인을 최신 상태로 유지하기 쉬워져, 여러 개발자가 사용하는 도구 환경의 일관성도 높일 수 있다.

동시에 기존 허용 목록 정책은 그대로 적용된다. 따라서 자동화의 편의성을 확보하면서도 승인된 마켓플레이스만 이용하도록 통제할 수 있다는 점이 기업 관리자에게 중요하다.

## 확인 범위

GitHub Changelog에 게시된 기능 설명을 기준으로 지원 설정, 적용 조건, 대상 요금제와 클라이언트를 확인했다. 구체적인 업데이트 주기와 실패 시 재시도 방식, 클라이언트별 세부 동작은 제공된 자료에서 확인되지 않았다.
