## 무엇이 있었나

알리바바가 플래그십 AI 모델 ‘큐원3.8-맥스’의 가중치를 공개했다. AI타임스에 따르면 이 모델은 2조4000억개의 매개변수를 갖춘 전문가 혼합 방식의 모델로, 이용자는 자체 서버에서 미세조정하거나 추론 성능을 시험할 수 있다.

다만 상업적 이용에는 조건이 붙는다. 최근 12개월 연간 총매출이 5000만달러를 넘는 기업과 계열사가 모델 서비스나 AI 업무 보조 제품으로 사업화하려면 별도의 상업용 라이선스를 구매해야 한다. 외부에 결과물을 제공하지 않는 내부 연구와 단순 사내 활용은 적용 대상에서 제외된다.

알리바바는 가중치 제공과 별도로 클라우드 기반 API도 운영한다. 기사에 제시된 요금은 100만 토큰 기준 입력 2달러, 출력 6달러다.

## 왜 중요한가

이번 정책은 가중치를 내려받아 활용할 수 있도록 개방하면서도, 일정 규모 이상의 상업적 사업에는 비용을 부과하는 절충형 모델이라는 점에서 주목된다. 완전한 무료 오픈소스와 폐쇄형 API 사이에 별도의 라이선스 체계가 확산될 가능성을 보여준다.

큐원 계열 모델을 검토하는 한국 기업은 성능과 구축 비용뿐 아니라 매출 기준, 사용 목적, 계열사 포함 여부를 함께 살펴야 한다. 특히 모델을 고객 대상 서비스에 탑재하거나 재판매하려는 사업자는 도입 전에 라이선스 적용 여부를 확인할 필요가 있다.

## 확인 범위

알리바바의 가중치 공개, 모델 규모, 상업용 라이선스 기준과 API 요금은 제공된 AI타임스 기사에서 확인했다. 구체적인 라이선스 원문과 예외 조항, 실제 계약 비용 및 모델 성능은 별도 자료로 교차 검증하지 않았으므로 기사에 명시된 범위를 넘어 판단하지 않았다.
