## 무엇이 있었나

허깅페이스는 2026년 1월부터 7월까지 허브에서 관찰한 오픈 모델 생태계의 변화를 정리했다. 이 기간 공개 모델 저장소는 243만 개에서 296만 개로, 데이터세트는 71만1천 개에서 100만 개로, 스페이스는 100만 개에서 144만 개로 늘었다.

보고서는 중국 연구소들이 초대형 모델 공개를 주도하는 가운데, 미국에서는 엔비디아와 AMD 같은 하드웨어·인프라 기업의 참여가 두드러졌다고 분석했다. 또한 화제성과 실제 사용량은 크게 달랐다. 2026년 다운로드 상위 25개 저장소와 ‘좋아요’ 상위 25개 저장소에 동시에 포함된 사례는 하나뿐이었다. 신작 대형 모델이 관심을 끄는 반면, 실제 파이프라인에서는 오래되고 안정적인 소형 모델이 반복적으로 사용된다는 설명이다.

Qwen은 커뮤니티가 후속 모델을 만드는 기반으로 빠르게 자리 잡았다. 허깅페이스가 집계한 Qwen 파생 저장소는 15만1,448개였으며, 2026년 첫 7개월 동안 하루 약 180~210개씩 증가했다. 전체 크기를 아우르는 모델 구성과 꾸준한 출시, 비교적 개방적인 라이선스가 생태계 확장에 영향을 준 것으로 분석됐다.

실제 실행 환경에서는 여전히 소형 모델의 비중이 압도적이었다. 파라미터 수를 공개한 모델 가운데 10억 개 미만 모델이 누적 다운로드의 83%를 차지했고, 2026년 다운로드 중 700억 개 초과 모델의 비중은 3%였다. 동시에 GGUF와 llama.cpp 생태계가 성장하면서 대형 모델을 양자화해 로컬 장비에서 구동하려는 흐름도 강해졌다.

AI 에이전트의 허브 이용도 새로운 변수로 제시됐다. 에이전트 식별자가 포함된 트래픽을 기준으로 2026년 7월 Claude Code가 44.4%, Codex가 20.8%를 기록했다. 다만 월별 점유율 변동이 크고 미등록 클라이언트 비중도 높아, 아직 특정 도구가 확고한 우위를 차지한 시장으로 보기는 어렵다.

## 왜 중요한가

한국의 개발자와 기업에는 최고 성능 모델을 고르는 일만큼 실제 배포 생태계를 살피는 일이 중요해졌다는 의미가 있다. 다운로드 수, 커뮤니티 파생 모델, 양자화 형식, 로컬 추론 도구 지원은 모델을 제품에 안정적으로 적용할 수 있는지를 가르는 실무 지표다.

특히 Qwen처럼 다양한 크기의 모델을 제공하고 파생 생태계가 큰 계열은 온디바이스 실험부터 서버 배포까지 같은 기술 기반을 유지하기 쉽다. 반대로 초대형 모델은 높은 관심을 받더라도 비용과 하드웨어 제약 때문에 일반적인 운영 환경에서 바로 채택되기 어렵다. 국내 기업은 성능 평가뿐 아니라 라이선스, 변환 산출물의 신뢰성, 한국어 품질, 추론 비용을 함께 검토할 필요가 있다.

에이전트가 모델과 데이터 저장소의 주요 이용 주체로 떠오른 점도 주목할 만하다. 앞으로 AI 개발 플랫폼은 사람이 탐색하기 좋은 웹 화면뿐 아니라 에이전트가 읽고 실행할 수 있는 문서, API, 권한 통제와 안전한 실행 환경을 함께 갖춰야 할 가능성이 크다.

## 확인 범위

이 기사는 허깅페이스가 공개한 2026년 여름 보고서의 집계와 분석을 바탕으로 작성했다. 수치는 주로 허깅페이스 허브 내부 활동을 나타내며, 외부 API 사용량이나 비공개 배포, 다른 유통 경로까지 포함한 전체 시장 점유율은 아니다. 다운로드·좋아요·파생 저장소 수도 각각 사용, 관심, 후속 개발의 신호일 뿐 모델 품질이나 상업적 채택을 직접 증명하지 않는다.

원문에는 중국 대형 모델의 라이선스가 대체로 허용적이라는 분석이 있지만, 게시물 하단에는 일부 Kimi 모델의 상업적 이용 조건을 지적하는 독자 의견도 실려 있다. 따라서 개별 모델을 도입할 때는 보고서의 분류만 따르지 말고 해당 저장소의 최신 라이선스와 별도 이용 조건을 직접 확인해야 한다.
