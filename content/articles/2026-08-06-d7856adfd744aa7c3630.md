## 무엇이 있었나

Ollama가 8월 4일 버전 0.32.6을 공개했다. 이번 릴리스에서는 애플 GPU에서 Qwen3.5를 실행할 때 MLX 엔진이 모델의 MTP 헤드를 자동으로 활용해 추측 디코딩을 수행하도록 개선됐다.

OpenAI 호환 API의 스트리밍 응답 형식도 조정됐다. `/v1/chat/completions`는 역할 정보를 첫 번째 청크에만 담고, 종료 사유와 사용량을 각각 별도 청크로 전송한다. 사용량 전송에는 `stream_options.include_usage` 설정이 적용된다. 출력 길이 제한으로 응답이 잘렸을 때 종료 사유가 `tool_calls`가 아닌 `length`로 표시되도록 수정됐다.

이 밖에도 기본 태그가 없는 클라우드 전용 모델의 실행 경로와 터미널 사용자 인터페이스가 개선됐으며, MLX와 llama.cpp 엔진이 업데이트됐다. 실험적 이미지 생성 기능은 이번 버전에서 임시로 제거됐다. 해당 기능이 필요한 이용자에게는 0.32.5를 계속 사용하라고 안내했다.

## 왜 중요한가

Ollama를 애플 실리콘 환경에서 사용하는 개발자는 Qwen3.5의 생성 성능 개선을 기대할 수 있다. 다만 릴리스 노트에는 구체적인 속도 측정값이나 적용 대상 기기별 결과가 제시되지 않았다.

OpenAI 호환 API를 이용해 국내 서비스나 개발 도구를 연결하는 경우에는 스트리밍 청크 구조와 종료 사유가 기존 처리 로직에 영향을 줄 수 있다. 특히 응답 파서, 사용량 집계, 길이 제한 감지 기능을 운영 중이라면 업데이트 전후 동작을 확인할 필요가 있다. 이미지 생성 기능을 사용하던 환경은 0.32.6으로 바로 올리기 전에 기능 제외에 따른 영향을 점검해야 한다.

## 확인 범위

GitHub에 게시된 Ollama 0.32.6 릴리스 노트에서 변경 사항과 공개 시점을 확인했다. 성능 향상의 구체적인 폭, 개별 하드웨어에서의 실제 결과, 이미지 생성 기능의 복귀 일정은 해당 릴리스 노트만으로 확인되지 않는다.
