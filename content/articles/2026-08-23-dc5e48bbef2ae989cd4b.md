## 무엇이 있었나

딥시크가 텍스트와 이미지를 함께 처리하는 실험용 멀티모달 모델 ‘딥시크-V4-플래시-비전-Exp’를 API 플랫폼에 공개했다. 기존 V4-플래시의 텍스트 처리 역량에 이미지 이해 기능을 더해 화면 오류 확인, 문서·차트 분석, 결과물의 시각적 검증 같은 에이전트 작업을 단일 모델로 수행하도록 설계했다.

이 모델은 전체 매개변수 2840억개 가운데 토큰마다 130억개를 활성화하는 전문가 혼합 구조이며, 최대 100만 토큰의 컨텍스트를 지원한다고 소개됐다. 딥시크는 자체 벤치마크에서 앤트로픽 ‘오퍼스 4.8’과 대등한 수준의 멀티모달 에이전트 성능을 보였다고 주장했다.

이미지는 한 장당 최대 384토큰으로 환산되며 별도의 멀티모달 할증 없이 텍스트와 같은 기준으로 과금된다. 파일을 한 번 올린 뒤 여러 요청에서 재사용할 수 있는 무료 파일스 API와 오픈AI·앤트로픽 호환 API도 지원한다.

## 왜 중요한가

이미지를 처리하려고 별도 비전 모델과 텍스트 모델을 연결하던 개발 과정이 단순해질 수 있다. 특히 화면이나 문서 이미지를 반복해서 분석하는 코딩·업무 자동화 에이전트에서는 모델 호출 구조와 운영비를 줄일 가능성이 있다.

오픈AI 및 앤트로픽 방식과 호환되는 API를 제공한다는 점도 국내 개발자의 실험과 기존 서비스 연동 문턱을 낮추는 요소다. 다만 실험 버전인 만큼 실제 도입 전에는 한국어·문서 처리 성능, 안정성, 비용을 자체 업무 환경에서 검증할 필요가 있다.

## 확인 범위

모델 공개 사실과 사양, 가격, API 지원 방식은 AI타임스가 보도한 딥시크 발표 내용을 기준으로 확인했다. 기사에 제시된 성능 수치는 딥시크의 자체 평가 환경에서 나온 결과로, 독립 기관의 재현이나 검증 결과는 확인되지 않았다. 모델명에 ‘Exp’가 붙은 실험 단계여서 향후 사양과 식별자가 변경될 가능성도 있다.
