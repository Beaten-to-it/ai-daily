## 무엇이 있었나

연구진이 정답 라벨이나 과제별 점수, 보상 모델 없이도 대규모 언어 모델(LLM) 에이전트의 재사용 가능한 작업 지침을 개선하는 ‘자기지도 스킬 최적화(Self-Supervised Skill Optimization·SSO)’ 방법을 공개했다.

SSO는 현재 스킬과 이를 바탕으로 생성한 여러 후보 스킬을 같은 비라벨 과제 묶음에 적용한 뒤, LLM 심사자가 답변과 실행 과정, 산출물 또는 최종 상태를 비교하도록 한다. 별도의 행동 추출기는 심사 결과를 보지 않은 채 후보 간 행동 차이를 찾아낸다. 시스템은 여러 과제에서 수집한 비교 증거를 종합해 효과적인 행동을 선별하고 새로운 스킬을 구성한다. 새 스킬은 비라벨 검증 세트에서 기존 스킬보다 나은 결과를 냈을 때만 채택된다.

논문 저자들은 SSO가 폐쇄형·개방형 과제 모두에서 기존의 정답 데이터 없는 프롬프트 최적화 기법보다 좋은 성능을 냈다고 보고했다. 폐쇄형 벤치마크에서는 정답 피드백을 사용하는 강력한 스킬 최적화 기법에 근접하거나 일부 조건에서 이를 넘어섰다고 주장했다.

## 왜 중요한가

LLM 에이전트를 실제 업무에 적용할 때 모든 과제에 정답과 정교한 평가기를 마련하기는 어렵다. 특히 문서 작성이나 조사처럼 결과의 형태가 다양하고 평가 기준이 복합적인 작업은 사람이 지속적으로 채점해야 해 비용이 커진다.

SSO가 제시한 방식은 라벨이 부족한 환경에서도 에이전트의 절차적 지침을 반복적으로 개선할 가능성을 보여준다. 국내 기업이 사내 지식 검색, 보고서 작성, 고객 지원과 같은 업무용 에이전트를 구축할 때 데이터 구축 부담을 낮추는 접근법으로 검토할 수 있다. 다만 비교 평가를 맡는 LLM의 판단 품질과 편향이 최종 스킬에 반영될 수 있으므로, 중요한 업무에서는 사람의 검증과 별도 안전성 평가가 여전히 필요하다.

## 확인 범위

논문의 제목, 저자, 제출 이력, 초록에 제시된 방법과 저자들의 실험 결론을 확인했다. 구체적인 벤치마크별 수치와 실험 조건, 사용 모델, 비용, 통계적 유의성 및 재현성은 이 기사에 제공된 자료만으로 검증하지 않았다. 성능 비교는 독립적으로 재현된 결과가 아니라 논문 저자들이 보고한 주장이다.
