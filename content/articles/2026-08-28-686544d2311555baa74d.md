## 무엇이 있었나

GitHub가 Copilot Business와 Copilot Enterprise의 정식 출시 모델에 적용하는 글로벌 모델 정책을 정식 제공하기 시작했다. 정책 적용은 기업별로 시점이 다르며 2026년 9월 1일까지 순차적으로 진행된다.

정책이 적용되면 관리자가 별도로 설정하지 않은 기존 모델과 새로 추가되는 정식 출시 모델은 기본 정책을 따르게 된다. 기본 정책은 활성화 상태이므로, 별도 조정이 없다면 해당 모델을 조직 구성원이 사용할 수 있다. 관리자가 특정 모델을 명시적으로 켜거나 끈 설정은 그대로 유지된다.

다만 DeepSeek와 Kimi K2 같은 오픈 웨이트 모델, GitHub의 데이터 보존 계약이 적용되지 않는 모델은 기본 활성화 대상에서 제외된다. 적용 이후 모델 설정에는 명시적 활성화·비활성화, 상위 조직 설정 위임, 기본 정책 위임 등 네 가지 상태가 표시된다.

## 왜 중요한가

국내 기업에서 GitHub Copilot을 관리하는 담당자는 조직에 새 모델이 제공될 때마다 일일이 허용 여부를 정하지 않아도 된다. 반면 기본 정책이 활성화된 조직에서는 미설정 모델이 자동으로 사용자에게 제공될 수 있으므로, 보안·준법·데이터 처리 기준이 엄격한 기업은 적용 시점과 현재 정책을 미리 점검할 필요가 있다.

명시적으로 지정한 모델별 설정은 유지되고, 데이터 보존 조건 등이 다른 모델은 기본 활성화에서 제외된다는 점은 중앙 관리의 편의성과 개별 통제를 함께 고려한 조치다. GitHub는 향후 기본 정책 위임 상태를 없애고 모든 정책을 관리자의 명시적 선택으로 전환하는 방안도 검토하고 있다.

## 확인 범위

GitHub Changelog에 공개된 정책 대상, 순차 적용 일정, 모델 설정 상태와 기본 활성화 예외를 확인했다. 기업별 실제 적용 시점과 향후 정책 구조 변경 여부는 확정되지 않았으며, GitHub는 관련 의견을 수렴하고 있다.
