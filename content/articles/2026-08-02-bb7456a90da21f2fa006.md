## 무엇이 있었나

GitHub는 2026년 7월 31일부터 모든 GitHub Copilot 환경에서 Gemini 2.5 Pro와 Gemini 3 Flash를 지원 중단했다고 밝혔다. 적용 대상에는 Copilot Chat, 인라인 편집, Ask 및 Agent 모드, 코드 자동 완성이 포함된다.

GitHub가 제시한 대체 모델은 Gemini 2.5 Pro의 경우 Gemini 3.1 Pro(프리뷰), Gemini 3 Flash의 경우 Gemini 3.6 Flash다. 기존 모델을 별도로 제거할 필요는 없지만, 해당 모델을 사용하던 워크플로와 연동 설정은 지원 모델로 변경해야 한다.

Copilot Enterprise 관리자는 Copilot 설정의 모델 정책에서 대체 모델 접근을 허용해야 할 수 있다. 정책이 활성화되면 VS Code와 github.com의 Copilot Chat 모델 선택 화면에서 해당 모델을 확인할 수 있다.

## 왜 중요한가

국내에서 GitHub Copilot을 개발 과정이나 사내 자동화에 사용하는 조직은 모델 이름을 고정한 설정과 업무 절차가 정상적으로 작동하는지 점검할 필요가 있다. 특히 Enterprise 환경에서는 관리자의 모델 정책에 따라 대체 모델이 구성원에게 곧바로 표시되지 않을 수 있다.

또한 Gemini 2.5 Pro의 권장 대안은 프리뷰 모델이므로, 조직의 안정성 기준과 프리뷰 기능 사용 정책을 함께 검토해야 한다. Gemini 3 Flash 사용자는 Gemini 3.6 Flash로의 전환 여부를 확인할 수 있다.

## 확인 범위

GitHub Changelog에 게시된 지원 중단 대상과 날짜, 적용되는 Copilot 기능, 권장 대체 모델 및 Enterprise 관리자 안내를 확인했다. 대체 모델 간 성능·가격·사용 한도 차이와 기존 연동의 구체적인 호환성은 이 공지에서 다루지 않아 확인 범위에 포함하지 않았다.
