## 무엇이 있었나

GitHub는 2026년 10월 2일부터 GitHub Copilot 전반에서 Gemini 3.5 Flash, Gemini 3.6 Flash, Kimi K2.7 Code, Claude Opus 4.7의 지원을 종료한다고 발표했다. 적용 범위에는 Copilot Chat과 인라인 편집, Ask·Agent 모드, 코드 자동 완성이 포함된다.

GitHub가 제시한 대체 모델은 Gemini 3.8 Flash, Kimi K3, Claude Opus 5다. 기존 모델을 사용하는 워크플로와 연동 기능은 지원 종료 전에 대체 모델로 전환해야 한다. 종료된 모델을 별도로 제거할 필요는 없다.

## 왜 중요한가

Copilot에서 특정 모델을 직접 선택하거나 자동화 과정에 연결한 국내 개발팀은 지원 종료일까지 설정과 연동 상태를 점검해야 한다. 모델 이름을 고정해 둔 워크플로는 변경하지 않으면 영향을 받을 수 있다.

Copilot Business와 Enterprise에서는 대체 모델이 조직 정책상 허용돼 있는지도 확인해야 한다. 관리자가 Copilot 설정에서 해당 모델의 접근 권한을 활성화하면, 지원되는 Copilot 환경의 모델 선택기에 모델이 표시된다.

## 확인 범위

이번 내용은 GitHub Changelog에 게시된 공식 공지를 기준으로 확인했다. 지원 종료 대상과 날짜, 권장 대체 모델, 관리자 정책 관련 안내는 공지에 명시돼 있다. 다만 모델별 성능 차이와 이전 과정의 호환성, 조직별 실제 영향은 이번 공지만으로 확인되지 않으므로 별도 검증이 필요하다.
