## 무엇이 있었나

텐센트 Hy 팀이 차세대 대규모 언어 모델 ‘Hy4 preview’를 공개했다. 혼합 전문가(MoE) 구조를 채택한 이 모델은 전체 매개변수 7700억 개 가운데 토큰마다 490억 개를 활성화하며, 최대 100만 토큰의 문맥 길이를 지원한다.

모델은 78개 계층으로 구성됐으며, 투기적 디코딩을 위한 MTP 계층도 내장했다. 텐센트는 소프트웨어 개발, 문서·데이터 분석, 게임 제작, 과학 연구와 같은 실무 작업을 주요 활용 분야로 제시했다.

일반 모델과 FP8 양자화 모델의 가중치는 여러 모델 배포 플랫폼에 공개됐다. Apache License 2.0을 적용했으며, vLLM과 SGLang을 통한 배포 및 OpenAI 호환 API 호출 방법도 제공한다. 파인튜닝 절차와 모델 압축 도구에 관한 안내도 저장소에 포함됐다.

## 왜 중요한가

Hy4 preview는 긴 문맥과 대규모 MoE 구조를 결합해 코드베이스 분석이나 여러 파일에 걸친 문서 작업처럼 입력량이 많은 업무를 겨냥한다. 가중치뿐 아니라 배포·파인튜닝 경로까지 함께 공개돼, 국내 연구자와 개발자도 자체 인프라에서 모델을 검토하거나 응용 가능성을 시험할 수 있다.

다만 전체 규모가 매우 크고 공식 배포 예시도 다중 GPU 구성을 전제로 한다. 따라서 실제 도입 시에는 FP8 모델 활용 여부를 비롯해 하드웨어 요구량, 추론 비용, 한국어 성능을 별도로 평가해야 한다.

## 확인 범위

모델 구조, 공개 방식, 라이선스, 배포 지원 및 알려진 한계는 텐센트 Hy 팀의 공식 GitHub 저장소 설명에서 확인했다. 저장소에 제시된 내부 비교 평가는 텐센트가 자체 전문가와 과제를 대상으로 수행한 결과이므로, 독립 기관의 검증 결과로 볼 수는 없다.

또한 Hy4 preview는 초기 버전이다. 개발팀은 복잡한 작업에서 필요 이상으로 오래 추론하거나 자체 결과를 과도하게 검증하는 경향이 있다고 밝혔다. 실제 한국어 품질, 운영 안정성, 비용 효율성은 제공된 자료만으로 확정하기 어렵다.
