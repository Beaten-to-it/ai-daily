## 무엇이 있었나

연구진은 토큰 로짓과 같은 모델 내부의 불확실성 정보에 접근하지 않고도 웹 에이전트의 실패 위험을 예측하는 방법을 제안했다. 에이전트가 작업을 수행하며 남기는 관찰 가능한 실행 궤적을 분석해, 현재 과정이 목표를 향하고 있는지 실패로 기울고 있는지를 단계별로 판단한다.

제안된 표현은 두 종류다. 거시적 특징은 여러 단계에 걸친 에이전트와 웹 환경의 상호작용 및 피드백을 요약한다. 미시적 특징은 블랙박스 질의를 반복해 에이전트의 의도와 행동, 예상되는 상태 변화가 서로 일치하는지를 측정한다.

학습 데이터의 표기 방식도 달리했다. 실패한 실행 전체를 처음부터 실패로 간주하지 않고, 최종 실패와 연결되면서 이후에도 바로잡히지 않은 최초의 중대한 오류를 경계로 삼았다. 이에 따라 실패한 실행에 포함된 정상적인 초기 단계는 정상 상태로 보존된다.

연구진은 WebArena-Lite와 Online Mind2Web 벤치마크에서 공개·비공개 모델 다섯 종을 이용해 평가했다. 논문 초록에 따르면 관찰 가능한 궤적 신호만 사용한 예측기는 모델 내부 신호를 이용하는 기준선과 경쟁력 있는 결과를 보였다. 오탐으로 정상 실행을 중단하는 횟수를 일정 수준으로 제한한 조건에서도 조기 개입에 활용할 수 있었으며, 학습에서 제외한 웹사이트 범주로의 전이 가능성도 관찰됐다.

## 왜 중요한가

기업이 외부 업체의 모델이나 API 기반 에이전트를 사용하면 토큰별 내부 정보에 접근하기 어려운 경우가 많다. 이번 접근은 브라우저에서 실제로 관찰할 수 있는 행동과 환경 반응만으로 위험을 감시할 수 있어, 폐쇄형 모델을 포함한 웹 자동화 시스템에도 적용할 여지가 있다.

특히 쇼핑, 예약, 업무 시스템 조작처럼 잘못된 클릭이나 입력이 실제 결과로 이어지는 서비스에서는 최종 실패를 확인한 뒤 대응하는 것보다 오류가 굳어지는 시점을 조기에 감지하는 편이 유용하다. 다만 이 연구가 곧바로 모든 실제 서비스에서 안정적인 차단 장치로 사용할 수 있음을 입증한 것은 아니다.
