## 무엇이 있었나

GitHub가 Copilot 사용량 지표 API에 서드파티 에이전트 앱별 활동 통계를 추가했다. Claude와 Codex 같은 파트너 에이전트를 GitHub 워크플로에서 실행한 내역을 개별 에이전트 단위로 확인할 수 있게 된 것이다.

새로운 선택 필드 `totals_by_3rd_party_agent`에는 식별된 에이전트마다 이름과 고유 ID, 사용자가 시작한 작업 수, 세션 수가 기록된다. 에이전트 ID는 보고 기간이 달라져도 유지되는 식별자인 반면 표시 이름은 바뀔 수 있어, GitHub는 집계와 데이터 연결에 ID를 사용할 것을 권고했다.

이 정보는 기업·조직 및 각 사용자 단위의 1일·28일 보고서에 제공된다. 다만 세션 수는 기업과 조직의 통합 보고서에만 포함되고 사용자별 항목에서는 빠진다.

## 왜 중요한가

그동안 관련 활동이 하나의 범주로 합산돼 Copilot 코딩 에이전트와 다른 에이전트의 사용량을 구분하기 어려웠다. 이번 변경으로 기업은 실제로 어떤 에이전트가 활용되는지 비교하고, 신규 도구의 도입 추이나 기존 도구와의 관계를 데이터로 판단할 수 있다.

여러 AI 코딩 에이전트를 함께 도입하는 한국 기업에도 운영과 라이선스 의사결정의 근거가 될 수 있다. 특히 조직별 사용 현황을 파악하거나 시범 도입 성과를 비교할 때 제품별 활동을 분리해 볼 수 있다는 점이 의미가 있다.

## 확인 범위

GitHub Changelog에서 발표한 API 변경 내용과 필드 정의, 접근 조건을 확인했다. 해당 지표를 보려면 Copilot 사용량 지표 정책이 활성화돼 있어야 하며, 기업 소유자·청구 관리자·조직 소유자 또는 관련 조회 권한을 부여받은 사용자만 접근할 수 있다.

에이전트별 작업 시작 횟수는 최상위의 동명 필드와 집계 대상이 다르므로 두 값을 합산하거나 같은 의미로 취급하면 안 된다. 같은 에이전트에 속한 여러 앱의 활동은 하나로 합쳐지며, 식별할 수 없는 에이전트의 활동은 제외된다. 보고 기간에 인식된 에이전트 앱 활동이 없으면 새 필드 자체가 반환되지 않는다. 기존 필드 구조는 유지돼 이전 API 이용 방식과의 호환성에는 영향을 주지 않는다.
