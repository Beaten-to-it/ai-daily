## 무엇이 있었나

AWS는 지도 미세조정(SFT)을 위한 데이터 준비 지침을 공개했다. 핵심은 학습 인프라를 마련하기 전에 데이터의 정확성, 다양성, 일관성, 중복 여부와 안전성을 점검해야 한다는 것이다. SFT는 새로운 지식을 주입하기보다 모델이 지시를 따르고 일정한 문체나 출력 형식을 유지하도록 행동을 조정하는 데 적합하다고 설명했다.

학습 데이터는 실제 추론 환경과 같은 구조를 사용해야 한다. 운영 단계에서 시스템 프롬프트를 쓴다면 학습 예시에도 포함하고, 대화형 데이터는 한 줄에 하나의 JSON 객체를 담는 JSONL 형식으로 구성해야 한다. 사용자와 어시스턴트 역할을 엄격히 구분하고, 도구 호출이나 문서·이미지 입력도 대상 모델이 요구하는 공식 스키마에 맞춰야 한다.

AWS는 전체 데이터 가운데 10~20%를 평가용으로 분리하라고 권고했다. 표본이 1,000개 미만인 소규모 데이터셋은 작업 유형별 비중을 유지하는 층화 분할을 적용하고, 미세조정 전 기본 모델의 성능을 먼저 측정해야 과적합 여부와 개선 폭을 판단할 수 있다고 밝혔다.

## 왜 중요한가

국내 기업이 고객 상담, 문서 처리, 분류 자동화처럼 정해진 답변 방식이 필요한 생성형 AI를 구축할 때 데이터 양만 늘리는 접근에는 한계가 있다. 잘못되거나 서로 충돌하는 예시는 모델의 오답과 불안정한 출력 형식을 고착시킬 수 있기 때문이다.

특히 한국어 서비스는 실제 이용자의 다양한 표현, 전문 용어, 불완전한 질문과 예외 상황을 학습 데이터에 반영할 필요가 있다. 운영 환경과 학습 형식을 일치시키고 별도의 평가 데이터를 확보하면, 미세조정 효과를 객관적으로 비교하고 배포 이후의 형식 오류나 행동 편차를 줄이는 데 도움이 된다.

## 확인 범위

이번 내용은 AWS 머신러닝 블로그가 공개한 2부작 가운데 첫 번째 글을 바탕으로 확인했다. 데이터 품질 점검, JSONL 기반 형식, 추론 환경과의 구조 일치, 평가 데이터 분리 원칙이 다뤄졌다. 후속 글에서 다룰 예정인 데이터 준비도 평가, 고가치 표본 선택, 데이터 증강과 혼합 전략의 구체적인 결과는 이번 확인 범위에 포함되지 않는다.
