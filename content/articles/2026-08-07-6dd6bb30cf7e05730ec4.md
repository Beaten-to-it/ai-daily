## 무엇이 있었나

LLM 에이전트가 잘못된 도구를 골랐을 때 그 원인까지 분석하기 위한 평가 방법이 제안됐다. 연구진은 MCP 도구 목록에 특정한 판단 약점을 시험하도록 설계한 진단용 ‘카나리 도구’를 넣고, 오류 유형을 의미적 미끼, 매개변수 함정, 기능 착시, 선행 조건 간과, 시간적 미끼, 작업 단위 함정 등 여섯 가지로 구분했다.

연구진은 성능 수준이 다른 모델 8개를 대상으로 120개 과제를 평가했다. 카나리 도구의 밀도와 반복 실행 조건을 달리한 본 실험은 8,640회, 표현의 노골성을 낮춘 추가 실험은 2,880회 진행됐다. 과제 성공 여부는 서로 독립적인 두 판정 모델로 확인했으며, 판정 일치도를 나타내는 코언의 카파는 0.75였다.

논문에 따르면 모델별 카나리 취약성은 약 36배까지 차이가 났다. 전반적으로 성능이 높은 모델일수록 취약성이 낮았지만, 같은 제공업체 안에서도 저렴한 모델이 더 안전한 사례가 나타나 성능 등급만으로 도구 선택의 안정성을 예측하기는 어려웠다. 카나리 취약성과 과제 성공률 사이에는 음의 상관관계도 관찰됐다. 연구진은 평가 프레임워크와 도구 명세, 과제, 실행 기록을 공개한다고 밝혔다.

## 왜 중요한가

도구를 사용하는 AI 에이전트는 검색, 데이터 처리, 업무 자동화 같은 실제 작업에서 어떤 도구를 선택하고 어떤 순서로 호출할지 판단해야 한다. 기존 평가는 대체로 성공과 실패를 가르는 데 집중했지만, 이번 방법은 실패 원인을 유형별로 나눠 모델의 약점을 비교할 수 있게 한다.

국내 기업과 기관이 MCP 기반 에이전트를 도입할 때도 단순한 벤치마크 점수만으로 모델을 고르기보다 실제 제공할 도구 구성에서 선택 오류가 어떻게 발생하는지 점검할 필요가 있다는 의미다. 특히 고성능 모델이라도 존재하지 않거나 과장된 기능을 암시하는 ‘기능 착시’에 흔들릴 수 있다는 연구 결과는 도구 설명 설계와 배포 전 안전성 평가의 중요성을 보여준다.

## 확인 범위

이번 내용은 arXiv에 공개된 10쪽 분량의 사전 공개 논문과 초록에서 확인했다. 실험 규모, 모델 간 비교, 상관관계와 판정 일치도는 논문 저자들이 보고한 결과이며, 동료평가나 독립적인 재현을 거쳐 확정된 결론으로 볼 수는 없다. 개별 모델의 세부 조건과 모델별 수치, 실제 운영 환경에서의 일반화 가능성은 논문 전문과 후속 검증을 통해 추가로 확인해야 한다.
