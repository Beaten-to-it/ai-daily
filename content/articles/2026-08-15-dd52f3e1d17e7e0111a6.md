## 무엇이 있었나
Ollama가 0.32.11 버전을 공개했다. 이번 릴리스에서는 `ollama launch dsh`를 통한 오픈소스 에이전트 하네스 DeepSeek Harness 지원과 `ollama launch muse`를 통한 Meta의 에이전트형 코딩 CLI Muse Code 지원이 추가됐다.

OpenAI 호환 Responses API에는 웹 검색 기능이 도입됐다. Muse Glimmer 템플릿도 함께 업데이트됐다.

## 왜 중요한가
로컬 환경에서 AI 모델과 코딩 에이전트를 운용하는 개발자는 Ollama를 통해 DeepSeek Harness와 Muse Code를 실행할 수 있는 선택지를 얻게 됐다. OpenAI 호환 API의 웹 검색 지원은 해당 인터페이스를 이용하는 애플리케이션에서 최신 외부 정보를 활용하는 기능을 구성할 때 특히 의미가 있다.

국내 개발팀에도 기존 OpenAI 호환 도구와 로컬 모델 운영 환경을 연결할 수 있는 범위가 넓어졌다는 점에서 주목할 만하다. 다만 실제 지원 모델과 설정 방법, 웹 검색의 동작 조건은 별도 문서와 사용 환경을 확인해야 한다.

## 확인 범위
GitHub에 게시된 Ollama 0.32.11 릴리스 노트에서 명시한 변경 사항과 공개 시점을 확인했다. 각 기능의 세부 설정, 성능, 안정성, 보안 영향 및 운영 환경별 호환성은 이 자료만으로 확인되지 않는다.
