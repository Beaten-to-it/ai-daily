## 무엇이 있었나

GitHub가 Copilot 코드 리뷰의 검토 수준인 ‘Lite’와 ‘Balanced’를 정식 출시했다. 사용자는 풀 리퀘스트의 복잡성과 위험도에 따라 리뷰 깊이를 선택할 수 있다. Lite는 문서 수정이나 간단한 버그 수정처럼 비교적 단순한 변경에, Balanced는 복잡한 로직이나 보안에 민감한 코드, 여러 서비스에 걸친 변경에 적합하다.

공개 미리보기에서 제공했던 Low와 Medium은 각각 Lite와 Balanced로 이름이 바뀌었다. 기존 설정은 새 명칭으로 자동 승계된다. 개별 리뷰를 요청할 때 선택한 수준은 해당 리뷰에만 적용되며 저장소나 조직의 기본 설정을 바꾸지는 않는다.

조직 관리자는 전체 저장소에 적용할 기본 검토 수준을 지정할 수 있다. 별도 수준을 설정하지 않은 저장소는 조직 기본값을 상속한다. 실제 사용된 수준은 풀 리퀘스트의 타임라인 이벤트와 개요 댓글에서 확인할 수 있다.

두 옵션은 Copilot Pro, Pro+, Max, Business, Enterprise 요금제에서 제공된다.

## 왜 중요한가

모든 코드 변경을 같은 강도로 검토할 필요가 없는 팀은 작업 특성에 맞춰 리뷰 자원을 배분할 수 있게 됐다. 일상적인 변경에는 빠르고 집중된 피드백을 받고, 장애나 보안 문제로 이어질 가능성이 큰 변경에는 더 깊은 분석을 적용하는 식이다.

특히 여러 저장소를 운영하는 국내 기업과 개발 조직에는 조직 기본값과 저장소별 설정을 함께 활용할 수 있다는 점이 유용하다. 공통 기준을 마련하면서도 프로젝트 특성에 맞게 검토 수준을 조정할 수 있고, 리뷰 기록에 사용 수준이 표시돼 운영 현황을 추적하기도 쉬워진다.

## 확인 범위

GitHub가 2026년 8월 7일 공개한 변경 공지에서 Lite·Balanced의 정식 출시, 명칭 변경과 기존 설정 승계, 적용 방식, 조직 기본값, 사용 수준 표시 및 지원 요금제를 확인했다. 각 수준의 구체적인 처리 시간, 비용 차이, 모델 사양과 성능 수치는 해당 공지에 제시되지 않아 포함하지 않았다.
