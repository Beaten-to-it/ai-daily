## 무엇이 있었나

GitHub가 github.com에서 제공하던 GitHub Spark를 2026년 8월 31일 종료한다. 8월 4일부터 신규 사용자 등록과 새 앱 생성은 중단됐으며, 기존 사용자는 종료일까지 접속해 이전에 만든 앱의 코드를 내보낼 수 있다.

이미 배포된 앱은 Spark 종료 이후에도 계속 작동한다. 다만 향후 앱을 수정하려면 종료 전에 Spark 작업 공간에서 저장소를 생성해 코드를 보존해야 한다.

Spark의 `llm()` 함수가 사용하던 추론 서비스 GitHub Models는 이보다 앞선 7월 30일 종료됐다. 이에 따라 `llm()` 호출은 더 이상 작동하지 않는다. 해당 함수를 사용하는 앱에서 AI 기능을 유지하려면 별도의 추론 서비스로 교체하고, 이용자가 API 키와 비용을 직접 관리해야 한다. `llm()`을 사용하지 않는 앱은 GitHub Models 종료의 영향을 받지 않는다.

GitHub는 AI 모델과 에이전트형 개발 도구가 발전하면서 이용자들이 VS Code, Copilot CLI, GitHub Copilot 앱 등 기존 작업 환경에 통합된 개발 방식을 더 많이 선택하고 있다고 서비스 종료 배경을 설명했다.

## 왜 중요한가

국내 GitHub Spark 이용자에게 가장 중요한 시한은 8월 31일이다. 배포된 앱이 즉시 중단되는 것은 아니지만, 이후에도 코드를 수정하거나 다른 환경에서 개발하려면 그 전에 저장소로 내보내야 한다.

AI 기능을 포함한 앱은 별도 점검이 필요하다. 코드에서 `llm()` 사용 여부를 확인하고, 사용 중이라면 대체 추론 제공업체와 인증·과금 방식을 마련해야 한다. Spark 종료와 GitHub Models 종료는 서로 다른 조치이므로, 앱 배포 상태뿐 아니라 AI 호출 의존성도 따로 확인해야 한다.

이번 결정은 GitHub의 AI 기반 앱 개발 경험이 독립적인 Spark 서비스보다 Copilot 중심의 통합 개발 환경으로 재편되고 있음을 보여준다.

## 확인 범위

GitHub가 2026년 8월 4일 공개한 변경 공지에서 서비스 종료 일정, 기존 앱의 처리 방식, 코드 내보내기 절차와 `llm()` 영향 범위를 확인했다. 이미 배포된 앱의 지속 운영 기간이나 개별 대체 추론 서비스의 호환성·비용은 공지에 구체적으로 제시되지 않았다.
