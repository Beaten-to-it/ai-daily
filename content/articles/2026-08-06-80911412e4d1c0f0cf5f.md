## 무엇이 있었나

AWS가 아마존 베드록의 웹 검색 기능을 미국에서 정식 출시했다. 기반 모델이 학습 이후의 최신 정보를 활용할 수 있도록 서버 측에서 웹 검색을 수행하고, 관련 내용과 출처를 모델의 문맥에 넣어 답변을 생성하는 기능이다.

AWS에 따르면 이 기능은 아마존이 운영하는 웹 색인과 지식 그래프를 함께 활용한다. 검색 결과에서는 질의와 관련된 구간을 추려 모델에 전달하며, 최종 응답에는 출처 URL과 문서 제목을 담은 구조화된 인용 정보가 포함된다.

개발자는 오픈AI 호환 Responses API 요청의 도구 목록에 웹 검색을 추가해 기능을 활성화할 수 있다. 별도의 검색 사업자 연동이나 클라이언트 측 도구 호출 반복 과정은 필요하지 않다. 인증에는 기존 AWS 자격 증명과 IAM 권한이 사용되며, 검색 및 페이지 조회 활동은 AWS CloudTrail 관리 이벤트로 기록된다.

출시 시점에는 아마존이 미리 색인한 웹 자료만 검색할 수 있다. 실시간 외부 웹 접근을 위한 API 항목과 권한 체계는 마련됐지만, 실제 검색 지원은 향후 제공될 예정이다. 서비스는 미국 동부 버지니아 북부·오하이오와 미국 서부 오리건 리전에서 리전 내 질의 처리를 지원한다.

## 왜 중요한가

최신 정보가 필요한 챗봇이나 업무용 AI를 구축할 때 검색 API, 인증 수단, 결과 파싱, 재시도 체계를 따로 조합해야 했던 부담을 줄일 수 있다는 점이 핵심이다. 베드록을 사용하는 한국 기업도 기존 AWS 권한 관리와 감사 체계 안에서 검색 기반 응답을 구현할 선택지가 생겼다.

특히 검색어와 검색 결과 URL, 가져온 페이지 원문은 CloudTrail에 기록하지 않으면서 호출 주체와 시각, 수행 작업은 감사할 수 있다는 것이 AWS의 설명이다. 규제 산업이나 기업 내부 환경에서는 AI의 최신성뿐 아니라 데이터 이동과 접근 기록도 중요하므로 검토 가치가 있다.

다만 현재 제공 리전이 미국으로 한정돼 있어 한국에서 도입할 때는 지연 시간, 데이터 처리 위치, 조직의 규제·보안 요건을 함께 확인해야 한다. 실시간 웹 조회가 아직 지원되지 않는다는 점도 최신성이 중요한 서비스에서는 고려해야 한다.

## 확인 범위

이번 내용은 2026년 8월 4일 공개된 AWS ML 공식 발표에서 확인했다. 정식 출시 여부, 지원 리전, API 사용 방식, IAM 권한과 CloudTrail 기록 범위는 해당 발표를 기준으로 정리했다.

웹 색인의 실제 갱신 주기와 검색 품질, 응답 지연, 비용, 지원 모델의 전체 목록은 제공된 자료만으로 비교·검증하지 않았다. 데이터 유출이 없다는 설명과 규정 준수 관련 특성 역시 AWS가 밝힌 서비스 설계를 요약한 것으로, 개별 기업의 규제 충족을 보장하는 의미는 아니다.
