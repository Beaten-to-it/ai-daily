## 무엇이 있었나

개발자 사이먼 윌리슨이 대규모언어모델용 명령줄·파이썬 도구인 LLM 0.32를 공개했다. 이번 버전은 추론 모델의 추론 과정을 표준 오류 출력으로 분리해 보여주며, 일반 출력에는 섞이지 않도록 설계됐다.

OpenAI Responses API 기반 기능과 공급자 측 서버 도구도 추가됐다. OpenAI의 코드 실행 및 웹 검색을 사용할 수 있고, 함께 갱신된 `llm-anthropic` 플러그인은 웹 검색·웹 문서 가져오기·코드 실행·MCP 연결을 지원한다. OpenAI 호환 엔드포인트에 일회성 요청을 보내는 명령도 새로 제공된다.

파이썬 API에는 전체 메시지 이력을 직접 전달하는 방식과 추론, 텍스트, 도구 호출 등 서로 다른 응답을 이벤트 단위로 처리하는 스트리밍 인터페이스가 도입됐다. 반복되는 대화 기록의 중복 저장을 줄이기 위해 Git에서 착안한 콘텐츠 주소 기반 SQLite 메시지 저장 구조도 적용됐다.

## 왜 중요한가

이번 개편은 LLM 응답을 단순 문자열이 아니라 추론 과정, 본문, 도구 호출, 첨부물 등이 섞인 구조화된 흐름으로 다룬다는 점에서 의미가 있다. 여러 모델과 도구를 조합하는 국내 AI 서비스 개발자도 명령줄 실험부터 파이썬 기반 에이전트 구축까지 한 도구 체계에서 이어갈 수 있다.

특히 추론 출력과 실제 결과를 분리하면 다른 프로그램으로 결과를 전달하는 자동화 흐름을 유지하면서 디버깅 정보를 확인할 수 있다. 사람의 승인을 기다렸다가 작업을 재개하거나 저장된 대화 기록을 활용하는 기능도 갖춰지면서 LLM은 범용 모델 실행기를 넘어 에이전트 개발 기반에 가까워졌다.

## 확인 범위

LLM 0.32의 공개와 주요 기능은 프로젝트 개발자가 작성한 발표 글을 기준으로 확인했다. 기존 플러그인의 호환성은 유지되지만, 새 스트리밍 이벤트 체계를 온전히 사용하려면 모델 제공 플러그인의 갱신이 필요하다고 안내됐다. 각 공급자 도구의 실제 동작 범위와 운영 환경별 안정성·성능은 이 자료만으로 독립 검증하지 않았다.
