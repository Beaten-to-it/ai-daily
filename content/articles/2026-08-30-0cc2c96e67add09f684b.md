## 무엇이 있었나

GitHub가 Visual Studio 2026용 GitHub Copilot의 8월 업데이트를 공개했다. 지원 모델의 사고 수준을 낮음·중간·높음으로 조절할 수 있게 됐으며, 자주 쓰는 모델을 고정하거나 모델별 기능과 컨텍스트 창 크기, 비용 정보를 확인하는 관리 화면도 추가됐다.

Git 에이전트에는 풀 리퀘스트를 열기 전 커밋 또는 커밋하지 않은 변경 사항을 검토하는 기능이 도입됐다. 검토 결과는 편집기와 Git Changes 화면에 표시되며, Copilot Chat에서 제안 내용을 이어서 묻거나 수정할 수 있다. 이 기능은 GitHub와 Azure DevOps 저장소를 지원한다.

조직 및 엔터프라이즈 소유자는 여러 저장소에서 사용할 맞춤형 에이전트를 게시할 수 있다. Visual Studio는 이를 자동으로 감지해 에이전트 선택 화면에 설명과 소속 조직을 표시한다. Copilot 사용량과 요금제 한도도 프롬프트 창에서 확인할 수 있다.

이번 업데이트는 Copilot Free와 Student를 포함해 Pro, Pro+, Max, Business, Enterprise 등 모든 GitHub Copilot 요금제 이용자에게 제공된다.

## 왜 중요한가

개발자는 단순한 작업에는 낮은 사고 수준을, 디버깅이나 알고리즘·아키텍처 판단에는 높은 수준을 선택해 추론 깊이와 토큰 사용량의 균형을 조절할 수 있다. 모델 선택 기준과 비용 정보를 한곳에서 확인할 수 있다는 점도 업무별 모델 운영을 단순하게 만든다.

특히 코드 변경을 풀 리퀘스트 이전에 검토할 수 있어 개인 개발자와 팀 모두 피드백 시점을 앞당길 수 있다. 국내 기업 환경에서 함께 쓰이는 GitHub와 Azure DevOps 저장소를 모두 지원한다는 점도 활용 범위를 넓힌다. 조직 단위 맞춤형 에이전트 배포는 팀별 개발 규칙이나 전문 작업 절차를 여러 저장소에 공유하는 기반이 될 수 있다.

## 확인 범위

GitHub Changelog에 명시된 Visual Studio 2026용 8월 업데이트의 기능, 지원 저장소와 대상 요금제를 확인했다. 조직 단위 맞춤형 에이전트에는 GitHub 조직이 필요하다. 개별 기능의 세부 배포 일정, 지원 모델 목록, 지역별 제공 여부와 구체적인 비용 산정 방식은 제공된 본문에서 확인되지 않았다.
