## 무엇이 있었나

OpenAI가 8월 14일 파이썬 SDK `openai-python` 3.1.0을 공개했다. 이번 버전에는 웹소켓 스트림 ID와 워크로드 아이덴티티 액세스 토큰 발급 이벤트가 추가됐다.

또한 초고속 처리 등급인 Ultrafast tier 관련 지원을 비롯해 구조화된 MCP·웹소켓 오류, 세분화된 웹소켓 이벤트가 반영됐다. Sora 영상 API는 사용 중단 예정 상태로 전환됐다. 유지보수 항목으로는 Stainless 관련 표기와 인프라 제거가 포함됐다.

## 왜 중요한가

파이썬으로 OpenAI API를 연동하는 국내 개발팀은 실시간 통신 흐름을 더 세밀하게 식별하고, 웹소켓 오류와 이벤트를 구조적으로 처리할 수 있게 됐다. 워크로드 아이덴티티 관련 이벤트 추가도 서비스 간 인증 상태를 추적하는 구현에 영향을 줄 수 있다.

기존 Sora 영상 API 이용자는 사용 중단 예고가 적용된 범위와 향후 이전 경로를 별도로 확인할 필요가 있다. SDK를 올리기 전에는 웹소켓 이벤트 처리 코드와 오류 분기, 영상 API 의존성을 중심으로 호환성을 점검하는 편이 안전하다.

## 확인 범위

GitHub의 공식 3.1.0 릴리스 페이지에 기재된 기능 및 유지보수 변경 사항을 확인했다. 각 기능의 상세 인터페이스, Ultrafast tier의 이용 조건, Sora 영상 API의 종료 일정이나 대체 API는 해당 릴리스 요약만으로 확인되지 않는다.
