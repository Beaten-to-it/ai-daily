## 무엇이 있었나

LangChain이 1.4.0 계열의 세 번째 알파 버전인 `langchain==1.4.0a3`를 공개했다. 이번 시험판은 MCP 서버를 LangChain 도구로 연결하는 새로운 `langchain.mcp` 네임스페이스에 초점을 맞췄다.

핵심 기능인 `MCPAdapter`는 URL과 로컬 스크립트, 프로세스 내부 서버, 여러 서버를 지정한 MCP 설정, 기존 클라이언트 등 다양한 연결 대상을 지원한다. 서버가 제공하는 도구를 탐색해 LangChain 도구로 변환하며, 서버가 알린 유효기간을 활용하는 클라이언트 측 목록 캐시 기능도 제공한다.

MCP 서버가 도구 실행 도중 사용자에게 추가 정보를 요청하면 이를 LangGraph 인터럽트로 전달하고, 답변을 받은 뒤 실행을 재개하는 기능도 포함됐다. 사용하려면 `mcp` 추가 의존성과 `fastmcp` 4.0.0 이상이 필요하다. 알파 버전이므로 설치할 때 시험판 허용 옵션을 지정해야 한다.

## 왜 중요한가

여러 MCP 서버의 기능을 LangChain 에이전트에 붙이는 과정이 하나의 공식 네임스페이스와 어댑터로 정리되기 시작했다는 점이 중요하다. 국내에서 사내 데이터나 업무 시스템을 MCP 서버로 제공하는 개발팀이라면, 기존 LangChain 도구 체계와 연결할 때 필요한 변환 코드를 줄일 가능성이 있다.

특히 실행 도중 사람의 확인을 받고 이어서 처리하는 흐름은 승인이나 추가 입력이 필요한 업무형 에이전트를 설계할 때 활용할 수 있다. 다만 아직 알파 단계여서 실제 서비스에 적용하려면 향후 변경 가능성과 의존성 호환성을 함께 검토해야 한다.
