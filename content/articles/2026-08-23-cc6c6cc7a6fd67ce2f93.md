## 무엇이 있었나

엔비디아는 장기 작업용 AI 에이전트 아키텍처 ‘AVO(Agentic Variation Operators)’가 ARC-AGI-3 공개 세트의 25개 환경, 183개 레벨을 모두 완료해 RHAE 100.00점을 기록했다고 밝혔다. Claude Opus 5를 기반 모델로 사용했으며, 전체 수행에 6,624회의 환경 행동이 필요했다.

AVO는 모델 하나의 추론 능력보다 에이전트 시스템 전반의 설계에 초점을 둔다. 작업 과정과 평가 결과를 이어받는 영속 메모리, 진행 정체를 감시하고 방향 전환을 돕는 감독 장치, 외부 도구를 활용하는 실행 루프가 핵심 요소다. ARC-AGI-3에서는 이미지 대신 정확한 64×64 텍스트 격자를 관찰 정보로 제공했다.

엔비디아는 앞서 AVO를 GPU 커널 최적화에도 적용했다. 회사 설명에 따르면 에이전트는 7일 동안 500개가 넘는 최적화 방향을 탐색하고 40개 커널 버전을 커밋했다. NVIDIA DGX B200에서 평가한 멀티헤드 어텐션 커널은 구성에 따라 cuDNN보다 최대 3.5%, FlashAttention-4보다 최대 10.5% 높은 성능을 보였다.

## 왜 중요한가

이번 결과는 장시간 이어지는 AI 작업의 성패가 기반 모델뿐 아니라 메모리, 도구 사용, 피드백 처리, 실패 복구 같은 시스템 구성에도 크게 좌우될 수 있음을 보여준다. 동일한 에이전트 구조가 GPU 코드 최적화와 규칙이 주어지지 않은 상호작용형 추론 문제에 모두 적용됐다는 점도 주목할 만하다.

한국의 AI 개발 조직에도 시사점이 있다. 업무 자동화 에이전트를 평가할 때 단발성 답변 품질만 볼 것이 아니라, 여러 단계에 걸쳐 상태를 보존하고 잘못된 가설을 수정하며 실제 실행 결과를 반영하는 능력까지 검증해야 한다. 모델 교체만으로 성능 향상을 기대하기보다 모델을 둘러싼 실행 구조를 함께 설계해야 한다는 의미다.

## 확인 범위

확인된 결과는 ARC-AGI-3의 25개 환경으로 구성된 공개 세트에 한정된다. 준비공개 또는 비공개 경쟁 세트의 성적은 포함되지 않았다.

엔비디아는 같은 공개 세트를 완료한 VISTA의 7,542회와 비교해 AVO가 약 12% 적은 환경 행동을 사용했다고 설명했다. 다만 두 시스템은 에이전트 백엔드, 관찰 형식, 메모리와 문맥 관리 방식 등이 달라 통제된 비교 실험으로 볼 수 없다. 따라서 차이를 AVO의 특정 구성 요소나 기반 모델의 효과로 단정할 수 없다. GPU 커널 성능 수치와 ARC-AGI-3 결과 역시 엔비디아가 공개한 자체 연구 결과를 기준으로 정리했다.
