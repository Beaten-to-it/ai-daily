## 무엇이 있었나

메타가 대규모 코드 저장소에서 복잡한 개발 업무를 수행하는 터미널 기반 AI 에이전트 ‘Muse Code’를 베타로 공개했다. 메타에 따르면 이 도구는 변경 계획 수립부터 코드 작성, 결과 검증까지 하나의 소프트웨어 엔지니어링 작업 흐름을 처리한다.

Muse Code는 메타의 코딩 모델 ‘Muse Spark’를 기반으로 한다. 규모가 큰 작업은 격리된 Git 워크트리에서 여러 하위 에이전트가 동시에 처리하도록 분산하며, 사용자의 작업 사본에는 직접 손대지 않는 방식이라고 회사 측은 설명했다. 메타는 내부 시험에서 게임 기능 여섯 개를 충돌 없이 병렬로 개발했다고 밝혔다.

## 왜 중요한가

이번 공개는 메타가 OpenAI의 Codex, Anthropic의 Claude Code 등이 경쟁하는 AI 코딩 에이전트 시장에 본격적으로 진입했다는 의미가 있다. 특히 대형 저장소의 작업을 여러 에이전트에 나누고 각각 격리된 환경에서 실행하는 구조는 개발 속도뿐 아니라 변경 충돌과 작업 사본 오염 위험을 줄이려는 접근으로 볼 수 있다.

한국의 개발팀에도 비용과 대규모 프로젝트 지원 여부가 새로운 선택 기준이 될 수 있다. 다만 실제 도입 가치는 한국어 개발 환경과 사내 저장소에서의 정확도, 보안·권한 관리, 기존 개발 도구와의 호환성 등을 별도로 검증한 뒤 판단해야 한다.

## 확인 범위

TechCrunch가 보도한 제품 공개 사실과 메타 경영진이 밝힌 기능 설명을 바탕으로 정리했다. Muse Code가 현재 베타라는 점, Muse Spark를 기반으로 한다는 점, 하위 에이전트와 격리된 워크트리를 활용한다는 점은 기사에서 확인된다.

반면 설치 명령, 지원 운영체제와 프로그래밍 언어, 구체적인 가격·이용 조건, 일반 공개 일정은 제공된 기사에서 확인되지 않는다. 병렬 개발 성과와 비용 경쟁력 역시 메타 측 설명에 해당하며, 독립적인 성능 평가 결과는 기사에 제시되지 않았다.
