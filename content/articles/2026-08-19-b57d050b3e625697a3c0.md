## 무엇이 있었나

로보틱스 데이터 플랫폼 기업 폭스글러브가 자연어로 로봇 데이터를 다루는 에이전트 워크플로를 베타로 공개했다. 사용자는 데이터에 관한 질문을 하거나 시각화 레이아웃과 사용자 스크립트를 만들고, 저장된 로봇 기록을 검색할 수 있다.

기능은 폭스글러브 앱에 내장된 ‘에이전트 사이드바’와 데스크톱 앱에서 실행되는 MCP 서버로 제공된다. 사이드바는 요청 의도와 현재 작업 맥락을 바탕으로 검색이나 화면 구성 등의 작업을 수행한다. MCP 서버는 Claude, ChatGPT, Cursor 같은 외부 AI 에이전트가 폭스글러브를 조작하도록 연결한다.

폭스글러브는 이 시스템이 LLM 인프라, 로컬·클라우드 도구, 평가 파이프라인으로 구성된다고 설명했다. 현재 에이전트 기능은 모든 고객에게 베타로 제공된다.

## 왜 중요한가

로봇 개발에서는 코드뿐 아니라 카메라 영상, 센서 신호, 운행 기록 등 다양한 형식의 데이터를 함께 분석해야 한다. 이번 기능은 검색과 시각화 구성, 기록 검토처럼 여러 도구에 걸친 작업을 자연어 중심으로 연결하려는 시도다.

국내 로봇·자율주행·스마트 제조 개발팀에도 의미가 있다. 예를 들어 코드 테스트 실패와 관련된 로봇 기록을 찾아 시각화 화면에 준비하는 과정을 외부 AI 에이전트와 연계할 수 있다. 다만 실제 도입 효과는 조직의 데이터 구조와 보안 정책, 사용 중인 개발 도구, 에이전트의 작업 정확도에 따라 달라질 수 있다.

## 확인 범위

폭스글러브가 공개한 제품 발표를 통해 기능 구성, 제공 방식, 베타 제공 대상과 기술 구조를 확인했다. 성능이나 정확도, 작업시간 절감 효과를 입증하는 비교 평가 수치는 제시되지 않았다. 외부 AI 서비스와 연결할 때의 데이터 처리 범위와 보안 조건도 이번 자료만으로는 구체적으로 판단하기 어렵다.
