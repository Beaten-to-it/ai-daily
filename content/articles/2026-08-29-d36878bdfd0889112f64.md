## 무엇이 있었나

Antigravity에 사용자가 직접 조작할 수 있는 ‘Interactive Generative UI Artifacts’ 기능이 추가됐다. 에이전트는 HTML·CSS·자바스크립트 기반의 아티팩트를 생성해 동적 대시보드와 차트, 탐색형 설명 자료, 디자인 목업, 3D 시뮬레이션 등을 대화 화면이나 별도 패널에 표시한다.

사용자는 결과물을 클릭해 작동 방식을 살펴보고, 자연어로 구성이나 표현을 계속 수정할 수 있다. 생성된 아티팩트는 별도 패키지 설치 없이 로컬에서 실행되며, 오프라인 사용과 독립형 HTML 파일 내보내기도 지원한다. `/generative_ui` 명령을 통한 생성도 가능하다.

## 왜 중요한가

텍스트나 정적인 도표만으로 이해하기 어려운 프로젝트 의존성, 데이터 흐름, 알고리듬의 작동 과정 등을 직접 탐색할 수 있는 형태로 설명할 수 있게 됐다. 분석 결과를 외부 시각화 도구로 옮기지 않고 같은 작업 흐름에서 확인하고 수정할 수 있어 데이터 분석과 UI 프로토타이핑의 반복 작업을 줄일 가능성이 있다.

독립형 HTML 내보내기와 로컬 실행 지원은 인터넷 연결이 제한된 환경에서 결과물을 확인하거나, Antigravity 밖에서 공유·재사용하려는 국내 개발자와 기획자에게도 실용적인 요소다.

## 확인 범위

GeekNews에 게시된 기능 소개를 바탕으로 기능의 종류, 실행 방식, 수정 흐름과 내보내기 지원 여부를 확인했다. 실제 성능과 브라우저 호환성, 보안 격리 방식, 복잡한 데이터에서의 처리 한계는 제공된 자료만으로 확인되지 않았다.
