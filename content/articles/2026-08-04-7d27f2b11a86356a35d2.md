## 무엇이 있었나

서로 다른 대형언어모델(LLM) 사이에서 문맥의 KV 캐시를 변환해 재사용하는 프레임워크 ‘Mixture-of-Translators(MoT)’가 제안됐다. 모델마다 KV 캐시의 내부 표현이 달라 같은 문맥이라도 각 모델이 별도로 사전 처리하거나 캐시를 저장해야 했던 문제를 줄이는 것이 목표다.

MoT는 여러 변환 모듈을 조합해 출발 모델의 캐시를 대상 모델의 캐시 공간으로 옮긴다. 연구진은 대상 모델이 원래 문맥을 처리했을 때의 궤적과 변환된 캐시를 재생했을 때의 궤적을 맞추는 ‘Context Correction Loss’도 도입했다. 이 방식은 캐시를 너무 일찍 주입할 때 번역 오차가 누적되는 현상과, 늦게 주입할 때 마지막 상태가 어긋나는 현상을 함께 다루도록 설계됐다.

논문 초록에 따르면 Qwen2.5, GPT-2, OPT 계열을 대상으로 같은 구조와 서로 다른 구조 간 변환을 평가했다. Qwen2.5-7B 규모 실험에서는 폐쇄형 질의응답 평균 정확도 51.0%, 추출형 질의응답 평균 F1 0.43을 기록했다. 장문 문맥 기반 생성 사례에서는 원문 문맥을 직접 제공한 방식 대비 품질의 96.3%를 유지했다고 연구진은 보고했다.

## 왜 중요한가

여러 모델이 협업하는 멀티에이전트 시스템에서는 동일한 대화 기록이나 검색 자료를 모델마다 반복 처리하는 비용이 커질 수 있다. 모델 간 KV 캐시 재사용이 가능해지면 긴 문맥의 중복 연산과 저장 부담을 줄이고, 역할별로 다른 모델을 조합하는 시스템을 더 효율적으로 운영할 가능성이 생긴다.

한국어 서비스에서도 검색증강생성, 장문 문서 분석, 다중 에이전트 업무 자동화처럼 동일한 문맥을 여러 모델이 공유하는 구조에 적용 가능성이 있다. 다만 실제 효율은 변환 모듈의 학습 비용과 지연시간, 한국어 데이터에서의 성능, 대상 모델 조합에 따른 품질 변화까지 함께 검증해야 판단할 수 있다.
