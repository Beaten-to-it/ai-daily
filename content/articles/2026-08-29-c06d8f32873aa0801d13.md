## 무엇이 있었나

GitHub는 2026년 8월 28일부로 GitHub Classroom을 공식 폐기하고 웹사이트와 API, 관련 서비스를 종료했다. 이는 같은 해 5월 26일 발표한 전환 절차의 마무리다. GitHub는 Classroom 대신 자사가 선정한 파트너 솔루션을 이용하도록 안내했다.

Classroom 활동을 위해 만든 GitHub 사용자 계정과 저장소, 조직은 이번 조치의 영향을 받지 않는다. 다만 수업·과제 이름, 저장소 외부에서 정의한 테스트, LTI 연동 수강생 명단 등 일부 Classroom 전용 데이터는 GitHub의 데이터 보존 정책에 따라 영구 삭제된다.

## 왜 중요한가

GitHub Classroom을 사용해 온 국내 학교와 교육기관은 기존 계정·저장소를 계속 이용할 수 있지만, 수업 생성과 과제 배포 등 Classroom 기반 운영은 더 이상 지원받을 수 없다. 특히 저장소에 포함되지 않은 평가 설정이나 LTI 연동 정보는 유지 대상이 아니므로, 향후 수업 운영에는 대체 솔루션과 별도의 데이터 관리 방식이 필요하다.

## 확인 범위

GitHub Changelog가 밝힌 서비스 종료 범위, 유지되는 GitHub 자산, 영구 삭제되는 Classroom 전용 데이터의 예시를 확인했다. 구체적인 삭제 시점과 데이터별 보존 기간, 추천 파트너의 명단 및 이전 절차는 제공된 본문에서 확인되지 않았다.
