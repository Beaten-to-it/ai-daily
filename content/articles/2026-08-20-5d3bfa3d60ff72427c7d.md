## 무엇이 있었나

LangChain 프로젝트가 `langchain-core` 1.6.0을 공개했다. 1.5.6 이후 변경 사항에는 표준 모델 예외 유형 추가와 함께 도구 스키마, 직렬화, 템플릿, 실행 흐름 관련 수정이 포함됐다.

엄격한 도구 스키마에서 중첩 속성을 필수로 처리하도록 개선했으며, 전방 참조를 해석할 수 없는 도구 스키마는 직렬화 과정에서 조기에 실패하도록 변경했다. `RunnablePick` 역직렬화와 지연된 타입 주석 처리 문제도 수정됐다.

이 밖에 OpenAI 함수 변환 과정에서 호출 가능한 객체와 딕셔너리가 아닌 매핑을 처리하도록 지원 범위를 넓혔다. Mustache 템플릿의 비딕셔너리 매핑 지원, 체인 그룹 실행 종료 처리, Transformers 지연 로딩, Windows에서의 서브프로세스·임시 파일 테스트 이식성 개선도 반영됐다.

## 왜 중요한가

LangChain 기반 AI 애플리케이션에서 도구 호출 스키마와 직렬화는 모델과 애플리케이션 코드를 연결하는 핵심 경계다. 이번 변경은 잘못된 스키마를 더 일찍 드러내고 다양한 매핑 및 함수 형태를 처리해, 에이전트와 도구 연동 과정의 예측 가능성을 높이는 데 의미가 있다.

Windows 테스트 이식성 개선은 해당 환경에서 라이브러리를 개발하거나 검증하는 국내 개발자에게도 직접 관련된다. Transformers를 필요할 때 불러오도록 바꾼 성능 개선은 해당 의존성을 즉시 사용하지 않는 실행 경로의 초기 로딩 부담을 줄일 가능성이 있다.

## 확인 범위

GitHub에 게시된 `langchain-core` 1.6.0 릴리스와 변경 항목을 확인했다. 각 수정의 구체적인 동작, 성능 향상 폭, 기존 애플리케이션과의 호환성은 릴리스 페이지에 수치로 제시되지 않았으며 별도 실행 테스트로 검증하지 않았다. 도입 전에는 사용하는 도구 스키마와 직렬화 경로를 중심으로 회귀 테스트할 필요가 있다.
