Anthropic가 공개한 사례로, 캐나다 앨버타 주정부가 자체 보유한 약 **4억 6,600만 행**의 코드를 Claude Code(Opus/Sonnet)로 **20시간** 만에 훑어 보안 취약점(CVE)을 찾아내고 고쳤다는 내용이다. 사람이 손으로 했다면 대략 6.5년치 작업량에 해당한다는 계산이 함께 붙었다. 한 번에 코드 한 조각을 뽑아내는 생성이 아니라, 거대한 기존 코드베이스를 통째로 읽어 횡단적으로 손보는 이른바 '에이전트적 코딩'이 행정이라는 보수적인 현장에서 실운영 단계에 도달했다는 점이 이 사례의 핵심이다.

실무자 눈에 특히 눈에 띄는 대목은 테스트가 갖춰지지 않은 구간을 다루는 방식이다. Claude가 곧바로 수정에 들어가지 않고 **먼저 테스트 코드를 자동으로 작성한 뒤** 고치는 운용을 택했다고 한다. 레거시를 만질 때 회귀를 막는 안전망을 먼저 깔고 들어간다는, 사람이 하던 정공법을 에이전트 워크플로에 녹인 셈이다. 여기에 더해 25년 전 만들어진 Java 기반 신청 포털을 **4~5일 만에** 재구축한 예도 보고됐다.

기존 자산 棚卸(재고 점검)·취약점 대응·레거시 재구축에 AI를 어떻게 끼워 넣을지 고민하는 팀이라면, '스캔 → 테스트 선작성 → 수정'이라는 구체적인 형(型)으로 참고할 만하다. 다만 이 글은 트윗 한 건에서 나온 짧은 확인 수준이고 수치·기간은 Anthropic 발표 기준이라, 방법론은 취하되 성과 규모는 독립 검증 전 값으로 받아두는 게 좋겠다.
