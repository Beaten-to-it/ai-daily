## TL;DR

- Black Forest Labs가 이미지·영상·오디오를 하나의 아키텍처에서 함께 학습하는 멀티모달 파운데이션 모델 **FLUX 3**를 공개했다(7월 23일 발표, **Video는 Early Access로 이미 오픈**).
- 네이티브 오디오가 붙는 최대 20초 영상을 한 번에 생성하며, 초기 비교 평가에서 Runway Gen-4.5 대비 77%, Luma Ray 3.2 대비 93% 선호를 얻었다고 주장한다(단, 전부 "예비 결과"라고 명시).
- 같은 백본이 로봇 행동 예측(action prediction)까지 확장되어, mimic robotics와 만든 `FLUX-mimic`이 Audi 실제 생산 작업에서 테스트되고 있다 — "콘텐츠 생성과 피지컬 AI가 같은 기반 위에서 돈다"는 게 핵심 논지다.

## 무슨 일이 일어났나

Black Forest Labs(FLUX 시리즈 제작사)가 차세대 모델 **FLUX 3**를 발표했다. 이전 FLUX가 이미지 생성에 특화됐던 것과 달리, FLUX 3는 **이미지·영상·오디오를 하나의 통합 아키텍처에서 동시에 학습**하는 멀티모달 파운데이션 모델로 포지셔닝됐다.

BFL이 내세우는 설계 철학은 명확하다. 모델이 배워야 하는 것은 "이미지"나 "영상" 같은 개별 모달리티가 아니라 **세계 그 자체의 표현**이라는 것이다. 각 모달리티는 같은 하나의 실재를 서로 다른 센서로 투영한 것이고, 저마다 정보를 일부 잃는다 — 이미지는 특정 시점의 공간 구조를, 영상은 시간축과 물리 법칙을, 오디오는 시각만으로는 잡히지 않는 기계적 현상과 음향의 인과 관계를, 언어는 이 지각들을 목표·추상·지시로 연결한다. 하나만 배우면 그 투영의 좋은 모델을 얻지만, **전부를 동시에 배우면 모달리티 사이의 상호 제약이 더 많은 것을 알려준다**는 논리다. 원문 표현을 빌리면 "소리는 충돌과 맞아야 하고, 움직임은 질량을 따라야 하며, 미래는 과거로부터 이어져야 한다." 모달리티가 별개의 대상이 아니라 하나의 실재에 대한 증거가 되는 셈이다.

기술적 토대는 **Self-Flow**라는 자체 접근이다. 같은 아키텍처 안에서 멀티모달 "생성"과 "이해"를 효율적으로 정렬하는 방법이며, 여기에 연산·데이터를 크게 스케일업해 영상·이미지·오디오를 동시에 학습시킨 결과가 FLUX 3다. BFL은 Self-Flow를 기존 Flow Matching(FM)과 비교한 차트를 제시했는데 — 모달리티별 생성 오차(Fréchet distance, FM=100 기준 정규화, 낮을수록 좋음)와 파인튜닝을 통한 조작(manipulation) 과제 성공률(4개 과제군 평균, 높을수록 좋음)에서 우위를 보였다고 한다. 다만 구체적 수치는 공개하지 않았으므로, "FM 대비 오차는 낮고 성공률은 높다"는 방향성 정도로 읽는 게 정확하다.

### 영상(FLUX 3 Video)

핵심 상용 기능은 영상이다. **네이티브 오디오가 함께 생성되는 최대 20초 영상을 한 번의 생성으로** 만들 수 있다는 게 대표 스펙이다. 지원하는 방식은 다음과 같다:

- **Text-to-video**: 텍스트만으로 오디오 포함 영상 생성
- **Image-to-video**: 시작 프레임에서 이어가는 "애니메이션", 또는 이미지를 시각 레퍼런스로 사용
- **Video-to-video**: 레퍼런스 클립의 핵심 요소(예: 동일 캐릭터)를 새 장면으로 이식
- **영상-오디오 continuation**: 입력 영상·오디오로부터 이어 생성
- **Keyframe-to-video**: 정의된 순간들 사이의 통제된 전환
- 다국어 대화, 폭넓은 스타일·화면비, **여러 클립을 이어 붙이는 agentic chaining**으로 멀티샷 시퀀스 구성
- 강한 타이포그래피·애니메이션 디자인 생성

초기 비교 평가는 720p·10초 text-to-video(오디오 포함) 기준이며, BFL은 "모델과 하네스가 아직 개발 중이라 예비 결과이고 개선 여지가 있다"고 반복해서 못 박았다. 그 전제 위에서 제시한 선호도(preference)는 — Grok Imagine Video 대비 **최대 69%**, Kling v3 Pro 60%, Happy Horse v1 59%, Happy Horse 1.1 57%, Seedance 2.0 및 Gemini Omni Flash 각 52%, **Runway Gen-4.5 대비 77%, Luma Ray 3.2 대비 93%**다. 특히 **사람 표정 포착, 소리와 물리 사건의 연결, 다국어**에서 강하다고 자평했고, 시각 레퍼런스로 캐릭터 일관성을 유지하며 수 분짜리 시퀀스로 확장 가능하다고 밝혔다.

### 이미지(FLUX 3 Image)

이미지는 다양한 스타일·화면비·해상도로 합성·편집이 가능하다. midtraining 단계의 예비 평가에서 이전 FLUX 대비 **복잡한 프롬프트 처리와 텍스트 생성이 크게 개선**됐고, 여러 언어의 고정확도 텍스트 렌더링을 지원한다고 한다. Image의 Early Access는 "앞으로 몇 주 내"로 예고됐다(아직 오픈 아님).

### 행동 예측(Action)

FLUX 3의 세계 이해는 **행동 예측**으로도 확장된다. 두 경로를 취했다 — (1) Self-Flow 작업을 스케일업해 네이티브 행동 예측을 FLUX 3에 직접 통합, (2) 사전학습된 영상 백본을 "역학(dynamics)을 아는" 기반으로 삼아, 적은 과제별 데이터로 특화된 행동 모델을 파인튜닝. 두 번째 경로의 초기 파트너가 **mimic robotics**이며, 함께 FLUX 3 백본과 mimic의 로봇 학습 전문성을 결합한 video-action 모델 **FLUX-mimic**을 만들었다. 이 조합은 **Audi의 실제 생산 과제**에서 테스트되고 있다고 한다.

### 출시 계획

모든 기능은 동일한 멀티모달 flow matching 모델에서 나오며, 각각 Early Access를 거쳐 순차 공개된다:

- **FLUX 3 Video** — 영상·오디오 생성/편집, API 및 private weight 접근 (지금 Early Access)
- **FLUX-mimic / FLUX 3 Action** — 행동 예측, mimic robotics를 시작으로 선별된 연구·상업 파트너 대상
- **FLUX 3 Image** — 이미지 합성/편집, API 및 private weight 접근 (몇 주 내 예정)
- **FLUX 3 Dev** — 콘텐츠 생성(영상·오디오·이미지)과 행동 예측을 위한 **오픈 웨이트 멀티모달 백본** (예정)

## 왜 중요한가

첫째, **아키텍처 통합의 베팅**이다. 그동안 이미지(FLUX·SD), 영상(Kling·Runway·Sora 계열), 오디오, 로봇 정책 모델은 각자 다른 스택으로 발전해 왔다. FLUX 3는 이 모두를 하나의 flow 기반 모델에서 뽑아내겠다고 선언했고, 특히 **"콘텐츠 생성용 생성 모델"과 "피지컬 AI용 행동 모델"이 같은 백본을 공유한다**는 주장은 업계에서 흔치 않은 통합 명제다. 사실이라면 영상 생성 품질에 투입된 스케일이 로봇 조작 성능으로 전이된다는 뜻이 된다.

둘째, **오디오 네이티브 영상**이다. 20초 단일 생성에 소리가 처음부터 붙고, "소리를 물리 사건에 연결"하는 걸 강점으로 내세운 점은, 후처리로 오디오를 얹던 기존 파이프라인과 결이 다르다.

셋째, **오픈 웨이트 예고**다. FLUX 3 Dev로 멀티모달 백본을 오픈 웨이트로 풀겠다는 계획은, 사실이라면 로컬·자가호스팅 진영에 상당한 재료가 된다.

다만 냉정히 볼 지점 — **지금 손에 잡히는 건 Video Early Access뿐**이고, 벤치마크는 전부 자체 평가·예비 결과이며 절대 수치나 평가 프로토콜은 공개되지 않았다. 선호도 93% 같은 숫자는 "누가·어떤 조건에서 골랐는가"가 빠진 상태라 마케팅 수치로 읽고, 실측은 직접 돌려본 뒤 판단하는 게 맞다.

## 어떻게 써먹나

- **지금 가능**: 오디오 포함 영상이 필요한 팀이라면 FLUX 3 Video Early Access를 신청해 text/image/video-to-video와 keyframe·agentic chaining을 자사 워크플로에서 실측해볼 수 있다. 캐릭터 일관성(시각 레퍼런스)과 다국어 대화가 실제 얼마나 버티는지가 핵심 검증 포인트.
- **곧**: 이미지 파이프라인은 몇 주 내 Early Access 예정 — 다국어 텍스트 렌더링·복잡 프롬프트가 아쉬웠던 FLUX 사용자라면 대기.
- **로봇/피지컬 AI**: 행동 예측은 아직 파트너 한정이지만, "영상 백본을 적은 데이터로 파인튜닝해 조작 정책을 만든다"는 두 번째 경로는 데이터가 부족한 로봇 학습 팀에게 향후 주목할 접근이다.
- **오픈 웨이트 대기자**: FLUX 3 Dev는 아직 미출시 — 자가호스팅 계획은 실제 릴리스 시점과 라이선스를 확인한 뒤 세우는 게 안전하다.
